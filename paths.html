Pick a horizon (1 week, 2 weeks, 30 days) and execute instead of browsing randomly.

What belongs on this page (IA)

Path cards (below): title, audience, duration, outcome. Each card should eventually link to a path detail page with day-by-day tasks and outbound tutorial links.

Optional blocks to add next: “How to use paths” (15 min read), downloadable checklist PDF, and a table mapping paths → software (AutoCAD / Revit / Fusion).

Recommended path types

  • Literacy sprint — terms, 2D/3D mindset, file formats (no single vendor lock-in).
  • Tool execution — one software, one drawing loop: draft → annotate → plot.
  • Task rescue — one week on one job: dimensions, layers, xref, sheet sets, etc.

14-Day Starter Plan (Daily Execution)

Recommended for first-time CAD learners
Day 1-2: CAD basics + coordinate logic

Source type: beginner concept videos + glossary pages. Deliverable: explain model space/paper space and unit setup in your own words.

Day 3-4: layer, block, and selection workflow

Source type: myCADsite + YouTube beginner drills. Deliverable: complete one simple floor-plan draft with clean layer naming.

Day 5-6: dimension and annotation standards

Source type: tutorial detail recommendations. Deliverable: annotate your draft using one consistent dimension style template.

Day 7: mini review checkpoint

Deliverable: self-QA checklist completion (layers, text, dimensions, readability). Goal: find and fix at least 5 errors.

Day 8-10: 2D to 3D transition mindset

Source type: Fusion/Revit intro materials. Deliverable: compare when to use 2D drafting vs 3D modeling for one sample project.

Day 11-12: file formats and collaboration handoff

Source type: knowledge base glossary + domain notes. Deliverable: explain DWG, DXF, IFC, STEP usage scenarios.

Day 13: domain orientation (AEC / MFG / Product)

Deliverable: choose one domain track and list required software + workflow focus.

Day 14: final mini project loop

Deliverable: complete one small drawing/model from start to export and record lessons learned.

Path Completion Rules

Keep users retained, not just entertained

Rule 1: Every step has output

No passive watching. Each day ends with a file, checklist, or reflection note.

Rule 2: Weekly checkpoint

Users review mistakes and update a personal “do not repeat” error list.

Rule 3: Source switching by goal

Use different sources for concept, task drill, and formal progression to reduce drop-off.
