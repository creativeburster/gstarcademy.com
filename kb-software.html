The table lists only vendors with a credible English-global help or support surface. The OEMs below rely on domestic Greater China or mainland China documentation and sales channels; they do not maintain an equivalent standalone English-first help hub for overseas users, so we omit them from the main grid to avoid implying parity.

  • VHSoft (纬衡科技) — VHCAD and AEC-related tools are marketed heavily through regional Greater China sites. Public material is predominantly Chinese-facing; there is no consolidated global documentation tree comparable to the international vendors in the table above.
  • CAXA · Digitalchina — CAD and enterprise PLM lines target mainland China deployments with region-specific licensing and help launchers. International English documentation is not presented as a primary, self-contained portal for the same scope of products.

Per-vendor navigation notes

Short original pointers on how each official site is usually navigated (not quoted from OEM manuals). Expand a row to read; all deep content remains on the vendor.

Autodesk — how to enter

Begin at help.autodesk.com and lock the product + release year before searching—command names and palettes drift between versions. Use the Autodesk Knowledge Network / support hub when you have an error code or install ID; downloads and some articles require Autodesk Account entitlement. In desktop apps, Help → Learn often jumps to the matching web tree for your build.

Bentley — how to enter

docs.bentley.com is the documentation front door; filter by product family and whether you are on CONNECT-hosted services or legacy installs. Large infrastructure portfolios split across multiple microsites, so prefer product-specific landing pages from Bentley’s support navigation rather than guessing paths. Entitlement-gated downloads and communities sit under bentley.com/support.

Dassault Systèmes — how to enter

Treat SOLIDWORKS web help and 3DS platform / CATIA / DELMIA catalogs as separate worlds—URLs and login behavior differ. Consumer-grade discovery works from the public user-guides portal; 3DEXPERIENCE-hosted documentation often needs credentials even for browsing. Always match service pack or hotfix level when the tree is versioned. Deeper LearnCAD mapping: vendor profile, SOLIDWORKS profile and CATIA profile.

Nemetschek brands — how to enter

GRAPHISOFT, Vectorworks, and ALLPLAN operate distinct help domains; bookmark the brand you use. Archicad paths embed version segments (e.g., /29/)—swap only when you upgrade. Vectorworks uses rolling online help per release. ALLPLAN merges help and service ticketing on the brand site—pick language early because regional bundles differ.

HCL / CAMWorks — how to enter

CAM documentation is split between in-product help, CAMWorks.com customer tiles, and the broader HCL Software support umbrella. Start from CAMWorks Support for CAM-specific FAQs; escalate through HCL when you need entitlement-backed patches or account-level tickets. Expect manufacturing partners to route some requests before HCL.

Siemens — how to enter

Use the Siemens Support Center as the single gate for Doc Center articles, downloads, and PR/ISR references—almost everything valuable is tied to customer entitlement. NX, Solid Edge, Teamcenter, and Simcenter each have their own manuals inside the tree; search with exact build numbers. Legacy GTAC-era bookmarks may still redirect—follow the unified portal when in doubt.

Synopsys — how to enter

Semiconductor EDA stacks here—not mechanical CAD. Public marketing pages point to documentation, but SolvNetPlus hosts the real manuals and is customer-gated. Use the documentation landing to see what exists, then sign in for PDFs and interactive help. TCAD vs digital-implementation products use different tool families; scope your search narrowly.

PTC — how to enter

PTC splits Creo, Windchill, and add-ons into separate help centers under ptc.com/en/support/help; pick the product line first. Articles and Windchill administrative guides often assume a running server—filter for your deployment model. When Windchill redirects to PLM cloud topics, confirm whether you are Creo + desktop Windchill vs SaaS environment.

Ansys — how to enter

Ansys documentation is organized by product (Discovery, Mechanical, Fluent, Rocky, etc.) inside secured help trees—your install or license role controls depth. Start from the Customer Support Space for patches and release guidance, then open the HTML help that matches your installed major.minor version. Academic users may see separate Innovation Space learning hubs.

Altium — how to enter

The product documentation site is the canonical command and UI reference; Altium 365 and Designer share patterns but not identical menus. The public wiki is community-sourced—use it for workflow ideas, but trust the official docs for semantics. Wiki articles bridge licensing, updates, and interoperability with ECAD data management.

Hexagon — how to enter

Hexagon aggregates many acquisitions—MSC / Vero / metrology documentation may live on different subdomains (e.g., SimCompanion vs Hexagon MI docs). Identify your division first, then search within that silo; cross-product licensing is not always obvious from generic search. Login walls are common for solver downloads and full CAE decks.

Altair — how to enter

The help.altair.com launcher routes to HyperWorks, Inspire, OptiStruct, and related solvers—pick the suite that matches your seat file. Examples and release notes are version-stamped; mixing 2023 and 2025 trees causes broken deep links. Regional support portals handle tickets after you exhaust the public help tree for install-time issues.

ESI — how to enter

ESI’s public doc surface is deliberately thin: substantive PDFs and bundles sit in myESI behind customer login. Use the software-documentation page to learn what exists, then authenticate for downloads. Product marketing pages sometimes list high-level release notes suitable for pre-sales questions only.

Corel — how to enter

CorelDRAW and technical suites ship webhelp shells per OS and major version—open the landing that matches your product name. The knowledge base aggregates official PDF redistribution statements and version-specific user guides. Graphic suite bundles may share core documentation; confirm whether you are on subscription vs perpetual channel.

Gstarsoft — how to enter

Start from gstarcad.net for product positioning, then open Support → Help for the PDF index (filter by product + version). Match language and year to your install—Linux builds ship separate guide titles when published. Viewers and cloud tools (DWG FastView, GstarCAD 365) use different accounts from desktop seats; keep credentials straight before troubleshooting sync issues. Deeper LearnCAD mapping: vendor profile and software profiles.

ZWCAD / ZWSOFT — how to enter

Stay on the English Global support skin when possible. The ZWCAD Help Center aggregates FAQs, tutorials, and task articles; help.zwsoft.com exposes the full HTML help bundles with product and language selectors. For command-level lookup, the Functions & commands index is usually faster than guessing categories. ZW3D users should switch product context before searching—do not reuse ZWCAD-only paths.

Graebert — how to enter

Graebert maintains ARES branded help plus deep onlinehelp trees; OEM partners (DraftSight and others) sometimes skin the same core. Start from learn.graebert.com, then drop into onlinehelp for command-level topics. Help Center articles cover licensing and known issues—bookmark the exact ARES generation you deploy (service release matters for API behavior).

Bricsys / BricsCAD — how to enter

Bricsys combines a command encyclopedia with knowledge base entries on one subdomain—search works well if you paste exact command names. BIM vs Mechanical licenses expose different palettes; filter product mode before blaming “missing” tools. Released builds also publish changelog-style notes near downloads—pair them with Help Center entries when diagnosing regressions.

Nanosoft nanoCAD — how to enter

Pick your product line first on the Learning / Help Center chooser—plus, Mechanical, BIM, and platform builds diverge. On Windows, bundled PDF/HTML under \help remains authoritative when offline. The KB covers activation and interoperability; localized pages may duplicate English topics—prefer the newest revision date when both exist.
