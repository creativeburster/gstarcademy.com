GstarCAD C++ GRX, .NET & AutoLISP Developer 8-Week Path

Deep-dive 8-week software engineering curriculum for CAD plugin developers and ISVs. Master AutoLISP/Visual LISP, .NET C# managed APIs, native C++ GRX (ObjectARX equivalent), custom DbEntity classes, and dual-platform AutoCAD/GstarCAD compilation.

Curriculum Director: Gstarcademy Engineering Editorial Board Updated: 2026-10-12
Duration

8 weeks (8-10 hours / week)

Target Level

Advanced / Software Developer

Self-Assessment

Take CAD Quiz →

Prerequisites & Setup Requirements

Proficiency in C#, C++, or LISP programming and familiarity with DWG object models.

Structured Learning Progression (Stage by Stage)

Week 1: DWG Database Architecture & AutoLISP / Visual LISP Foundations

Stage 1

Core Topics Covered:

  • Understanding the DWG object hierarchy (`DbDatabase`, `BlockTable`, `BlockTableRecord`, `DBObject`)
  • Entity DXF group codes, selection sets (`ssget` filters), and `entget`/`entmod` manipulation
  • Visual LISP ActiveX/COM (`vlax-*`) functions and reactor callbacks (`vlr-object-reactor`)
  • Compiling encrypted `.vlx` / `.fas` distributions

🛠️ Practical Hands-on Assignment: Develop a Visual LISP reactor tool that automatically recalculates and updates a polyline room area label whenever a vertex is stretched.

Key Commands / Tools: VLIDE, APPLOAD, ENTGET, SSGET

Recommended Concepts: dwg-file-formatattributes-blocks

Week 2: GstarCAD .NET API (C#) Setup & Transaction Management

Stage 2

Core Topics Covered:

  • Setting up Visual Studio C# class library projects referencing `gmap.dll` and `gmdbmi.dll`
  • Command registration (`[CommandMethod]` attributes, session vs document context)
  • Database Transactions (`TransactionManager.StartTransaction()`, `GetObject`, `OpenMode.ForRead/ForWrite`)
  • Creating and appending native geometric entities to Model Space

🛠️ Practical Hands-on Assignment: Write a C# `.dll` plugin command that generates a parametric structural steel truss in Model Space within a single atomic Transaction.

Key Commands / Tools: NETLOAD, VISUALSTUDIO, TRANSACTION

Recommended Concepts: dwg-file-formatlayers-gstarcad

Week 3: Selection Filters, Jig Interactive Preview & XData / Extension Dictionaries

Stage 3

Core Topics Covered:

  • PromptSelectionOptions, `SelectionFilter`, and TypedValue DXF filter arrays
  • Implementing `EntityJig` and `DrawJig` for real-time dynamic cursor rubber-banding
  • Attaching custom application metadata via Extended Entity Data (`XData` / RegApps)
  • Storing complex structured data in `ExtensionDictionary` and `Xrecord` objects

🛠️ Practical Hands-on Assignment: Build an interactive C# `EntityJig` placement tool that attaches custom ERP part numbers and cost metadata to blocks via `Xrecord`.

Key Commands / Tools: NETLOAD, XDATA, XRECORD, ENTITYJIG

Recommended Concepts: attributes-blocksdynamic-blocks-autocad

Week 4: Dockable WPF Palettes, Ribbon UI API & Event Reactors

Stage 4

Core Topics Covered:

  • Hosting modern C# WPF UserControls inside GstarCAD `PaletteSet` dockable panels
  • MVVM data binding between WPF UI controls and active DWG Document transactions
  • Subscribing to `Database` and `DocumentCollection` events (`ObjectModified`, `CommandEnded`)
  • Programmatic Ribbon tab/button injection at startup (`IExtensionApplication.Initialize`)

🛠️ Practical Hands-on Assignment: Create a dockable WPF Property Inspector palette that live-displays and edits custom `Xrecord` attributes of selected CAD entities.

Key Commands / Tools: PALETTESET, WPF, IEXTENSIONAPPLICATION

Recommended Concepts: dwg-file-formatquality-assurance-cad

Week 5: Native C++ GRX SDK Architecture & ObjectARX Porting

Stage 5

Core Topics Covered:

  • Configuring C++17/20 MSVC toolsets with the GstarCAD GRX SDK headers and `.lib` imports
  • Entry point lifecycle (`acrxEntryPoint`, `kInitAppMsg`, `kUnloadAppMsg`)
  • Zero-overhead header aliasing (`AcDb` -> `GcDb`, `AcGe` -> `GcGe`, `AcEd` -> `GcEd`)
  • Smart pointers (`AcDbObjectPointer`), object IDs, and memory safety rules

🛠️ Practical Hands-on Assignment: Port an existing 5,000-line AutoCAD ObjectARX `.arx` C++ project to compile cleanly into a native 64-bit GstarCAD `.grx` binary.

Key Commands / Tools: ARX, APPLOAD, ACRXENTRYPOINT

Recommended Concepts: dwg-file-formatquality-assurance-cad

Week 6: Custom Entities (`AcDbEntity`), `worldDraw` & Custom Grips

Stage 6

Core Topics Covered:

  • Deriving custom database classes from `AcDbEntity` and `AcDbObject`
  • Implementing DWG/DXF filing persistence (`dwgInFields`, `dwgOutFields`, version tags)
  • Viewport-independent (`subWorldDraw`) and viewport-dependent (`subViewportDraw`) rendering
  • Custom grip points (`subGetGripPoints`, `subMoveGripPointsAt`) and custom Osnaps

🛠️ Practical Hands-on Assignment: Implement a custom C++ `GcDbPipeFitting` entity class with custom diamond grip handles and automatic 2D/3D representation switching.

Key Commands / Tools: ARX, WORLDDRAW, CUSTOMENTITY

Recommended Concepts: dwg-file-formatdynamic-blocks-autocad

Week 7: High-Performance Spatial Indexing & Multi-Threaded Compute

Stage 7

Core Topics Covered:

  • Using `AcGe` linear algebra, curve/surface intersection solvers, and spatial octrees
  • Handling 500,000+ entities without UI freezing via chunked transactions and `BlockTableRecord` iterators
  • Offloading heavy geometric calculations to background C++ worker threads safely
  • Interoperating between C++ `.grx` core engines and C# `.NET` UI wrappers via P/Invoke or C++/CLI

🛠️ Practical Hands-on Assignment: Write a C++ spatial clash detector that intersects 50,000 2D polylines in under 500 milliseconds using bounding-box R-tree pre-filtering.

Key Commands / Tools: ARX, ACGE, SPATIALINDEX

Recommended Concepts: dwg-audit-purge-drawing-recoveryquality-assurance-cad

Week 8: `.bundle` Autoloader Packaging, Code Signing & CI/CD Pipelines

Stage 8

Core Topics Covered:

  • Structuring cross-platform Application `.bundle` folders and `PackageContents.xml` manifests
  • Multi-targeting MSBuild configurations (`Debug_ACAD`, `Release_GCAD`) from a single Git repo
  • Authenticode digital signing of `.grx`/`.dll` binaries and automated regression testing
  • Building commercial MSI installers and licensing protection

🛠️ Practical Hands-on Assignment: Package your C++/.NET plugin into a universal `.bundle` directory with `PackageContents.xml` that auto-loads in both GstarCAD 2027 and AutoCAD.

Key Commands / Tools: PACKAGECONTENTS, MSBUILD, SIGNTOOL

Recommended Concepts: dwg-file-formatquality-assurance-cad

Capstone Graduation Portfolio Project

Dual-Platform Commercial CAD Plugin: Architect and compile a C#/.NET and C++ GRX plugin featuring a dockable WPF Palette, custom parametric database entities, automated Excel BOM synchronization, and a multi-version MSI installer supporting both AutoCAD and GstarCAD.
