Prerequisites & Setup Requirements

Structured Learning Progression (Stage by Stage)

Week 1: Interface Optimization & Core DWG Setup

Stage 1

Core Topics Covered:

  • GstarCAD workspace configuration (Ribbon vs Classic Interface)
  • Hardware graphics acceleration setup (GRAPHICSCONFIG)
  • Drawing setup (UNITS, LIMITS, Grid snap)
  • Quick Properties and heads-up dynamic cursor drafting

🛠️ Practical Hands-on Assignment: Draw an accurate structural anchor plate with counterbored holes and centerlines.

Key Commands / Tools: UNITS, GRAPHICSCONFIG, LINE, CIRCLE, RECTANG, DYNMODE

Recommended Concepts: gstarcad-system-requirementshow-to-migrate-autocad-to-gstarcad

Week 2: Precision 2D Construction & Layer Strategy

Stage 2

Core Topics Covered:

  • Object snap modes (Center, Quadrant, Tangent, Perpendicular)
  • Modify tools (Offset, Trim, Fillet, Chamfer, Mirror)
  • Layer management, color coding by lineweight, and layer filters
  • Design Center and Tool Palette integration

🛠️ Practical Hands-on Assignment: Draft a multi-room commercial layout with designated architectural, electrical, and furniture layers.

Key Commands / Tools: OFFSET, TRIM, EXTEND, FILLET, LAYER, ADCENTER, TOOLPALETTES

Recommended Concepts: layers-gstarcad

Week 3: Blocks, Dynamic Parameters & Quantity Takeoff

Stage 3

Core Topics Covered:

  • Block creation on Layer 0 with ByLayer attributes
  • Authoring Dynamic Blocks with visibility states and stretch actions
  • GstarCAD unique tools: Free Scale, Magnifier, and Barcode generator
  • Block data extraction to Excel / CSV tables

🛠️ Practical Hands-on Assignment: Create a dynamic electrical receptacle block with single/duplex/GFCI visibility states and extract component quantities.

Key Commands / Tools: BLOCK, WBLOCK, BEDIT, ATTDEF, EATTEXT, FREESCALE

Recommended Concepts: attributes-blocksdynamic-blocks-autocad

Week 4: Annotations, Tables & Multi-Sheet Plotting

Stage 4

Core Topics Covered:

  • Annotative text and dimension styles (Linear, Aligned, Radius)
  • Table creation and live mathematical spreadsheet formulas
  • Paper space layout viewports and scale locking
  • Batch Plotting multi-drawing DWG files to unified PDF packages

🛠️ Practical Hands-on Assignment: Publish an annotated manufacturing assembly drawing with balloon callouts and a linked BOM parts list.

Key Commands / Tools: DIMSTYLE, MTEXT, TABLE, MVIEW, PAGESETUP, BATCHPLOT

Recommended Concepts: annotative-objects-gstarcadhow-to-print-autocad

Week 5: AutoLISP Scripting & Enterprise Workflow Automation

Stage 5

Core Topics Covered:

  • AutoLISP syntax fundamentals (defun, setq, getpoint, command)
  • Loading custom LSP/VLX routines via APPLOAD and Startup Suite
  • Custom command aliases in gcad.pgp
  • Migrating legacy AutoCAD toolbars and menu macros to GstarCAD

🛠️ Practical Hands-on Assignment: Write a custom AutoLISP routine that automatically draws a standardized labeled rectangle with user-prompted length and width.

Key Commands / Tools: APPLOAD, VLIDE, ALIASEDIT, CUI, REINIT

Recommended Concepts: autolisp-gstarcadautolisp

Capstone Graduation Portfolio Project

Produce a complete industrial machinery foundation layout with dynamic components, bill of materials table, and automated LISP script routine.
