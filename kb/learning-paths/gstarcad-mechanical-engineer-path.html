Structured Learning Progression (Stage by Stage)

Week 1: Mechanical Standards Setup & Intelligent Layer Groups

Stage 1

Core Topics Covered:

  • Configuring ISO, DIN, JIS, ANSI, and GB drafting standards in GstarCAD Mechanical
  • Automatic mechanical layer management (AM_0 through AM_12 object routing)
  • Scale areas and multi-scale detail view containers in Model Space
  • Opening and round-tripping legacy AutoCAD Mechanical (ACM) drawings without proxy loss

🛠️ Practical Hands-on Assignment: Initialize a corporate ISO-standard mechanical template (.DWT) with automated contour, hidden, center, and dimension layer rules.

Key Commands / Tools: GMOPTIONS, GMLAYER, GMSCALEAREA, GM2DHIDE

Recommended Concepts: iso-128-technical-drawings-ruleslayers-gstarcaddwg-file-format

Week 2: Intelligent Hide Situations & Associative Centerlines

Stage 2

Core Topics Covered:

  • 2D Hide Situations (Foreground/Background component occlusion without trimming)
  • Automatic cross-hatching and associative hole/cylinder centerlines
  • Construction lines (C-Lines), symmetrical projection axes, and break symbols
  • Section lines and detail magnification callouts with automatic scale labels

🛠️ Practical Hands-on Assignment: Assemble an overlapping bearing housing cross-section using non-destructive 2D Hide rules and automated centerline arrays.

Key Commands / Tools: GM2DHIDE, GMCENTERLINE, GMCLINE, GMDETAIL

Recommended Concepts: annotative-scaling-model-paper-spaceiso-128-technical-drawings-rules

Week 3: Standard Parts Library (Fasteners, Bearings & Steel Profiles)

Stage 3

Core Topics Covered:

  • Inserting parametric ISO/DIN/ANSI bolts, nuts, washers, and pins
  • Screw connection assemblies with automatic through-hole and blind-tapped hole generation
  • Rolling bearings (radial, thrust, tapered roller) and circlip grooves
  • Structural steel shapes (I-beams, channels, angles) for machine frames

🛠️ Practical Hands-on Assignment: Build a bolted flange connection assembly with M12 hex socket head cap screws, spring washers, and radial shaft bearings.

Key Commands / Tools: GMSCREW, GMBEARING, GMSTEEL, GMPART

Recommended Concepts: dynamic-blocks-autocadattributes-blocks

Week 4: Power Dimensions, ISO Fits & GD&T Annotation

Stage 4

Core Topics Covered:

  • Power Dimensioning with embedded ISO 286 shaft/hole tolerance tables (e.g., H7/k6)
  • Multiple dimension arrangement (chain, baseline, ordinate alignment)
  • Feature Control Frames (GD&T per ASME Y14.5 / ISO 1101) and Datum targets
  • Surface texture symbols (ISO 1302 Ra/Rz) and welding symbols (ISO 2553)

🛠️ Practical Hands-on Assignment: Fully tolerance a precision spindle shaft with cylindrical runout, concentricity datums, and grinding surface finish callouts.

Key Commands / Tools: GMPOWERDIM, GMFCF, GMSURFSYM, GMWELDSYM, GMFITLIST

Recommended Concepts: iso-128-technical-drawings-rulesquality-assurance-cad

Week 5: Shaft, Gear, Spring & Cam Engineering Generators

Stage 5

Core Topics Covered:

  • Parametric Stepped Shaft Generator with keyways, thread reliefs, and undercuts
  • Involute Spur and Helical Gear pair design and profile generation
  • Compression, extension, and torsion spring drafting and calculation
  • Belt/chain drive layout and moment of inertia / deflection verification

🛠️ Practical Hands-on Assignment: Design a stepped transmission shaft with two gear seats, DIN 6885 keyways, and bearing journals.

Key Commands / Tools: GMSHAFT, GMGEAR, GMSPRING, EULERBUCKLING

Recommended Concepts: dwg-file-formatquality-assurance-cad

Week 6: Part References, Smart Balloons & Automated BOM Extraction

Stage 6

Core Topics Covered:

  • Creating and attaching Part References (metadata: Part Number, Material, Vendor, Mass)
  • Automatic Balloon placement, alignment, renumbering, and split-balloon callouts
  • Hierarchical BOM database management and Parts List table placement
  • Bi-directional Excel / ERP CSV synchronization and batch PDF publishing

🛠️ Practical Hands-on Assignment: Generate an itemized Parts List and aligned leader balloons for a 35-part pneumatic actuator assembly and export the BOM to Excel.

Key Commands / Tools: GMPARTREF, GMBALLOON, GMBOM, GMPARTSLIST, PUBLISH

Recommended Concepts: attributes-blockspaper-space-autocad

Capstone Graduation Portfolio Project

Complete Gearbox Sub-Assembly Package: Generate a multi-stage spur gear reducer assembly drawing using the built-in Shaft & Gear Generators, apply ISO 286 H7/g6 shaft-hole fits, place associative Part Reference balloons, and export a bi-directional Excel Bill of Materials.
