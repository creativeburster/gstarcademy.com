Capstone Project & Certification Milestones

Completing this structured learning track requires producing a portfolio-grade capstone project: create full 2D production drawings with standard GD&T tolerances, build parametric multi-body assemblies, and pass self-assessment evaluation checkpoints in our CAD Quiz system.

Industry certifications (Autodesk ACP, SOLIDWORKS CSWP, buildingSMART openBIM) provide verified third-party validation of your software capabilities when applying for corporate design and engineering roles.

Primary Standards & Official References: Verified against ASME Y14.5-2018 GD&T, ISO 1101 / STEP AP242, and GstarCAD Mechanical ACM Standards. Reviewed by Chen Haoran, M.Sc., GDTP-S (Testbed Specification).

12-Week Structured Engineering Syllabus & Capstone Deliverables

To transition from theoretical familiarity to accredited production competence in CATIA Beginner Learning Path, follow this week-by-week engineering syllabus developed by the GstarCAD Global Academy Curriculum Committee. Each phase culminates in a rigorous, standards-compliant Capstone Engineering Deliverable audited against ISO, ASME, and buildingSMART production criteria:

Training Sprint Core Technical Competencies Essential Commands & System Variables Mandatory Capstone Deliverable
Weeks 1–4
Foundation		 Precision coordinate geometry, ISO 13567 layer hierarchies, annotative scaling, and template (.dwt) governance. LAYER, LTSCALE, PSLTSCALE=1, MSLTSCALE=1, DIMASSOC=2, OSNAP, PEDIT, OVERKILL Produce a multi-viewport A1 production sheet set with 100% associative dimensions and monochrome CTB/STB plot compliance.
Weeks 5–8
Production		 Parametric block authoring, external reference (Xref) federation, associative BOM data extraction, and 3D solid/BIM coordination. BEDIT, XREF (Overlay), XCLIP, INDEXCTL=3, VISRETAIN=1, DATAEXTRACTION, IFCIMPORT Deliver a federated multi-discipline assembly/building package with live Excel BOM sync and zero unresolved Xrefs.
Weeks 9–12
Mastery & Automation		 Unattended batch publishing, AutoLISP / .NET / GRX workflow automation, QA/QC database auditing, and ISO/ASME tolerance verification. PUBLISH, SHEETSET, APPLOAD, AUDIT, RECOVER, -PURGE (Regapps), ETRANSMIT Write an automated QA/QC script that audits 50+ drawings and pass the official GstarCAD Skill Certification Exam.
