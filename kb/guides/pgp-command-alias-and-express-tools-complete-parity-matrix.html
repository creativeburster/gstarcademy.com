PGP Command Alias & Express Tools Complete Parity Matrix (AutoCAD vs GstarCAD)

Side-by-side mapping of default PGP keyboard shortcuts and Express Tools commands between AutoCAD and GstarCAD for zero-retraining migration.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Muscle memory is a CAD drafter's greatest asset. When migrating from AutoCAD to GstarCAD, engineers retain 99%+ of their keyboard shortcuts via gcad.pgp (direct equivalent of acad.pgp) and have immediate access to the full suite of Express Tools without separate plugin installers.

2. Step-by-Step Production Workflow & Command Modules

1. Core Drafting & Modification PGP Aliases

Every standard single-letter and two-letter alias is identical out of the box: L (LINE), PL (PLINE), C (CIRCLE), M (MOVE), CO/CP (COPY), RO (ROTATE), TR (TRIM), EX (EXTEND), F (FILLET), O (OFFSET), and MA (MATCHPROP).

2. Express Tools Parity (Blocks, Text, Layers & Layout)

GstarCAD natively bundles all high-frequency Express Tools: BURST (explode blocks while converting attributes to text), OVERKILL (delete duplicate geometry), TXTEXP (explode text to polylines), TCIRCLE (enclose text in slots/circles), LAYWALK, LAYMRG, and ALIGNSPACE.

3. Porting Custom acad.pgp Aliases in 10 Seconds

Copy the User Defined Command Aliases section at the bottom of your legacy acad.pgp into gcad.pgp and execute REINIT (check PGP File) to apply changes without restarting GstarCAD.

3. Command, Variable & Standard Reference Matrix

Command / Parameter Scope / Target Engineering Behavior & Best Practice

4. Automation Script & Reference Implementation (AutoLISP PGP Hot-Reload & Custom Alias Wrapper)

; Reload PGP file immediately and register custom shop aliases
(defun c:RELOAD-PGP ()
  (setvar "RE-INIT" 16) ; Bitcode 16 reloads PGP file immediately
  (princ "\n[GstarCAD] gcad.pgp reloaded into active session.")
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Append custom studio aliases to the bottom of gcad.pgp so software updates preserve them.
  • Run REINIT (or set RE-INIT = 16) after editing gcad.pgp to activate new shortcuts instantly.
  • Train drafters to use BURST instead of EXPLODE on attributed title blocks and tags.
