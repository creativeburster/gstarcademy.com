1. What Are Custom ObjectARX Proxy Entities (`AcDbProxyEntity`)?

When a drawing is authored in vertical applications such as AutoCAD Civil 3D (`AeccDbSurfaceTin`, `AeccDbAlignment`), AutoCAD MEP, or Plant 3D, those programs write custom C++ class instances into the DWG database. When the DWG file is opened in any CAD environment where the originating vertical C++ DLL is absent, the DWG kernel wraps the unknown binary stream inside an AcDbProxyEntity (Proxy / Zombie Object).

Whether those custom objects render with full visual fidelity or appear as empty wireframe bounding boxes in GstarCAD 2027 depends entirely on whether the sender saved the drawing with embedded Proxy Graphics.

2. Controlling Proxy Visibility & Display Variables in GstarCAD 2027

System Variable Recommended Setting Database & Viewport Effect
PROXYGRAPHICS 1 (Must be set by Sender on Save) Embeds full 2D/3D vector display primitives inside the DWG file so GstarCAD renders exact contours and labels.
PROXYSHOW 1 (Display Graphics) 0 hides proxies; 1 displays full embedded graphics; 2 displays only bounding boxes.
PROXYNOTICE 0 (In Batch Scripts) / 1 (Audit) Controls whether the Proxy Information dialog pops up when opening files with custom AEC/Civil objects.

3. Converting Locked Proxy Entities into Editable Native Geometry

If your engineering team needs to edit, trim, or snap to Civil 3D contours or AEC walls inside GstarCAD 2027:

  1. Upstream `EXPORTTOAUTOCAD` (`-AECTOACAD`): Instruct the upstream Civil 3D or MEP consultant to run `-EXPORTTOAUTOCAD` before transmittal, which decomposes `AeccDb*` objects into native 2D/3D polylines, blocks, and MTEXT with zero visual shift.
  2. Open LandXML 1.2 / IFC 4.3 Exchange: For civil alignments, profiles, and TIN surfaces, request a lightweight LandXML (`.xml`) export alongside the DWG—preserving exact mathematical clothoid spirals and elevation triangles.
  3. Diagnostic LISP Scanner for Hidden Proxy Bloat: Run the following AutoLISP routine in GstarCAD 2027 to inventory all proxy entity classes inside a sluggish subcontractor drawing:
;; GstarCAD 2027 — Audit & Inventory Custom Proxy Entities in Active DWG
(defun c:GCAD_AUDIT_PROXIES ( / ss i ent dxf proxyCount)
  (setq ss (ssget "_X" '((0 . "ACAD_PROXY_ENTITY"))))
  (if ss
    (progn
      (setq proxyCount (sslength ss))
      (princ (strcat "\n[Proxy Audit] Found " (itoa proxyCount) " graphical proxy entities in drawing."))
      (setvar "PROXYSHOW" 1)
    )
    (princ "\n[Proxy Audit] Clean DWG! Zero graphical proxy entities detected.")
  )
  (princ)
)

4. Selective Proxy Explode vs. Round-Trip Preservation Strategy

A critical architectural distinction must be maintained between consuming an external civil/MEP consultant's drawing as a background coordination Xref versus destructively exploding proxy entities:

Coordination Scenario Recommended GstarCAD 2027 Workflow Impact on Custom C++ Object Streams
Round-Trip Consultant DWG (You edit annotations/layers and return the file to a Civil 3D user) Keep PROXYGRAPHICS = 1 and PROXYSHOW = 1. Do not run EXPLODE on proxy objects. 100% lossless preservation. When reopened in Civil 3D, dynamic TIN surfaces, pipe networks, and alignments remain fully parametric.
Background Xref Underlay (Architectural/Structural coordination over Civil site plan) Attach via XREF (Overlay). Use LAYISO / viewport layer overrides (`VP Color`) on proxy sub-layers. Zero modification to consultant file; full `OSNAP` endpoint/intersection snapping to cached proxy graphics streams.
Archival Deliverable Handover (Contract requires pure vanilla 2D DWG with zero third-party dependencies) Save a detached copy (`SAVEAS`), select proxy objects via `QSELECT` (`Object Type = ACAD_PROXY_ENTITY`), and run `EXPLODE`. Converts cached `worldDraw()` graphics into native `AcDbPolyline`, `AcDbLine`, and `AcDbMText` primitives and purges custom class dictionaries.

Inspecting Registered Application Weight: When third-party vertical applications create proxy entities, they frequently attach thousands of Registered Application IDs (`AcDbRegAppTableRecord`) and Extended Entity Data (`XDATA`). Running `-PURGE → Regapps` in GstarCAD 2027 safely strips orphaned `RegApp` records that have zero active entity bindings without harming live proxy objects.
