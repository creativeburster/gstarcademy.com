GstarCAD 365 Enterprise Cloud CDE: Role-Based Access Control, Revision Versioning & Cross-Terminal Sync

Deploy GstarCAD 365 as an ISO 19650-aligned Common Data Environment (CDE) connecting desktop GstarCAD 2027, web browsers, and mobile DWG FastView field teams.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-10-26 Editorial Process

1. Eliminating Chaotic Email Attachments with a Unified DWG Cloud CDE

Exchanging `FloorPlan_Final_v3_RevB_John.dwg` over email or consumer chat apps inevitably causes construction contractors to build from outdated drawings. GstarCAD 365 provides an enterprise-grade, cloud-enabled Common Data Environment (CDE) that unites three terminals onto a single authoritative DWG data source: GstarCAD 2027 Desktop (for heavy authoring), GstarCAD Web (zero-install browser viewing/markup), and DWG FastView Mobile (for jobsite inspection).

2. Role-Based Permission Matrix & ISO 19650 Folder States

Project Role GstarCAD 365 Permission Tier Permitted DWG Actions & Security Boundary
Lead Discipline Engineers Read / Write / Check-In / Lock Full desktop DWG editing, Xref binding, and version promotion from WIP to Shared.
Site Superintendents & QA View + Measure + Cloud Markup Only Can measure coordinates and post redline clouds/photos; cannot alter base DWG geometry.
External Bidding Vendors Time-Limited Read-Only Link (No Download) Browser-only viewing with expiration timestamp and password protection; blocks raw DWG file download.

3. Immutable Version History & Instant Visual Revision Rollback

Every time an engineer saves and checks a drawing into GstarCAD 365, the cloud storage engine records an immutable version snapshot (`V1`, `V2`, `V3`...) with author timestamp and commit notes. Project managers can select any two historical snapshots directly in the cloud portal and invoke Cloud DWG Compare to audit exact geometric changes before approving the drawing for construction issue.

4. On-Premises Private Cloud Deployment & REST Webhook Integration

For defense contractors, state power grids, semiconductor fabs, and municipal water authorities operating under strict data-sovereignty regulations, **GstarCAD 365 Enterprise** can be deployed as a 100% air-gapped **Private Cloud container cluster** (Docker / Kubernetes on internal Linux servers backed by PostgreSQL + MinIO/Ceph object storage) or as a hybrid cloud tenant.

Project managers can also bind GstarCAD 365 CDE lifecycle events (`File.Uploaded`, `Markup.Created`, `Container.PromotedToPublished`) to internal ERP, DingTalk, Microsoft Teams, or Jira workflows via signed HTTPS webhooks:
