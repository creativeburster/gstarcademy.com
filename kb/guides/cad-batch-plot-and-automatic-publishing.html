Enterprise CAD Batch Plot, Multi-Frame Smart Plotting & Automated PDF Publishing

Eliminate manual sheet-by-sheet printing: master GstarCAD Smart Batch Plot (BP), multi-frame model space border recognition, Sheet Set Manager (SSM) publishing, and searchable vector PDFs.

By Gstarcademy Editorial Team Updated 2026-10-12 Editorial process

1. Solving the Multi-Frame Model Space Plotting Bottleneck

While textbook CAD standards advocate placing one title block per Paper Space layout tab, real-world engineering subcontractors across Asia, Europe, and manufacturing sectors routinely arrange 20 to 100 drawing borders inside a single Model Space (or a single Layout) at varying scales. Printing these manually requires selecting 100 individual windows. GstarCAD's **Batch Plot (`BP` / `BATCHPLOT`)** engine automatically recognizes multiple title block frames by Block Name, Layer, or Closed Rectangle and publishes them into a single bookmarked PDF or individual sheet files.

2. Step-by-Step: Configuring Smart Frame Recognition in Batch Plot

Launch `BATCHPLOT` (`BP`), choose how your title blocks are structured (Block Reference, Layer, or Closed Polyline), and pick a sample border in the drawing. GstarCAD scans the entire coordinate space, identifies all matching frames regardless of scale (e.g., mixing 1:100 A1 sheets with 1:50 A3 details), sorts them in Left-to-Right / Top-to-Bottom reading order, and maps each frame to its optimal paper size automatically.

3. Automated File Naming from Title Block Attributes

Instead of manually renaming `Sheet_01.pdf`, `Sheet_02.pdf`, configure Batch Plot's attribute extraction rule to read the `DWG_NO`, `SHEET_TITLE`, and `REV` tags directly from each title block's attributes—automatically outputting ISO-compliant filenames such as `A-101-Ground_Floor_Plan-Rev02.pdf`.

4. Ensuring Searchable TrueType Text and Layer Trees in PDF Output

To ensure downstream estimators using Bluebeam Revu or Adobe Acrobat can search text strings and toggle CAD layers, enable 'Capture TrueType fonts as text' and 'Include layer information' in the PC3 PDF driver properties, and avoid substituting SHX simplex fonts where searchable text is contractually required.
