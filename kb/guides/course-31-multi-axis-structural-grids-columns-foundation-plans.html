Course 31: Multi-Axis Structural Grids, Custom Column Schedules & Foundation Plans

Build orthogonal and radial structural axis grids, auto-dimensioned column layouts, and pad/pile foundation plans in GstarCAD Architecture 2027.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Every architectural and structural project begins with the **Structural Axis Grid (`AXISGRID`)** and **Column Layout (`COLUMN`)**. In GstarCAD Architecture 2027, structural grids are intelligent parametric AEC objects rather than loose dash-dot lines and static circles: stretching a bay spacing automatically updates the two-tier overall and bay-by-bay dimension strings (`AXISDIM`), re-sequences axis bubbles (`1, 2, 3...` and `A, B, C...` skipping `I, O, Z` per ISO/GB rules), and shifts grid-anchored structural columns in lockstep.

2. Step-by-Step Production Workflow & Command Modules

Module 1: Generating Orthogonal & Radial Structural Grids (`RECTGRID` & `ARCGRID`)

Launch AXISGRID, enter bay spacing pairs in the dialog (e.g., `3x7200, 4500, 3x7200` along X and `6600, 2700, 6600` along Y), and insert the grid at `0,0,0`. For curved stadium concourses or podium wings, switch to **Arc/Radial Grid** to combine radial angle steps (`15° x 6`) with concentric ring radii.

Module 2: Two-Tier Axis Dimensioning & Bubble Renumbering (`AXISDIM` & `AXISNUM`)

Run AXISDIM and click the four outer sides of the grid. GstarCAD Architecture generates both the inner bay-to-bay chain dimensions and the outer total building envelope dimension, automatically attaching `1, 2, 3...` and `A, B, C...` axis bubbles (`I`, `O`, and `Z` are automatically excluded to prevent confusion with `1`, `0`, and `2`).

Module 3: Batch-Placing Reinforced Concrete & Steel Columns (`STDCLN`) at Grid Intersections

Run STDCLN (Standard Column), choose a rectangular RC section (`600x600`), circular pier (`Ø800`), or H-steel profile (`HW 400x400`), and window-select the entire axis grid to populate columns at every intersection simultaneously. Wall segments intersecting a column automatically clean up (`T-join`/`L-join`) around the structural core.

3. Command, Variable & Standard Reference Matrix

Command / Parameter Scope / Target Engineering Behavior & Best Practice
AXISGRID / RECTGRID Parametric Axis System Creates orthogonal or radial structural bay grids from bay-spacing arrays.
AXISDIM / AXISNUM Two-Tier Grid Dimensioning Places bay chain + overall dimensions and auto-increments bubble tags (skipping I, O, Z).
STDCLN / CRNCLN Grid-Bound Columns Places RC or steel columns at grid intersections with automatic wall-core cleanup.
BASEPLAN Foundation Generation Projects column loads to generate isolated pad footings, strip beams, or pile caps.

5. Production QA Verification & Competency Checklist

  • Ensure axis bubble numbering automatically skips uppercase **`I`, `O`, and `Z`** per ISO/BS/GB architectural drafting conventions.
  • Place the primary project benchmark intersection (`Axis 1` × `Axis A`) exactly at WCS `0,0,0` so upper-floor Xrefs and MEP models align without offset drift.
  • Verify that multi-ply architectural walls intersecting structural columns clean up around the structural core while preserving exterior thermal insulation continuity.

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

In multi-office engineering environments operating across GstarCAD 2027, GstarCAD Mechanical, GstarCAD Architecture, and legacy AutoCAD (2018–2027) seats, mastering Course 31: Multi-Axis Structural Grids, Custom Column Schedules & Foundation Plans requires understanding how the underlying AC1032 DWG binary database serializes entity handles, symbol table records, and Named Object Dictionary (NOD) pointers.

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
  3. Submittal Packaging & Mobile Review: Lock all Paper Space viewports (`DisplayLocked = Yes`), bind or relative-path all external references via ETRANSMIT, and verify final plotted PDF/A lineweights (`ISO full bleed`) alongside DWG FastView mobile cloud markup links.
