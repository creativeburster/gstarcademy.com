Structural Steel Profiles (EN HEA/HEB/IPE vs. ASTM AISC W-Shapes) CAD Guide

Structural steel cross-section geometry guide covering European EN 10365 (IPE, HEA, HEB, UNP) and American AISC (W, C, HSS, L) profiles with exact flange/web/fillet drafting dimensions.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Structural steel detailing in GstarCAD requires accurate cross-sectional geometry—especially the root fillet radius ($r$) and flange thickness ($t_f$)—to verify bolt gauge clearances, stiffener plates, and beam-to-column welded connections across both European EN 10365 (IPE / HEA / HEB) and American AISC (W-Shapes).

2. Step-by-Step Production Workflow & Command Modules

1. European Wide-Flange & I-Beam Series (IPE vs. HEA vs. HEB)

European structural steel uses parallel-flange metric profiles:

  • IPE (e.g., IPE 300: depth $h=300\text{ mm}$, width $b=150\text{ mm}$): Narrower flanges optimized for bending as secondary floor beams and purlins.
  • HEA (light) & HEB (standard, e.g., HEB 300: $h=300\text{ mm}, b=300\text{ mm}$): Wide square H-sections with high weak-axis moment of inertia $I_z$ for columns and heavy girders.

2. American AISC W-Shapes (Nominal Depth x Weight in lb/ft)

An AISC designation like W14x90 indicates a Wide-Flange section with a nominal depth of $14\text{ in}$ ($d = 14.02\text{ in} / 356\text{ mm}$) and a linear mass of $90\text{ lb/ft}$ ($134\text{ kg/m}$). Always look up the exact decimal depth $d$ and k-distance (outer flange face to web toe of fillet) before detailing clip angles.

4. Automation Script & Reference Implementation (AutoLISP Parametric Structural I/H-Beam Section Generator (IPE/HEB/W))

(defun c:DRAW-IBEAM ( / pt h b tw tf x0 y0)
  (setq pt (getpoint "\nPick Beam Centroid Insertion Point: ")
        h  (getreal "\nEnter Total Depth h (mm, e.g. 300): ")
        b  (getreal "\nEnter Flange Width b (mm, e.g. 150): ")
        tw (getreal "\nEnter Web Thickness tw (mm, e.g. 7.1): ")
        tf (getreal "\nEnter Flange Thickness tf (mm, e.g. 10.7): "))
  (setq x0 (car pt) y0 (cadr pt))
  (command "_.PLINE"
    (list (- x0 (* 0.5 b)) (- y0 (* 0.5 h)))
    (list (+ x0 (* 0.5 b)) (- y0 (* 0.5 h)))
    (list (+ x0 (* 0.5 b)) (+ (- y0 (* 0.5 h)) tf))
    (list (+ x0 (* 0.5 tw)) (+ (- y0 (* 0.5 h)) tf))
    (list (+ x0 (* 0.5 tw)) (- (+ y0 (* 0.5 h)) tf))
    (list (+ x0 (* 0.5 b)) (- (+ y0 (* 0.5 h)) tf))
    (list (+ x0 (* 0.5 b)) (+ y0 (* 0.5 h)))
    (list (- x0 (* 0.5 b)) (+ y0 (* 0.5 h)))
    (list (- x0 (* 0.5 b)) (- (+ y0 (* 0.5 h)) tf))
    (list (- x0 (* 0.5 tw)) (- (+ y0 (* 0.5 h)) tf))
    (list (- x0 (* 0.5 tw)) (+ (- y0 (* 0.5 h)) tf))
    (list (- x0 (* 0.5 b)) (+ (- y0 (* 0.5 h)) tf)) "_C")
  (princ "\n[Structural Steel] Parametric I/H section generated.")
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Always include the root fillet radius r (or AISC k-dimension) when checking whether stiffener plates or bolt washers clear the web-flange transition.
  • Remember that HEA 300 has an actual depth h = 290 mm, whereas HEB 300 has h = 300 mm.
  • Place structural steel profiles on dedicated S-COLS or S-BEAM layers with centroid reference points.

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

In multi-office engineering environments operating across GstarCAD 2027, GstarCAD Mechanical, GstarCAD Architecture, and legacy AutoCAD (2018–2027) seats, mastering Structural Steel Profiles (EN HEA/HEB/IPE vs. ASTM AISC W-Shapes) CAD Guide requires understanding how the underlying AC1032 DWG binary database serializes entity handles, symbol table records, and Named Object Dictionary (NOD) pointers.

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
  3. Submittal Packaging & Mobile Review: Lock all Paper Space viewports (`DisplayLocked = Yes`), bind or relative-path all external references via ETRANSMIT, and verify final plotted PDF/A lineweights (`ISO full bleed`) alongside DWG FastView mobile cloud markup links.
