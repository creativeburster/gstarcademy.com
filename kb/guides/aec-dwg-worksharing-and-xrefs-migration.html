AEC DWG Worksharing, External References (Xrefs), and Sheet Sets

Managing multi-discipline architectural and engineering drawing packages in GstarCAD: relative Xrefs, layer overrides, clipping boundaries, and Sheet Set Manager (.DST).

By Gstarcademy Editorial Team Updated 2026-09-30 Editorial process

1. High-Performance Multi-Discipline External References

Commercial architectural design packages often involve 20+ linked DWG files (architectural floor plans, structural framing, HVAC ducting, plumbing, and electrical grids). GstarCAD's XREF manager provides identical hierarchical and nested reference support:

  • Relative Path Preservation: Moving project folders between local servers or cloud storage (OneDrive/Dropbox) preserves cross-drawing linkages without broken paths.
  • XCLIP Boundaries: Non-rectangular polygonal clipping boundaries with inverted clip masking calculate instantly.
  • Viewport Layer Overrides: Color, linetype, and transparency overrides configured in specific paper space viewports match AutoCAD exactly.

2. Sheet Set Manager (.DST) Interoperability

Large building permits rely on .dst Sheet Set files to organize hundreds of sheets, automated sheet numbering, and title block field population. GstarCAD provides full bi-directional reading, editing, and publishing of AutoCAD .dst databases:

  1. Open the Sheet Set Manager (SSM command).
  2. Load existing corporate .dst project sets without conversion.
  3. Trigger automated multi-sheet batch plotting to multi-page PDF with layer indexing enabled.
  4. Generate one-click eTransmit packages with all external fonts, xrefs, and plot styles bundled.

3. Sheet Set Manager (DST) Enterprise Publishing

Collaborative multi-discipline architectural delivery relies on unified Sheet Set Manager (.dst) databases:

  • Centralized Project Fields: Updating the project title, revision date, or issue code in the Sheet Set Manager automatically synchronizes across 100+ drawing layout title blocks.
  • Automated Sheet Indexing: Dynamic callout blocks and automated sheet lists compile drawing deliverable tables without manual data entry.
  • Batch PDF Publishing: Background publishing outputs multi-page, searchable vector PDF sets with layer structures preserved for contractor review.

4. Network Storage Latency & Reference Governance

When hosting DWG files on shared enterprise NAS or cloud drives: enforce 'Overlay' instead of 'Attach' to eliminate recursive reference loops; standardize relative path mappings (.\Xrefs\) rather than absolute drive letters; and schedule weekly automated scripts to audit and purge unregistered application dictionaries (RegApps) from all referenced base drawings.
