Course 11: GstarCAD Architecture — Structural Column Grids, Multi-Leaf Cavity Walls & Associative Openings

Construct parametric architectural column grids, multi-layer insulated cavity walls with automatic T/L intersection healing, and associative doors/windows with real-time 2D/3D synchronization.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Dr. Lin Wei, Ph.D., PE (Chief BIM & OpenBIM Interoperability Architect) Key Commands: AXISGRID, WALL, DOOR, WINDOW, WALLJOIN Last reviewed 2026-10-19 Editorial Process & Testbed

Course Technical Scope & Production Competencies

Drafting architectural floor plans with primitive parallel lines and manual trim/fillet commands turns every wall-thickness change or window relocation into tedious manual surgery. GstarCAD Architecture 2027 introduces intelligent, object-oriented AEC entities (Walls, Axes, Doors, Windows, Columns) that display simultaneously as 2D construction plan symbols and 3D volumetric models.

  • Generate orthogonal and radial structural axis grids (AXISGRID) with automated multi-bubble dimension chains (AXISDIM) and live column insertion (COLUMN) at grid intersections.
  • Draw multi-ply composite thermal walls (WALL) with prioritized layer cleanup (brick veneer, rigid insulation, concrete core, gypsum board) that self-heal T-junctions and L-corners automatically.
  • Insert parametric Doors (DOOR) and Windows (WINDOW) equipped with intelligent wall-opening boolean cutouts, swing direction grips, and configurable sill/lintel plan representations.

Module 1: GstarCAD Architecture: Multi-Axis Structural Grids, Composite Walls & Parametric Openings

In GstarCAD Architecture, architectural walls are custom parametric objects derived from the AEC entity database. Each wall style defines multiple component plies with specific priority indices (from 1 for structural reinforced concrete cores down to 5 for interior plaster finishes). When a partition wall intersects an exterior load-bearing wall, the engine automatically trims the plaster and insulation layers while fusing the structural cores cleanly.

Similarly, doors and windows maintain a topological host-child relationship with their parent wall: dragging a window along a wall or changing its width in the Properties palette heals the masonry opening and updates its associative Window Tag (`DOORWINTAG`) in real time.

Module 2: Step-by-Step Hands-On Command Execution Lab

Follow this structured 4-step laboratory procedure directly at the GstarCAD command line or dynamic input prompt:

  1. Step 1 — Environment & System Variable Initialization: At the command prompt, verify the active state of core commands and variables: AXISGRID, WALL, DOOR, WINDOW, WALLJOIN. Ensure that object snap bitcodes (OSMODE=175), associative dimensioning (DIMASSOC=2), and multi-core display regeneration (WHIPTHREAD=3) are active.
  2. Step 2 — Primary Geometry & Metadata Authoring: Execute the primary workflow on standardized ISO 13567 or discipline-specific layers. Never place production geometry or block definitions on Defpoints, and keep internal block geometry on Layer 0 so instances inherit host layer properties dynamically.
  3. Step 3 — Associative Verification & Revision Auditing: Test parametric associativity by stretching or modifying parent geometry and confirming that linked dimensions, attributes, schedules, or section views update automatically without disassociation warnings (ANNOMONITOR=2).
  4. Step 4 — Pre-Transmittal Quality Assurance (QA/QC): Prior to saving or publishing the deliverable, run OVERKILL to eliminate duplicate vectors, -PURGE (RegApps and All) to strip orphaned symbol table bloat, and AUDIT to verify 100% AcDbObject handle integrity.
