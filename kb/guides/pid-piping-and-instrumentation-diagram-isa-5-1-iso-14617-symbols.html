P&ID Piping and Instrumentation Diagram Symbols (ISA-5.1 & ISO 14617) CAD Guide

Complete engineering reference for P&ID tag identification letters (FT, FIC, PCV, PSV), instrument bubble styles, signal line types, and valve block libraries in GstarCAD.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

A Piping and Instrumentation Diagram (P&ID) is the master functional contract for process plants, refineries, and water treatment facilities. Governed by ANSI/ISA-5.1 and ISO 14617 / ISO 10628, every valve, pump, vessel, and control loop tag in GstarCAD follows a strict functional identification schema.

2. Step-by-Step Production Workflow & Command Modules

1. ISA-5.1 Instrument Tag Identification Letters (First Letter + Succeeding Letters)

An instrument bubble tag consists of a Measured/Initiating Variable (First Letter) followed by Readout/Output Functions and a Loop Number:

  • F = Flow, P = Pressure, T = Temperature, L = Level, A = Analysis.
  • I = Indicate, T = Transmit, C = Control, V = Valve, SH/SL = Switch High/Low, PSV = Pressure Safety Valve.

2. Instrument Bubble Montage & Location Lines

A plain circle indicates a Field-Mounted instrument; a circle with a single horizontal solid line through the center indicates a Main Control Room (DCS/PLC Panel) accessible display; a dashed horizontal line indicates an instrument behind the panel or inaccessible to the operator.

3. Process Signal Linetypes & Attributed P&ID Blocks in GstarCAD

Major process pipelines use heavy solid lines (0.50 mm); pneumatic signals use double-slashed lines; electrical/4–20mA signals use dashed lines; software/DCS data links use line-circle-line patterns. Store your valves and instrument bubbles as attributed blocks with TAG_ID and LINE_SIZE attributes for instant DATAEXTRACTION to Instrument Index spreadsheets.

3. Command, Variable & Standard Reference Matrix

Command / Parameter Scope / Target Engineering Behavior & Best Practice
FT / FE / FIC Flow Flow Transmitter / Flow Element / Flow Indicating Controller — 4-20mA or HART loop
PT / PI / PSV Pressure Pressure Transmitter / Local Gauge / Pressure Safety Relief Valve — Field & relief header
LT / LIC / LSHH Level Level Transmitter / Level Controller / High-High Level Switch — Tank & vessel protection
TT / TE / TIC Temperature Temperature Transmitter / Thermowell Element / Controller — RTD / Thermocouple loop
FCV / PCV / XV Final Control Flow Control Valve / Pressure Control Valve / On-Off Solenoid Valve — Pneumatic or motorized actuator

4. Automation Script & Reference Implementation (AutoLISP P&ID Instrument Bubble & Tag Generator)

(defun c:PID-BUBBLE ( / pt fn loop)
  (setq pt   (getpoint "\nPick Instrument Bubble Center: ")
        fn   (getstring "\nEnter Function Letters (e.g. FIT, PCV, LIC): ")
        loop (getstring "\nEnter Loop Number (e.g. 101A): "))
  (command "_.CIRCLE" pt 6.0)
  (command "_.LINE" ( polar pt pi 6.0) (polar pt 0.0 6.0) "")
  (command "_.TEXT" "_J" "_MC" (polar pt (* 0.5 pi) 2.2) 2.5 0.0 (strcase fn))
  (command "_.TEXT" "_J" "_MC" (polar pt (* 1.5 pi) 2.2) 2.5 0.0 (strcase loop))
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Keep P&ID schematics non-scale and orthogonal, maintaining at least 10 mm clearance between parallel process lines.
  • Break vertical lines when crossing horizontal process lines (or use automatic gap loops) while keeping main process headers continuous.
  • Embed TAG_ID and LOOP_NUM as block attributes so DATAEXTRACTION can generate the plant Instrument Index automatically.

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

In multi-office engineering environments operating across GstarCAD 2027, GstarCAD Mechanical, GstarCAD Architecture, and legacy AutoCAD (2018–2027) seats, mastering P&ID Piping and Instrumentation Diagram Symbols (ISA-5.1 & ISO 14617) CAD Guide requires understanding how the underlying AC1032 DWG binary database serializes entity handles, symbol table records, and Named Object Dictionary (NOD) pointers.

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
  3. Submittal Packaging & Mobile Review: Lock all Paper Space viewports (`DisplayLocked = Yes`), bind or relative-path all external references via ETRANSMIT, and verify final plotted PDF/A lineweights (`ISO full bleed`) alongside DWG FastView mobile cloud markup links.
