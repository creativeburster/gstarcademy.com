GstarCAD .NET API Quickstart: Custom Commands & Entity Jigs in C#

Learn modern CAD customization using C# and .NET API: writing custom command methods, handling transactions, modifying block tables, and implementing dynamic EntityJig drag previews.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-09-30 Editorial Process

1. Overview of GstarCAD Managed .NET API

While C++ GRX provides maximum raw performance, modern enterprise line-of-business CAD automation is overwhelmingly written in C# (.NET) due to rapid UI development, robust memory management, and seamless integration with corporate databases, cloud APIs, and WPF.

GstarCAD exposes managed wrapper assemblies matching the standard AutoCAD .NET API model:

  • GcadData.dll (Equivalent to AcDbMgd.dll) — Database, entities, tables, transactions.
  • GcadDbMgd.dll (Equivalent to AcCoreMgd.dll) — Command runtime, document manager, editor interaction.

2. Writing a Transaction-Safe Custom Entity Generator

The following production C# snippet demonstrates opening a document transaction, creating a new Circle entity with custom properties, and appending it to Model Space:

using System;
using GstarCAD.ApplicationServices;
using GstarCAD.DatabaseServices;
using GstarCAD.EditorInput;
using GstarCAD.Geometry;
using GstarCAD.Runtime;

namespace EnterpriseCadTools
{
    public class CircleCommands
    {
        [CommandMethod("DRAW_PIPE_FLANGE")]
        public void DrawPipeFlange()
        {
            Document doc = Application.DocumentManager.MdiActiveDocument;
            Database db = doc.Database;
            Editor ed = doc.Editor;

            PromptPointResult ptRes = ed.GetPoint("\nSelect flange center point: ");
            if (ptRes.Status != PromptStatus.OK) return;

            using (Transaction tr = db.TransactionManager.StartTransaction())
            {
                BlockTable bt = tr.GetObject(db.BlockTableId, OpenMode.ForRead) as BlockTable;
                BlockTableRecord btr = tr.GetObject(bt[BlockTableRecord.ModelSpace], OpenMode.ForWrite) as BlockTableRecord;

                Circle circle = new Circle(ptRes.Value, Vector3d.ZAxis, 150.0);
                circle.ColorIndex = 1; // Red

                btr.AppendEntity(circle);
                tr.AddNewlyCreatedDBObject(circle, true);

                tr.Commit();
                ed.WriteMessage("\nFlange outline generated successfully.");
            }
        }
    }
}

  • Gate 1 — Bidirectional DWG & Neutral Schema Verification: Test round-trip saving between GstarCAD 2027 (AC1032 DWG 2018+ binary format), AutoCAD, and downstream BIM/CAM platforms. Confirm that custom proxy entities (PROXYGRAPHICS = 1), associative dimensions (DIMASSOC = 2), and multiline attributes retain exact geometric fidelity.
