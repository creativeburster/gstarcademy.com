Course 14: Scan-to-CAD & Heritage Renovation — Processing LiDAR Point Clouds (.RCP/.E57/.LAS) in GstarCAD

Import terrestrial laser scanning (TLS) point clouds into GstarCAD Point Cloud, slice horizontal/vertical clipping boxes, and snap accurate 2D/3D as-built architectural floor plans.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Key Commands: POINTCLOUDATTACH, POINTCLOUDCLIP, UCS, PLAN,PDFIMPORT Last reviewed 2026-10-19 Editorial Process

Course Technical Scope & Production Competencies

Renovating historic heritage buildings or retrofitting brownfield industrial piping plants using outdated 1980s paper blueprints leads to severe field clashes. Course 14 trains surveyors and retrofit engineers to process billions of terrestrial LiDAR laser scan points directly inside GstarCAD Point Cloud.

  • Index raw terrestrial and drone photogrammetry scan archives (.e57, .las, .laz, .rcp/.rcs, .pts) into high-speed octree structures capable of rendering 500+ million points at 60 FPS.
  • Manipulate the interactive Clipping Box and Horizontal/Vertical Section Slicers (10mm–50mm slice thickness) with RGB, Intensity, and Z-Elevation color-ramp shaders.
  • Utilize automated feature-extraction snapping to trace true as-built 2D floor plans (including plumb/bowed wall deviations), Heritage facade elevations, and 3D structural steel centrelines.

Module 1: GstarCAD Point Cloud (Undet Engine): LiDAR E57/LAS Indexing, Dynamic Slicing & As-Built Vectorization

Loading an unindexed 40GB terrestrial laser scan directly into a standard CAD viewport exhausts workstation RAM instantly. GstarCAD Point Cloud integrates the specialized Undet voxel-octree indexing engine: only the point density visible within the current camera frustum and clipping slice is streamed into GPU VRAM, keeping memory overhead flat while preserving sub-millimeter coordinate accuracy.

By toggling between Intensity Coloring (which highlights reflective differences between mortar joints, steel flanges, and painted drywall) and Plane Deviation Coloring, drafters snap 2D polylines and parametric walls directly to the physical reality of the site.

Module 2: Step-by-Step Hands-On Command Execution Lab

Follow this structured 4-step laboratory procedure directly at the GstarCAD command line or dynamic input prompt:

  1. Step 1 — Environment & System Variable Initialization: At the command prompt, verify the active state of core commands and variables: POINTCLOUDATTACH, POINTCLOUDCLIP, UCS, PLAN,PDFIMPORT. Ensure that object snap bitcodes (OSMODE=175), associative dimensioning (DIMASSOC=2), and multi-core display regeneration (WHIPTHREAD=3) are active.
  2. Step 2 — Primary Geometry & Metadata Authoring: Execute the primary workflow on standardized ISO 13567 or discipline-specific layers. Never place production geometry or block definitions on Defpoints, and keep internal block geometry on Layer 0 so instances inherit host layer properties dynamically.
  3. Step 3 — Associative Verification & Revision Auditing: Test parametric associativity by stretching or modifying parent geometry and confirming that linked dimensions, attributes, schedules, or section views update automatically without disassociation warnings (ANNOMONITOR=2).
  4. Step 4 — Pre-Transmittal Quality Assurance (QA/QC): Prior to saving or publishing the deliverable, run OVERKILL to eliminate duplicate vectors, -PURGE (RegApps and All) to strip orphaned symbol table bloat, and AUDIT to verify 100% AcDbObject handle integrity.
