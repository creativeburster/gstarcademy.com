Course Technical Scope & Production Competencies

Carrying rolled A0 paper blueprints onto muddy construction sites, underground metro tunnels, or cleanroom fabs leads to crews building from superseded revisions. Course 16 trains field engineers and QA inspectors to run paperless digital inspections using DWG FastView across iOS, Android, Windows, and Web browsers.

  • Package font-complete DWG drawings (with embedded SHX/TTF fonts and Xrefs) to DWG FastView My Cloud or offline encrypted tablet storage for zero-connectivity tunnel and offshore inspections.
  • Execute sub-millimeter field measurements (Distance, Continuous Polyline Length, Closed Room Area, Arc Radius, Coordinate Readout) with touch-magnifying loupe Osnaps.
  • Author rich field Redlines—combining revision clouds, freehand sketches, geotagged site photos, and embedded Voice Annotations—and sync instant markup notifications back to office GstarCAD desktops.

Module 1: DWG FastView Mobile & Web: Offline Jobsite Inspection, Voice Markups & Cloud CDE Sync

Module 2: Step-by-Step Hands-On Command Execution Lab

Follow this structured 4-step laboratory procedure directly at the GstarCAD command line or dynamic input prompt:

  1. Step 1 — Environment & System Variable Initialization: At the command prompt, verify the active state of core commands and variables: DWG FastView Mobile, Revision Cloud, Voice Note Pin, Area Measure, Offline Cache. Ensure that object snap bitcodes (OSMODE=175), associative dimensioning (DIMASSOC=2), and multi-core display regeneration (WHIPTHREAD=3) are active.
  2. Step 2 — Primary Geometry & Metadata Authoring: Execute the primary workflow on standardized ISO 13567 or discipline-specific layers. Never place production geometry or block definitions on Defpoints, and keep internal block geometry on Layer 0 so instances inherit host layer properties dynamically.
  3. Step 3 — Associative Verification & Revision Auditing: Test parametric associativity by stretching or modifying parent geometry and confirming that linked dimensions, attributes, schedules, or section views update automatically without disassociation warnings (ANNOMONITOR=2).
  4. Step 4 — Pre-Transmittal Quality Assurance (QA/QC): Prior to saving or publishing the deliverable, run OVERKILL to eliminate duplicate vectors, -PURGE (RegApps and All) to strip orphaned symbol table bloat, and AUDIT to verify 100% AcDbObject handle integrity.
