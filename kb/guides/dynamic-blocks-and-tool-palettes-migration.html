Migrating Dynamic Blocks and Custom Tool Palettes (XTP)

Technical guide to transferring dynamic block libraries with parametric visibility states and exporting/importing customized Tool Palettes (XTP) into GstarCAD.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-09-30 Editorial Process & Testbed

1. Dynamic Block Parametric Fidelity

Enterprise CAD libraries often encapsulate thousands of hours of parametric block authoring. GstarCAD provides full binary support for AutoCAD dynamic blocks. All parametric grips, actions, and lookup matrices behave with 100% parity:

  • Visibility States: Drop-down multi-representation states (e.g., Door 90° / 45° / closed) switch instantly via custom grip nodes.
  • Linear & Polar Stretch: Dimension-driven frame extensions adjust dynamically with live associative dimension updates.
  • Lookup Tables: Master sizing tables (e.g., standard ANSI/DIN pipe flanges) populate from internal attribute tables without error.
  • Block Editor (BEDIT): Designers can modify existing dynamic blocks or author new parametric components natively.

2. Migrating Tool Palettes (.XTP)

Tool Palettes allow draftspersons to drag-and-drop standardized blocks, hatch patterns, and custom command macros onto drawings with pre-configured target layers and scales.

Step-by-Step XTP Palette Transfer:

  1. In AutoCAD, right-click the Tool Palette title bar, select Customize Palettes, right-click the corporate palette group, and choose Export (.xtp).
  2. Ensure the underlying DWG symbol library files are accessible on a shared corporate UNC network share (e.g., \\cadserver\blocks\).
  3. In GstarCAD, open Customize (CUSTOMIZE command), right-click the Palette panel, select Import, and select the exported .xtp files.
  4. GstarCAD automatically maps all block icons, command macros, and insertion layer overrides.
