ISO 2553 vs. AWS A2.4 Welding Symbols Cross-Reference Guide for CAD Engineers

Critical structural and mechanical comparison between ISO 2553 (System A dual reference line) and AWS A2.4 (Arrow Side vs Other Side) welding callouts in CAD.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Misinterpreting whether a weld symbol sits on the Arrow Side or the Other Side of a joint can cause catastrophic fabrication rework. Global fabricators must distinguish between AWS A2.4 (North America) and ISO 2553 (Europe/Asia System A with a dashed identification line).

2. Step-by-Step Production Workflow & Command Modules

1. The Crucial Reference Line Rule: AWS A2.4 vs. ISO 2553 System A

In AWS A2.4 (and ISO 2553 System B), there is a single solid reference line: symbols placed below the line indicate the Arrow Side, and symbols above indicate the Other Side. In ISO 2553 System A, there is a solid reference line plus a parallel dashed line: symbols on the solid line are Arrow Side, and symbols on the dashed line are Other Side (regardless of whether the dashed line is drawn above or below!).

2. Fillet Weld Leg Size (z) vs. Throat Thickness (a)

ISO 2553 requires prefixing fillet weld dimensions with either a (design throat thickness) or z (leg length), where for a $45^\circ$ mitre fillet:

$$a = \frac{z}{\sqrt{2}} \approx 0.707 z \quad \Longleftrightarrow \quad z = 1.414 a$$

AWS A2.4 defaults to leg size without a letter prefix (e.g., 1/4 or 6 before the triangle).

3. Inserting Compliant Weld Symbols in GstarCAD Mechanical

Launch AMWELDSYM in GstarCAD Mechanical and select either ISO 2553 or ANSI/AWS A2.4 in the drawing standard settings—the software automatically formats the dashed identification line, tail process codes (e.g., 135 for MAG / GMAW), and field-weld flags.

5. Production QA Verification & Competency Checklist

  • Always specify in the title block whether welding symbols conform to ISO 2553 (System A), ISO 2553 (System B), or AWS A2.4.
  • Explicitly include the 'a' or 'z' prefix on all metric fillet welds to prevent a 30% strength undersizing error.
  • Use numeric ISO 4063 process numbers (135 = MAG, 141 = TIG) in the tail when issuing drawings to European/Asian shops.

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.
