ISO 13567 vs. AIA / US National CAD Standard (NCS) Layer Naming Dictionary

Cross-reference dictionary mapping AIA/NCS discipline-major-minor layer names to ISO 13567 European/International codes for multi-national BIM & CAD projects.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Global engineering firms frequently exchange DWG deliverables between North American owners enforcing the AIA / US National CAD Standard (NCS) and European/Asian teams operating under ISO 13567 (or BS 1192 / Uniclass). Understanding both syntax structures allows CAD managers to automate bi-directional layer translation inside GstarCAD using LAYTRANS.

2. Step-by-Step Production Workflow & Command Modules

1. AIA / US National CAD Standard Syntax (Discipline-Major-Minor-Status)

NCS uses readable 4-character alphanumeric fields separated by hyphens: e.g., A-WALL-FULL-N (Architectural - Wall - Full Height - New), S-COLS-PRIM (Structural Primary Columns), and M-HVAC-CDFF (Mechanical HVAC Ceiling Diffusers).

2. ISO 13567 Syntax (Agent-Element-Presentation-Status)

ISO 13567 uses fixed-length positional fields coupled with national classification tables (SfB, Uniclass, or OmniClass): e.g., A-210-G-N (Architect - External Walls - Graphic element - New work) or S-280-T-E (Structural - Frame/Columns - Text - Existing).

3. Automated Translation via GstarCAD Layer Translator (LAYTRANS)

Save a baseline .dws or .dwt file containing your target AIA or ISO 13567 layer table, open any subcontractor drawing, and run LAYTRANS to map incoming layers, colors, linetypes, and lineweights in batch.

4. Automation Script & Reference Implementation (AutoLISP AIA-to-ISO 13567 Layer Prefix Renamer)

(defun c:AIA-TO-ISO-RENAME ( / pairs)
  (setq pairs '(("A-WALL-EXTER" . "A-210-G-N")
                ("A-WALL-INTER" . "A-220-G-N")
                ("A-DOOR-FULL"  . "A-310-G-N")
                ("S-COLS-PRIM"  . "S-280-G-N")
                ("A-ANNO-DIMS"  . "A-000-D-N")))
  (foreach p pairs
    (if (and (tblsearch "LAYER" (car p)) (not (tblsearch "LAYER" (cdr p))))
      (command "_.-RENAME" "_LA" (car p) (cdr p))))
  (princ "\n[Layer Dictionary] Mapped core AIA layers to ISO 13567.")
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Never allow spaces or special characters (*, ?, |, /) inside CAD layer names.
  • Store approved AIA and ISO 13567 layer schemas as .dws Standards files for automated CHECKSTANDARDS audits.
  • Use Phase/Status suffixes (-N for New, -E for Existing, -D for Demolish) instead of ad-hoc layer names.
