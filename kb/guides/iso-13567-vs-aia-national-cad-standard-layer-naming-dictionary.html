ISO 13567 vs. AIA / US National CAD Standard (NCS) Layer Naming Dictionary

Cross-reference dictionary mapping AIA/NCS discipline-major-minor layer names to ISO 13567 European/International codes for multi-national BIM & CAD projects.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Global engineering firms frequently exchange DWG deliverables between North American owners enforcing the AIA / US National CAD Standard (NCS) and European/Asian teams operating under ISO 13567 (or BS 1192 / Uniclass). Understanding both syntax structures allows CAD managers to automate bi-directional layer translation inside GstarCAD using LAYTRANS.

2. Step-by-Step Production Workflow & Command Modules

1. AIA / US National CAD Standard Syntax (Discipline-Major-Minor-Status)

NCS uses readable 4-character alphanumeric fields separated by hyphens: e.g., A-WALL-FULL-N (Architectural - Wall - Full Height - New), S-COLS-PRIM (Structural Primary Columns), and M-HVAC-CDFF (Mechanical HVAC Ceiling Diffusers).

2. ISO 13567 Syntax (Agent-Element-Presentation-Status)

ISO 13567 uses fixed-length positional fields coupled with national classification tables (SfB, Uniclass, or OmniClass): e.g., A-210-G-N (Architect - External Walls - Graphic element - New work) or S-280-T-E (Structural - Frame/Columns - Text - Existing).

3. Automated Translation via GstarCAD Layer Translator (LAYTRANS)

Save a baseline .dws or .dwt file containing your target AIA or ISO 13567 layer table, open any subcontractor drawing, and run LAYTRANS to map incoming layers, colors, linetypes, and lineweights in batch.

4. Automation Script & Reference Implementation (AutoLISP AIA-to-ISO 13567 Layer Prefix Renamer)

(defun c:AIA-TO-ISO-RENAME ( / pairs)
  (setq pairs '(("A-WALL-EXTER" . "A-210-G-N")
                ("A-WALL-INTER" . "A-220-G-N")
                ("A-DOOR-FULL"  . "A-310-G-N")
                ("S-COLS-PRIM"  . "S-280-G-N")
                ("A-ANNO-DIMS"  . "A-000-D-N")))
  (foreach p pairs
    (if (and (tblsearch "LAYER" (car p)) (not (tblsearch "LAYER" (cdr p))))
      (command "_.-RENAME" "_LA" (car p) (cdr p))))
  (princ "\n[Layer Dictionary] Mapped core AIA layers to ISO 13567.")
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Never allow spaces or special characters (*, ?, |, /) inside CAD layer names.
  • Store approved AIA and ISO 13567 layer schemas as .dws Standards files for automated CHECKSTANDARDS audits.
  • Use Phase/Status suffixes (-N for New, -E for Existing, -D for Demolish) instead of ad-hoc layer names.

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

In multi-office engineering environments operating across GstarCAD 2027, GstarCAD Mechanical, GstarCAD Architecture, and legacy AutoCAD (2018–2027) seats, mastering ISO 13567 vs. AIA / US National CAD Standard (NCS) Layer Naming Dictionary requires understanding how the underlying AC1032 DWG binary database serializes entity handles, symbol table records, and Named Object Dictionary (NOD) pointers.

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
  3. Submittal Packaging & Mobile Review: Lock all Paper Space viewports (`DisplayLocked = Yes`), bind or relative-path all external references via ETRANSMIT, and verify final plotted PDF/A lineweights (`ISO full bleed`) alongside DWG FastView mobile cloud markup links.
