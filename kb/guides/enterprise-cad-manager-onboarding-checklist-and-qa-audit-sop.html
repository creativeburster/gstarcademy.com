Enterprise CAD Manager Onboarding Checklist & Pre-Submittal QA Audit SOP

Turnkey Standard Operating Procedure (SOP) for enterprise CAD managers deploying GstarCAD across engineering teams: shared network profiles, DWS checking, and zero-defect submittal gates.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Zhang Mingyuan, B.Eng. (Distinguished DWG Graphics Kernel & GRX SDK Architect) Last reviewed 2026-11-03 Editorial Process & Testbed

1. Engineering Architecture & Core Methodology

Scaling a 20- to 500-seat engineering department on GstarCAD requires shifting from individual drafter habits to a locked, server-governed CAD Management Standard Operating Procedure (SOP). This guide provides the complete Day-1 workstation onboarding checklist and the 10-point Pre-Submittal QA Gate.

2. Step-by-Step Production Workflow & Command Modules

1. Phase 1: Central Server Repository & Shared Support Paths

Create a read-only network share (\\CAD-SVR\GstarCAD_Standards\) containing four locked folders: 01_Templates (.dwt/.dws), 02_PlotStyles (.ctb/.stb/.pc3), 03_ToolPalettes_Blocks, and 04_LISP_Startup (acaddoc.lsp). Export the configured profile as Enterprise_Standard.arg and deploy via command-line switch /p "\\CAD-SVR\...\Enterprise_Standard.arg".

2. Phase 2: Automated System Variable & Layer Standards Enforcement

Configure acaddoc.lsp to enforce FILEDIA=1, VISRETAIN=1, OSNAPZ=1, MIRRTEXT=0, and INDEXCTL=3 on every file open, and link your .dws CAD Standards file to check Layer, Text Style, and Dimension Style compliance automatically.

3. Phase 3: The 10-Point Pre-Submittal QA Audit Gate

Before any DWG or PDF leaves the firm, the lead checker executes the automated QA routine: AUDIT (fix database errors), -PURGE (All + Regapps + Zero-length geometry), OVERKILL, Xref Relative Path verification, Viewport Lock check, and ETRANSMIT packaging.

4. Automation Script & Reference Implementation (AutoLISP 1-Click Pre-Submittal QA Audit & Viewport Lock Enforcer)

(defun c:QA-SUBMITTAL-GATE ( / ss i ent locked)
  (setvar "CMDECHO" 0)
  (command "_.AUDIT" "_Y")
  (command "_.-PURGE" "_R" "*" "_N")
  (command "_.-PURGE" "_A" "*" "_N")
  (setq locked 0)
  (if (setq ss (ssget "_X" '((0 . "VIEWPORT"))))
    (progn
      (setq i 0)
      (while (< i (sslength ss))
        (setq ent (ssname ss i) i (1+ i))
        (vlax-put-property (vlax-ename->vla-object ent) 'DisplayLocked :vlax-true)
        (setq locked (1+ locked)))))
  (command "_.QSAVE")
  (princ (strcat "\n[QA Gate PASS] Audited, Purged Regapps, and Locked " (itoa locked) " Viewports."))
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Make the server Templates (.dwt) and Plot Styles (.ctb) folder Read-Only for standard users and Writable only for the CAD Manager.
  • Require every engineer to run QA-SUBMITTAL-GATE before moving drawings from WIP (S0) to Shared/Published CDE folders.
