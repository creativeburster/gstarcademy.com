Course 25: Associative Arrays (Path/Polar/Rectangular), Superhatch & Express Tools Mastery

Accelerate architectural facades, stadium seating, and mechanical perforation layouts in GstarCAD 2027 using Associative Arrays (Ctrl+Click item overrides), SUPERHATCH, and Express Tools.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Modern GstarCAD 2027 replaces legacy static dialog arrays with parametric **Associative Array Objects (`ARRAYRECT`, `ARRAYPATH`, `ARRAYPOLAR`)**. Even after placing 400 auditorium seats along a curved spline (`ARRAYPATH`) or 1,200 facade louvers across a multi-story elevation (`ARRAYRECT` with Z-Levels), you can drag interactive spacing grips, replace a single column obstacle instance with a custom block (`ARRAYEDIT → Replace Item`), or adjust row counts in `Ctrl+1` without recreating the array.

2. Step-by-Step Production Workflow & Command Modules

Module 1: Path Arrays (Measure vs. Divide) & Non-Destructive Item Overrides

Run ARRAYPATH to distribute lighting fixtures, piles, or rebar along a curve. Switch the **Method** on the contextual ribbon between **Divide** (spaces $N$ items equally along total curve length—auto-recalculating pitch if the curve stretches) and **Measure** (locks exact center-to-center spacing, adding/removing items as the curve stretches). Hold `Ctrl` and click any individual array item to move, erase, or replace it (`ARRAYEDIT`) while keeping the overall array associative!

Module 2: Custom Block/Image Tiling with SUPERHATCH & TFRAMES

When standard `.pat` vector line hatches cannot represent realistic interlocking pavers, curved roof tiles, or wood-grain textures, run Express Tools SUPERHATCH. Select any **Block** (or **Image/Wipeout**), define the unit repeat magenta box, and click inside a closed boundary. GstarCAD tiles and clips (`XCLIP`) the block across the boundary automatically.

Module 3: Top 10 Production Express Tools (`BURST`, `OVERKILL`, `TXT2MTXT`, `NCOPY`, `TORIENT`)

Master `BURST` (explodes blocks while converting `ATTDEF` values into static text instead of raw tag names!), `NCOPY` (copies individual lines/walls directly out of an Xref without opening or binding the Xref), `ARCTEXT` (curves text along an arc), `TCIRCLE` (encloses selected text numbers in slots/circles), and `TORIENT` (rotates 500 angled text labels to right-reading orientation in one click).

3. Command, Variable & Standard Reference Matrix

Command / Parameter Scope / Target Engineering Behavior & Best Practice
ARRAYPATH (Divide vs. Measure) Associative Curve Array Distributes objects tangent or parallel along splines/polylines with dynamic grips.
ARRAYEDIT (Ctrl+Click Item) Sub-Item Modification Deletes, moves, or swaps individual array elements around structural obstacles.
BURST (vs. EXPLODE) Attributed Block Flatten Converts populated block attributes into plain TEXT/MTEXT instead of raw ATTDEF tags.
NCOPY Nested Xref Extraction Clones a single sub-entity from an Xref into the host drawing without binding.

5. Production QA Verification & Competency Checklist

  • Always use `BURST` instead of `EXPLODE` when flattening title blocks or equipment tags for archival handover—`EXPLODE` reverts attributes back to their raw tag names (`REV` instead of `C02`)!
  • Use `Ctrl+Click` + `Delete` on individual items inside an Associative Array where structural columns pass through, rather than exploding the entire array.
  • Use `TFRAMES` (`IMAGEFRAME = 2` / `XCLIPFRAME = 2`) after running `SUPERHATCH` to hide clipping boundary frames on PDF plots.

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

In multi-office engineering environments operating across GstarCAD 2027, GstarCAD Mechanical, GstarCAD Architecture, and legacy AutoCAD (2018–2027) seats, mastering Course 25: Associative Arrays (Path/Polar/Rectangular), Superhatch & Express Tools Mastery requires understanding how the underlying AC1032 DWG binary database serializes entity handles, symbol table records, and Named Object Dictionary (NOD) pointers.

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
  3. Submittal Packaging & Mobile Review: Lock all Paper Space viewports (`DisplayLocked = Yes`), bind or relative-path all external references via ETRANSMIT, and verify final plotted PDF/A lineweights (`ISO full bleed`) alongside DWG FastView mobile cloud markup links.
