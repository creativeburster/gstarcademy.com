buildingSMART IDS & Automated IFC Model Compliance Checking Guide

Implement automated OpenBIM quality assurance using buildingSMART IDS (Information Delivery Specification), IFC 4.3 schema validation, Solibri/BIMcollab rulesets, and BCF issue round-tripping.

By Gstarcademy Editorial Team Updated 2026-10-12 Editorial process

1. What is buildingSMART IDS (Information Delivery Specification)?

Historically, BIM Execution Plans (BEPs) specified data requirements in static PDF tables—forcing BIM coordinators to manually inspect whether walls had `FireRating` properties or whether structural beams used correct `Uniclass` codes. Ratified by buildingSMART International, **IDS 1.0** is an open, machine-readable XML standard that defines exact alphanumeric and classification requirements for IFC models, enabling 100% automated pass/fail compliance auditing in seconds.

2. Structuring an IDS Specification: Applicability vs Requirements

Every IDS rule consists of two logical blocks: **Applicability** (which elements in the IFC model are selected for testing, e.g., all external doors) and **Requirements** (what conditions those elements must satisfy, e.g., must possess an `AcousticRating` property in decibels and a valid manufacturer string). This separation prevents false-positive failures on internal or schematic geometry.

3. Executing Automated Audits & Exporting BCF 3.0 Reports

When an architectural or MEP consultant uploads an IFC 4.3 model to the Common Data Environment (CDE), an automated IDS validator (such as IfcOpenShell ids-tester, Solibri Office, or BIMcollab Zoom) evaluates all rulesets. Failed elements are compiled into a **BCF 3.0 (BIM Collaboration Format)** report containing the exact `IfcGlobalId` and camera viewpoint, allowing the author to highlight and fix missing parameters directly inside Revit, Archicad, or GstarCAD Architecture.

4. Pre-Export Mapping in Authoring Software

To guarantee 100% IDS pass rates on first submission, BIM managers should configure standardized Property Mapping Tables (`IFC Export Classes` and user-defined property set `.txt` schedules) inside the authoring template so native parameters map deterministically to official buildingSMART Psets.
