Electrical Schematic Symbols: IEC 60617 vs. IEEE 315 / ANSI Y32.2 Reference

Comprehensive electrical CAD comparison between European/International IEC 60617 + IEC 81346 reference designations (-Q, -K, -F, -M) and North American NEMA/IEEE 315 ladder diagrams.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Control panel builders and electrical engineers exporting machinery globally must maintain dual schematic libraries in GstarCAD: IEC 60617 / IEC 81346 (vertical power flow, rectangular resistor boxes, -Q/-K/-F tags) and IEEE 315 / NFPA 79 (horizontal ladder rungs, zig-zag resistors, CB/CR/FU/M tags).

2. Step-by-Step Production Workflow & Command Modules

1. Schematic Orientation: Vertical IEC Columns vs. Horizontal NFPA 79 Ladders

IEC 60617 schematics draw 3-phase power rails horizontally across the top and route control/power branches vertically downward through numbered columns. North American NFPA 79 / JIC schematics draw L1/L2 vertical rails on the left and right with horizontal ladder rungs numbered sequentially down the page.

2. IEC 81346 Single-Letter Component Reference Designations

IEC 81346 standardized single-letter class prefixes across all schematics and BOMs: -Q (Switching devices: circuit breakers, contactors, motor starters), -K (Relays, PLC coils, timers), -F (Protective fuses, surge arresters), -S (Pushbuttons, selector/limit switches), -M (Motors), and -X (Terminal blocks).

3. Contact Cross-Referencing & Wire Numbering in GstarCAD

Every relay coil (e.g., -K1 on Sheet 04, Column 3) must display a cross-reference table beneath it listing the exact sheet.column coordinates of its Normally Open (NO: 13-14) and Normally Closed (NC: 21-22) contacts.

3. Command, Variable & Standard Reference Matrix

Command / Parameter Scope / Target Engineering Behavior & Best Practice
Circuit Breaker / Contactor IEC: -Q1, -Q2 ANSI/NFPA: CB1, M1, CON1 — IEC 81346 merges breakers & power contactors into Q
Control Relay / Timer Coil IEC: -K1, -K2 ANSI/NFPA: CR1, TR1 — Coil terminals A1/A2; NO contacts 13-14
Fuse / Overload Protection IEC: -F1, -F2 ANSI/NFPA: FU1, OL1 — Rectangular box with through-line (IEC) vs S-curve (ANSI)
Pushbutton / Limit Switch IEC: -S1, -S2 ANSI/NFPA: PB1, LS1 — NC contacts numbered 1-2; NO contacts 3-4
Resistor / Inductor Rectangular Box / Solid Semicircle Zig-Zag Line / Looped Coils — Classic visual distinction on schematics

4. Automation Script & Reference Implementation (AutoLISP Sequential Electrical Wire Number Stamping Tool)

(defun c:STAMP-WIRES ( / prefix num pt)
  (setq prefix (getstring "\nEnter Sheet/Page Prefix (e.g. 04): ")
        num    (getint "\nEnter Starting Wire Number (e.g. 1): "))
  (while (setq pt (getpoint "\nPick Wire Label Point (Enter to stop): "))
    (command "_.TEXT" "_J" "_BC" pt 2.5 0.0 (strcat prefix (if (< num 10) "0" "") (itoa num)))
    (setq num (1+ num)))
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Never mix IEC 60617 and IEEE 315 symbols on the same electrical schematic sheet.
  • Follow IEC 60947 terminal numbering: 1-2 / 3-4 / 5-6 for main power poles, X1-X2 for indicator lamps, and A1-A2 for relay coils.
  • Use GstarCAD Block Attributes for component tags (-Q1, -K1) so terminal strip and BOM schedules extract cleanly.
