Metric-to-Imperial CAD Scaling Factors, INSUNITS & Viewport Ratios Cheat Sheet

Exact mathematical conversion multipliers between Millimeters, Meters, Decimal Feet, US Survey Feet, and Architectural Inches with INSUNITS and viewport XP scales.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Few errors are costlier on international construction or manufacturing jobs than scaling a metric millimeter drawing by an approximate factor or mixing International Feet (0.3048 m exact) with US Survey Feet (1200/3937 m). This reference provides the exact conversion constants, system variables, and Paper Space ZOOM XP ratios for GstarCAD and AutoCAD.

2. Step-by-Step Production Workflow & Command Modules

1. Exact Unit Conversion Multipliers (1 Inch = 25.4 mm Exact)

When manually scaling geometry with the SCALE command using base point 0,0,0:

  • Inches to Millimeters: Multiply by 25.4.
  • Millimeters to Inches: Multiply by 0.03937007874 (or enter fraction 10/254 directly at the GstarCAD scale prompt!).
  • Feet (Decimal) to Millimeters: Multiply by 304.8; Millimeters to Feet: enter fraction 10/3048 (0.003280839895).

2. The INSUNITS, INSUNITSDEFSOURCE &UREMENT Triad

Set INSUNITS = 4 (Millimeters), 6 (Meters), 1 (Inches), or 2 (Feet) so GstarCAD automatically scales blocks and Xrefs upon insertion. Always pair with MEASUREMENT = 1 (Metric ISO hatch/linetype files) or 0 (Imperial ANSI).

3. Architectural vs. Engineering Viewport Scale Ratios (ZOOM XP)

In Architectural Inches (LUNITS = 4), $1/4'' = 1'-0''$ equals a 1:48 ratio (ZOOM 1/48XP), and $1/8'' = 1'-0''$ equals 1:96. In Civil Decimal Feet, $1'' = 20'$ on an inch sheet requires 1/20XP (if paper is inches and model is feet).

4. Automation Script & Reference Implementation (AutoLISP Exact Fractional Metric-Imperial Converter)

(defun c:CONVERT-DWG-UNITS ( / mode ss fac)
  (initget "MmToInch InchToMm MmToFeet FeetToMm")
  (setq mode (getkword "\nSelect conversion [MmToInch/InchToMm/MmToFeet/FeetToMm]: "))
  (setq fac (cond ((= mode "MmToInch") (/ 1.0 25.4))
                  ((= mode "InchToMm") 25.4)
                  ((= mode "MmToFeet") (/ 1.0 304.8))
                  ((= mode "FeetToMm") 304.8)))
  (if (setq ss (ssget "_X" '((410 . "Model"))))
    (command "_.SCALE" ss "" "0,0,0" fac))
  (princ (strcat "\n[Units] Scaled Model Space by exact factor " (rtos fac 2 10)))
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Enter exact rational fractions (10/254 or 10/3048) at the GstarCAD SCALE prompt instead of rounded 4-decimal numbers.
  • Verify whether state plane civil coordinates use International Feet (0.3048 m) or US Survey Feet (0.3048006096 m) at high coordinate values.
  • Update both INSUNITS and MEASUREMENT when converting a drawing between Imperial and Metric.

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
