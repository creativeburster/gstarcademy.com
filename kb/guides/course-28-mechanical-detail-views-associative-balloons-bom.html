Course 28: Mechanical Detail Views (AMDETAIL), Associative Balloons & Multi-Level BOM Rollups

Create associative multi-scale detail callouts (AMDETAIL / AMSCALEMONITOR), magnetic item balloons (AMBALLOON), and ERP-ready parts lists (AMPARTLIST) in GstarCAD Mechanical 2027.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Chen Haoran, M.Sc., GDTP-S (Lead Mechanical CAD & ASME GD&T Specialist) Last reviewed 2026-11-03 Editorial Process & Testbed

1. Engineering Architecture & Core Methodology

In traditional 2D CAD, creating a `5:1` enlarged detail view of a seal groove requires copying the geometry to the side, scaling it up by `5.0`, and manually setting `DIMLFAC = 0.2`—meaning any later design change to the main assembly leaves the enlarged detail out of sync! In GstarCAD Mechanical 2027, **`AMDETAIL`**, **`AMBALLOON`**, and **`AMPARTLIST`** are driven by an integrated relational assembly database.

2. Step-by-Step Production Workflow & Command Modules

Module 1: Associative Enlarged Detail Views (`AMDETAIL`) & Scale Area Zones

Run AMDETAIL, encircle the seal groove or thread relief on the `1:1` main view, specify a scale factor (e.g., `5:1` or `2:1`), and place the callout either in Model Space (with an automatic local scale monitor so `AMPOWERDIM` still measures true `1:1` values!) or as a linked Paper Space viewport.

Module 2: Magnetic Item Balloons (`AMBALLOON`) & Spline/Orthogonal Alignment

Run AMBALLOON, select all `AMPARTREF` nodes across the assembly in a single window, and place your balloons along a horizontal, vertical, circular, or custom polyline guide rail. Use **Collect Balloons** to stack a bolt + washer + nut fastener assembly onto a single leader arrow (`12 - 13 - 14`).

Module 3: Multi-Level BOM Databases (`AMBOM`), Filters & ERP Excel Export (`AMPARTLIST`)

Open AMBOM to inspect the hierarchical Bill of Materials, add custom formula columns (`Total Weight = QTY * UNIT_MASS`), renumber items sequentially (`Renumber`), and insert the formatted `AMPARTLIST` table into your drawing border or export bi-directionally to `.xlsx` / `.csv` for SAP and Teamcenter.

3. Command, Variable & Standard Reference Matrix

Command / Parameter Scope / Target Engineering Behavior & Best Practice
AMDETAIL Enlarged Detail Callout Creates zoomed detail views with automatic local dimension scale compensation.
AMBALLOON Associative Item Callouts Aligns item numbers along vertical/horizontal guide rails; supports stacked leaders.
AMBOM Relational BOM Engine Aggregates standard parts, custom blocks, and sub-assemblies with mass formulas.
AMPARTLIST Drawing Parts Schedule Places standards-compliant ISO/DIN/ASME parts lists with automatic row wrapping.

5. Production QA Verification & Competency Checklist

  • Never type manual numbers inside static circles for assembly callouts; always attach `AMPARTREF` and use `AMBALLOON` so item counts stay 100% synchronized.
  • Use `AMBALLOON > Collect` on bolted joints so bolt, flat washer, spring washer, and hex nut share a single clean leader line.
  • Run `AMBOM > Renumber` before final release so item numbers follow a clean sequential order (`1, 2, 3...`) with no gaps from deleted parts.
