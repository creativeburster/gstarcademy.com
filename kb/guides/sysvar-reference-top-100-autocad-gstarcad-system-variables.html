Top 100 AutoCAD & GstarCAD System Variables Reference Manual

Complete engineering dictionary of the 100 most critical AutoCAD and GstarCAD system variables across drafting, selection, Xrefs, plotting, and performance.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Zhang Mingyuan, B.Eng. (Distinguished DWG Graphics Kernel & GRX SDK Architect) Last reviewed 2026-11-03 Editorial Process & Testbed

1. Engineering Architecture & Core Methodology

Over 80% of unexpected CAD behaviors—missing file dialogs, broken noun-verb selection, vanishing Xref layer overrides, or sudden cursor lag—are caused by altered System Variables rather than software corruption. Both AutoCAD and GstarCAD store these variables either in the Windows Registry (profile-level) or directly inside the .dwg database header.

2. Step-by-Step Production Workflow & Command Modules

1. Selection, UI & Dialog System Variables

Control command prompt behavior, noun-verb selection, and grip interaction:

  • FILEDIA (1) & CMDDIA (1): Force GUI file open/save and command dialog boxes instead of command-line prompts.
  • PICKFIRST (1), PICKADD (2), PICKAUTO (1): Enable selecting objects before issuing a command and additive window selection.
  • SELECTIONPREVIEW (3) & HIGHLIGHT (1): Manage hover rollover highlighting without stalling on massive drawings.

2. Drafting, Snapping & Dimensioning Variables

Prevent 3D elevation accidents and annotation scaling mismatches:

  • OSNAPZ (1): Forces all object snaps to project onto the current UCS Z=0 elevation.
  • MIRRTEXT (0): Keeps text readable (right-reading) when mirroring blocks or details.
  • DIMASSOC (2) & ANNOALLVISIBLE (1): Maintain true associative dimensions and display annotative entities during troubleshooting.

3. External References (Xref), Plotting & Performance Variables

Lock down multi-discipline sheet sets and hardware acceleration:

  • VISRETAIN (1) & VISRETAINMODE (0): Preserve host drawing layer overrides across Xref reloads.
  • XLOADCTL (2) & INDEXCTL (3): Enable demand-loading with spatial and layer indexes.
  • BACKGROUNDPLOT (0) & WHIPTHREAD (3): Maximize multi-core regeneration and prevent plot spooler hangs.

3. Command, Variable & Standard Reference Matrix

Command / Parameter Scope / Target Engineering Behavior & Best Practice
FILEDIA / CMDDIA Registry 1 — Restores Open/Save GUI file dialogs
PICKFIRST / PICKADD Registry 1 / 2 — Enables noun-verb and additive object selection
OSNAPZ Not Saved 1 — Projects all Osnaps to current elevation (prevents Z drift)
VISRETAIN Drawing (.dwg) 1 — Retains Xref layer color/freeze overrides on reload
MIRRTEXT Drawing (.dwg) 0 — Prevents text from flipping backward during MIRROR
INDEXCTL Drawing (.dwg) 3 — Saves both Layer and Spatial indexes in DWG

    '(("FILEDIA" . 1) ("CMDDIA" . 1) ("PICKFIRST" . 1) ("PICKADD" . 2)
      ("MIRRTEXT" . 0) ("OSNAPZ" . 1) ("VISRETAIN" . 1) ("DIMASSOC" . 2)
      ("XLOADCTL" . 2) ("INDEXCTL" . 3) ("PROXYNOTICE" . 0)))
  (princ "\n[GstarCAD SysVar Guard] Core system variables verified.")
  (princ)
)
(c:GSTAR-SYSVAR-GUARD)

5. Production QA Verification & Competency Checklist

  • Run SYSVDLG or SETVAR to inspect current variable states against factory defaults.
  • Embed GSTAR-SYSVAR-GUARD inside acaddoc.lsp so third-party scripts cannot corrupt FILEDIA.
  • Configure SYSVARMONITOR to alert users immediately if PICKFIRST, MIRRTEXT, or VISRETAIN changes.
