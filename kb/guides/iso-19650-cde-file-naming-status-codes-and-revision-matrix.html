ISO 19650 Common Data Environment (CDE) File Naming, Status Codes & Revision Matrix

Complete engineering guide to ISO 19650-2 container naming conventions, Work in Progress (S0) to Published (A1/CR) status codes, and revision sequences (P01 vs C01).

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Dr. Lin Wei, Ph.D., PE (Principal BIM & Interoperability Architect) Last reviewed 2026-11-03 Editorial Process & Testbed

1. Engineering Architecture & Core Methodology

On international infrastructure and building projects governed by ISO 19650-2 (and UK National Annex BS EN ISO 19650), every DWG, IFC, and PDF uploaded to the Common Data Environment (CDE) must follow a strict 7-field container identifier and lifecycle state machine (WIP → Shared → Published → Archive).

2. Step-by-Step Production Workflow & Command Modules

1. The 7-Field ISO 19650 Container File Naming Convention

Files are named using hyphen-delimited alphanumeric codes: Project-Originator-Volume-Level-Type-Role-Number. Example: PRJ01-ACM-V1-02-DR-A-0101.dwg (Project PRJ01, Originator ACM, Volume 1, Level 02, 2D Drawing, Architect, Sheet 0101).

2. Suitability Status Codes (S0 to S4, A1 to A4, B1)

Status codes reside in CDE metadata and title block attributes—never hardcoded into the filename so links don't break:

  • S0: Work in Progress (WIP — internal team only).
  • S1: Suitable for Coordination; S2: Suitable for Information; S3: Suitable for Review & Comment; S4: Suitable for Stage Approval.
  • A1 / A2 / A3 / CR: Authorized for Construction / As-Built Published states.

3. Revision Numbering (Preliminary P01.01 vs. Contractual C01)

During WIP (S0), minor drafts increment sub-revisions (P01.01, P01.02). When shared to S1–S4, the decimal drops (P01, P02). Once approved for construction (A1), the prefix switches to Contractual (C01, C02).

3. Command, Variable & Standard Reference Matrix

Command / Parameter Scope / Target Engineering Behavior & Best Practice
S0 (Work in Progress) P01.01, P01.02 WIP Folder — Unreleased internal drafting & checking
S1 / S2 / S3 P01, P02, P03 Shared Folder — Cross-discipline clash coordination & review
S4 P04 Shared Folder — Client / Lead Appointed Party stage sign-off
A1 / A2 / A3 C01, C02 Published Folder — Authorized for construction / fabrication
CR C03 Archive / As-Built — Verified As-Built record documentation

4. Automation Script & Reference Implementation (AutoLISP ISO 19650 Filename Syntax Validator)

(defun c:ISO19650-CHECK-NAME ( / dwgname parts)
  (setq dwgname (vl-filename-base (getvar "DWGNAME")))
  (setq parts (acet-str-to-list "-" dwgname))
  (if (= (length parts) 7)
    (princ (strcat "\n[ISO 19650 PASS] Valid 7-field container ID: " dwgname))
    (princ (strcat "\n[ISO 19650 FAIL] '" dwgname "' has " (itoa (length parts))
                   " fields (Expected 7: Proj-Orig-Vol-Lvl-Type-Role-Num).")))
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Never embed Revision (P01/C01) or Status (S1/A1) inside the DWG filename; store them in title block attributes so Xref paths never break.
  • Restrict character sets in container filenames to uppercase A-Z, digits 0-9, and hyphens (-).
  • Run ISO19650-CHECK-NAME before exporting ETRANSMIT packages to the project CDE.
