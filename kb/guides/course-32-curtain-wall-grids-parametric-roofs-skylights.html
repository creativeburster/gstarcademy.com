Course 32: Curtain Wall Mullion Grids, Parametric Hip/Gable Roofs, Skylights & Dormers

Model complex multi-pitched hip/gable roofs, dormer cutouts, skylights, and unitized glass curtain walls in GstarCAD Architecture 2027.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Drafting intersecting multi-pitch roofs (`30°` main hip roof intersecting a `40°` entrance gable with dormer windows) by manually calculating 3D valley/hip miter angles in 2D plan and section views is notoriously difficult. In GstarCAD Architecture 2027, the parametric **Roof Engine (`ROOF` / `SLOPEROOF`)** and **Curtain Wall System (`CURTAINWALL`)** solve 3D plane intersections automatically and project exact 2D elevations and sections on demand.

2. Step-by-Step Production Workflow & Command Modules

Module 1: Multi-Pitch Hip, Gable & Mansard Roof Generation (`SLOPEROOF`)

Trace a closed polyline around the outer building walls (plus eave overhang, e.g., `600 mm`), launch SLOPEROOF, and assign pitch angles (`25°`, `35°`, or `0°/90°` for a vertical gable end) to each eave edge. GstarCAD Architecture automatically solves all hip, valley, and ridge intersections in 3D.

Module 2: Extending Walls to Roof Soffits & Cutting Dormers / Skylights (`DORMER`)

Select the top-story perimeter walls and run **Extend Wall to Roof** so gable end walls trim cleanly against the underside of the sloped roof slab. Use DORMER and SKYLIGHT to punch roof openings complete with side cheeks and flashing.

Module 3: Unitized & Stick-Built Curtain Wall Grids (`CURTAINWALL`)

Convert any curved or straight path into a **Glass Curtain Wall** by defining vertical mullion spacing (`1500 mm`), horizontal transom heights (`1100 mm` spandrel + `2400 mm` vision glass), aluminium profile depth (`65x150 mm`), and operable awning/door panel replacements.

3. Command, Variable & Standard Reference Matrix

Command / Parameter Scope / Target Engineering Behavior & Best Practice
SLOPEROOF / FREEFORMROOF 3D Roof Solver Computes hip, valley, and ridge intersections from 2D perimeter polylines and edge slopes.
DORMER / SKYLIGHT Roof Penetrations Cuts sloped roof slabs and generates vertical dormer side walls and glazing.
CURTAINWALL Facade Mullion System Generates aluminum mullions, transoms, vision glazing, and operable louver panels.
BLDGSECTION / BLDGELEV Automated 2D Extraction Projects 2D exterior elevations and cross-sections directly from the 3D envelope.

4. Automation Script & Reference Implementation (Roof Pitch Percentage vs. Degree Converter LISP)

(defun C:ROOFPITCH ( / deg rad pct ratio12)
  (setq deg (getreal "\nEnter roof pitch angle in degrees (e.g. 26.565): "))
  (if (and deg (> deg 0.0) (< deg 89.0))
    (progn
      (setq rad     (* deg (/ pi 180.0))
            pct     (* (tan rad) 100.0)
            ratio12 (* (/ (sin rad) (cos rad)) 12.0))
      (princ (strcat "\nAngle      : " (rtos deg 2 2) " deg"))
      (princ (strcat "\nSlope (%)  : " (rtos pct 2 1) "%"))
      (princ (strcat "\nRise : 12  : " (rtos ratio12 2 2) " : 12"))
    )
  )
  (princ)
)
(defun tan (x) (/ (sin x) (cos x)))

5. Production QA Verification & Competency Checklist

  • Verify eave gutter overhang distances (`500–800 mm`) and parapet flashing heights before running `BLDGELEV` to generate exterior elevations.
  • Check that upper-story masonry walls are trimmed to the underside of the sloped roof (`Extend Wall to Roof`) so they don't poke through roof tiles in 3D views.
  • Tag curtain wall operable panels and spandrel fire-stop zones so they appear in the automated `WINDSCHEDULE` opening table.

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

In multi-office engineering environments operating across GstarCAD 2027, GstarCAD Mechanical, GstarCAD Architecture, and legacy AutoCAD (2018–2027) seats, mastering Course 32: Curtain Wall Mullion Grids, Parametric Hip/Gable Roofs, Skylights & Dormers requires understanding how the underlying AC1032 DWG binary database serializes entity handles, symbol table records, and Named Object Dictionary (NOD) pointers.

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
  3. Submittal Packaging & Mobile Review: Lock all Paper Space viewports (`DisplayLocked = Yes`), bind or relative-path all external references via ETRANSMIT, and verify final plotted PDF/A lineweights (`ISO full bleed`) alongside DWG FastView mobile cloud markup links.
