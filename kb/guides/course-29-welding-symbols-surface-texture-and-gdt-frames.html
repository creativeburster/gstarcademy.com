Course 29: Welding Symbols (AMWELDSYM), Surface Texture (AMSURFSYM) & GD&T Feature Control Frames

Author standards-compliant ISO 2553 / AWS A2.4 welding symbols, ISO 21920 surface roughness annotations, and ASME Y14.5-2018 GD&T frames in GstarCAD Mechanical 2027.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Fabrication and machining drawings stand or fall on the clarity of their **Geometrical Product Specifications (GPS)**. A single misplaced dashed line on a weld symbol or a missing datum modifier on a Feature Control Frame can cause an entire batch of welded frames or CNC housings to be scrapped. GstarCAD Mechanical 2027 provides intelligent, object-attached symbol builders (`AMWELDSYM`, `AMSURFSYM`, `AMFCFRAME`, `AMDATUMID`) that validate syntax automatically against **ISO, DIN, ASME/ANSI, JIS, and GB** rules.

2. Step-by-Step Production Workflow & Command Modules

Module 1: Associative Welding Symbols (`AMWELDSYM`) — ISO 2553 vs. AWS A2.4

Run AMWELDSYM and click the joint edge. In the dialog, specify throat thickness (`a5`) or leg length (`z7`), elementary symbol (`Fillet`, `Single-V Butt`, `Plug/Slot`, `Spot`), intermittent weld pitch (`4 x 50 (100)`), and supplementary contour (`Flush`, `Convex`, `Concave`, `Weld-All-Around`, `Field Weld Flag`) plus EN ISO 4063 process code (`135` MAG, `141` TIG).

Module 2: Surface Texture & Machining Allowance Symbols (`AMSURFSYM` — ISO 21920 / ISO 1302)

Run AMSURFSYM and attach the symbol directly to the contour or dimension extension line (it rotates automatically to stay perpendicular to the surface!). Configure `Material Removal Required` (machined bar), `Material Removal Prohibited` (cast/forged circle), upper/lower limits (`Ra 1.6`, `Rz 6.3`), manufacturing method (`Milled`, `Ground`), and lay direction (`=`, `X`, `C`, `M`).

Module 3: Datum Identifiers (`AMDATUMID`) & GD&T Feature Control Frames (`AMFCFRAME`)

Place primary, secondary, and tertiary datum triangles (`|A|`, `|B|`, `|C|`) via AMDATUMID, then attach associative Feature Control Frames (`AMFCFRAME`). GstarCAD Mechanical enforces valid ASME Y14.5-2018 / ISO 1101 syntax—preventing illegal combinations such as applying a Datum Reference to a pure Form tolerance (`Flatness` or `Cylindricity`).

3. Command, Variable & Standard Reference Matrix

Command / Parameter Scope / Target Engineering Behavior & Best Practice
AMWELDSYM ISO 2553 / AWS A2.4 Generates fillet/butt weld symbols with throat/leg sizes, pitch, and process numbers.
AMSURFSYM ISO 21920 / ISO 1302 Attaches surface roughness symbols that auto-sync with the top-right collective header.
AMFCFRAME ASME Y14.5 / ISO 1101 Constructs syntax-validated GD&T frames with MMC/LMC/Projected zone modifiers.
AMEDGE ISO 13715 Edge State Specifies burr-free / undercut edge break tolerances (e.g., -0.2 to -0.5 mm).

5. Production QA Verification & Competency Checklist

  • Enable the **Collective Surface Texture Header** option in `AMSURFSYM` so the top-right corner of the sheet automatically lists the default roughness (`Ra 3.2`) alongside parenthetical summary icons of all specific roughness callouts used on the drawing!
  • Double-check whether your title block specifies **ISO 2553** (dual solid/dashed reference line) or **AWS A2.4** (single solid reference line) before releasing shop weldments.
  • Attach `AMSURFSYM` and `AMFCFRAME` directly to `AMPOWERDIM` extension lines so moving the dimension moves the symbols associatively.

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

In multi-office engineering environments operating across GstarCAD 2027, GstarCAD Mechanical, GstarCAD Architecture, and legacy AutoCAD (2018–2027) seats, mastering Course 29: Welding Symbols (AMWELDSYM), Surface Texture (AMSURFSYM) & GD&T Feature Control Frames requires understanding how the underlying AC1032 DWG binary database serializes entity handles, symbol table records, and Named Object Dictionary (NOD) pointers.

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
  3. Submittal Packaging & Mobile Review: Lock all Paper Space viewports (`DisplayLocked = Yes`), bind or relative-path all external references via ETRANSMIT, and verify final plotted PDF/A lineweights (`ISO full bleed`) alongside DWG FastView mobile cloud markup links.
