3. Pre-Processing GstarCAD DWG Files for Instant 3D Extrusion

To achieve 100% automatic face generation when importing a 2D DWG floor plan or urban masterplan into Houseplan, run this 3-step cleanup in GstarCAD 2027 prior to import:

  1. Relocate Near Origin `(0,0,0)`: Move geodetic UTM site plans close to `(0,0,0)` so 32-bit GPU vertex shaders render crisp shadow maps without z-fighting flicker.
  2. Zero Z-Elevation (`FLATTEN`): Ensure all 2D contour lines and wall footprints lie strictly on the $Z = 0.000$ plane.
  3. Weld Closed Loops (`OVERKILL` + `JOIN`): Eliminate duplicate overlapping segments so Houseplan recognizes closed building footprints immediately.
