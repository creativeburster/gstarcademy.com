Command Alias (PGP) and AutoLISP Script Compatibility Guide

How to migrate custom AutoCAD command aliases (acad.pgp) and legacy AutoLISP, FAS, and VLX automation routines to GstarCAD with zero syntax alterations.

By Gstarcademy Editorial Team Updated 2026-09-30 Editorial process

1. 99%+ Command Line & Shortcut Parity

Drafting speed relies heavily on muscle memory. GstarCAD preserves exact command names, prompts, and default options for over 99% of legacy 2D/3D operations—including complex operations like BEDIT, XREF, FILTER, QSELECT, ALIGN, and LAYTRANS.

To transfer your custom shortcut customizations from AutoCAD:

  1. In AutoCAD, type ALIASEDIT or open %APPDATA%\Autodesk\AutoCAD 20xx\Rxx.x\enu\Support\acad.pgp.
  2. Copy all custom entries at the bottom of the file (e.g., C, *CIRCLE, ZZ, *ZOOM).
  3. In GstarCAD, execute ALIASEDIT or open gcad.pgp, paste the customized alias definitions, and click Reinit.

2. AutoLISP & Visual LISP Execution Fidelity

GstarCAD features an independent, high-performance LISP interpreter supporting standard AutoLISP functions as well as modern Visual LISP extensions (VLA, VLAX, VLR reactor events). Over 98% of standard LISP programs written for AutoCAD run out-of-the-box without editing a single line of code.

Example: A production LISP routine that extracts text entities and queries bounding coordinates runs identically:

(defun c:BatchTextBounds ( / ss i ent obj minpt maxpt )
  (vl-load-com)
  (if (setq ss (ssget '((0 . "TEXT,MTEXT"))))
    (repeat (setq i (sslength ss))
      (setq ent (ssname ss (setq i (1- i))))
      (setq obj (vlax-ename->vla-object ent))
      (vla-getboundingbox obj 'minpt 'maxpt)
      (princ (strcat "\nFound text at: " (vl-prin1-to-string (vlax-safearray->list minpt))))
    )
  )
  (princ)
)

3. Handling FAS and VLX Compiled Binaries

While plain text .lsp and .mnl files execute directly, proprietary pre-compiled AutoCAD binaries (.fas and .vlx) use closed bytecode encryption. To migrate these plugins:

  • Recommended: Recompile original source .lsp files inside GstarCAD's integrated VLIDE (Visual LISP IDE) into .vlx.
  • LISP Debugger: GstarCAD 2026 SP1 introduces a full visual breakpoint debugger with variable watch windows and call stack inspection, streamlining in-house script maintenance.
