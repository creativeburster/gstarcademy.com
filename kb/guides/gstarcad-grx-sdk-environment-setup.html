C++ GRX SDK Development Environment Setup & First Plugin

Complete setup guide for GstarCAD C++ GRX SDK: Visual Studio compiler toolchain, include paths, library dependencies, and compiling your first high-performance native ARX/GRX plugin.

By Gstarcademy Editorial Team Updated 2026-09-30 Editorial process

1. Understanding GstarCAD GRX Architecture

GRX (GstarCAD Runtime eXtension) is the native C++ software development kit (SDK) equivalent to Autodesk ObjectARX. GRX provides direct access to GstarCAD's core database structures (GcDbDatabase), graphics pipeline, and transaction manager, executing at native CPU speed.

Visual Studio & Compiler Version Matrix:
  • GstarCAD 2026: Visual Studio 2022 (v143 toolset) / Windows 10/11 x64
  • GstarCAD 2024–2025: Visual Studio 2019 (v142 toolset) / Windows 10/11 x64
  • Binary Extension: Compiled plugins carry the .grx extension (or .arx).

2. Visual Studio Project Configuration

Create a standard C++ Dynamic-Link Library (DLL) project in Visual Studio and configure the following project properties:

  1. Target Extension: Set Configuration Properties -> General -> Target Extension to .grx.
  2. Additional Include Directories: Add $(GRX_SDK)\inc and $(GRX_SDK)\inc-x64.
  3. Additional Library Directories: Add $(GRX_SDK)\lib-x64.
  4. Additional Dependencies: Add gcad.lib, gcdb.lib, gcbase.lib, gcui.lib.
  5. Precompiled Headers: Use stdafx.h and include #include "gcad.h" and #include "gcdb.h".

3. The 'Hello GstarCAD' C++ Plugin Code

#include "stdafx.h"
#include "gcad.h"
#include "gcdb.h"
#include "gced.h"

void helloCmd() {
    gcedPrint(_T("\nHello, Welcome to GstarCAD GRX Native Development!\n"));
}

extern "C" GcRx::AppRetCode gcrxEntryPoint(GcRx::AppMsgCode msg, void* pkt) {
    switch (msg) {
        case GcRx::kInitAppMsg:
            gcrxUnlockApplication(pkt);
            gcrxRegisterAppMDIAware(pkt);
            gcedRegCmds->addCommand(_T("MY_COMMANDS"), _T("HELLO"), _T("HELLO"), 
                                    GCRX_CMD_MODAL, helloCmd);
            break;
        case GcRx::kUnloadAppMsg:
            gcedRegCmds->removeGroup(_T("MY_COMMANDS"));
            break;
    }
    return GcRx::kRetOK;
}

Build the project, launch GstarCAD, execute APPLOAD, pick your .grx binary, and type HELLO on the command line.
