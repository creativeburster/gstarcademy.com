Architectural & Structural Drawing Scales, Text Heights & DIMSCALE Master Chart

Complete lookup table for metric (1:1 to 1:500) and imperial (3"=1'-0" to 1/16"=1'-0") CAD text heights, DIMSCALE multipliers, and LTSCALE settings.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Whether you annotate in Model Space using DIMSCALE or in Paper Space Layouts using Annotative Scaling, plotted text on engineering drawings must measure exactly 2.5 mm (3/32" / 0.0938") for body notes/dimensions and 3.5 mm to 5.0 mm (1/8" to 3/16") for view titles per ISO 3098 and ASME Y14.2.

2. Step-by-Step Production Workflow & Command Modules

1. The Universal Model Space Text Height Formula

To calculate the required Model Space text height $H_{\text{model}}$ for any plot scale factor $S$ (where $1:S$ is the scale ratio):

$$H_{\text{model}} = H_{\text{paper}} \times S$$

For example, at 1:50 scale with a target plotted height of 2.5 mm, $H_{\text{model}} = 2.5 \times 50 = 125\text{ mm}$. At $1/4'' = 1'-0''$ ($S = 48$) with target $3/32''$, $H_{\text{model}} = (3/32) \times 48 = 4.5''$.

2. Metric Architectural & Structural Scale Lookup (1:5 to 1:200)

Standard ISO 5455 architectural scales step through 1:1, 1:2, 1:5, 1:10, 1:20, 1:50, 1:100, 1:200, 1:500. Never use non-standard scales like 1:30 or 1:75 that cannot be measured with a standard triangular scale rule on site.

3. Annotative Scaling in GstarCAD (CANNOSCALE & ANNOAUTOSCALE)

Instead of duplicating text layers for 1:50 and 1:100 viewports, enable the Annotative checkbox in GstarCAD's STYLE and DIMSTYLE dialogs and set Paper Text Height to 2.5 mm—GstarCAD scales the glyph automatically per viewport.

4. Automation Script & Reference Implementation (AutoLISP Model Space Text & DIMSCALE Calculator by Scale Ratio)

(defun c:CALC-CAD-SCALE ( / s h25 h35)
  (setq s (getreal "\nEnter Drawing Scale Denominator S (e.g. 50 for 1:50, 48 for 1/4"=1'): "))
  (setq h25 (* 2.5 s) h35 (* 3.5 s))
  (setvar "DIMSCALE" s)
  (princ (strcat "\n[Scale 1:" (rtos s 2 0) "] DIMSCALE set to " (rtos s 2 0)
                 " | 2.5mm Text = " (rtos h25 2 1) " | 3.5mm Header = " (rtos h35 2 1)))
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Standardize on 2.5 mm (metric) or 3/32" (imperial) plotted height for all general notes and dimensions.
  • Use Annotative Text and Dimensions when the same Model Space geometry appears in two viewports of different scales.
  • Never use 1:75 or 1:125 scales unless mandated by legacy municipal sheet constraints.

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

In multi-office engineering environments operating across GstarCAD 2027, GstarCAD Mechanical, GstarCAD Architecture, and legacy AutoCAD (2018–2027) seats, mastering Architectural & Structural Drawing Scales, Text Heights & DIMSCALE Master Chart requires understanding how the underlying AC1032 DWG binary database serializes entity handles, symbol table records, and Named Object Dictionary (NOD) pointers.

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
  3. Submittal Packaging & Mobile Review: Lock all Paper Space viewports (`DisplayLocked = Yes`), bind or relative-path all external references via ETRANSMIT, and verify final plotted PDF/A lineweights (`ISO full bleed`) alongside DWG FastView mobile cloud markup links.
