Sheet Set Manager (.DST), Dynamic Title-Block Fields & Multi-Core Batch Plotting in GstarCAD 2027

Migrate AutoCAD Sheet Set Data (.dst) files to GstarCAD 2027 without breaking CurrentSheetNumber, CurrentSheetTitle, or Model View callout fields during background PDF publishing.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-10-26 Editorial Process & Testbed

1. Binary Compatibility of `.DST` Sheet Set Databases

In large infrastructure, architectural, and EPC plant projects comprising 100 to 500 drawing sheets, managing sheet numbering, revision indexes, and transmittal packages manually is impossible. The Sheet Set Manager (`SSM` / `SHEETSET`) coordinates an entire project folder through a central XML/binary `.dst` (Drawing Sheet Set) database file.

GstarCAD 2027 reads and writes native `.dst` files directly without conversion. Every subset hierarchy, linked Paper Space layout pointer, Custom Sheet Set Property (such as `Client_Name`, `Project_Code`, `Issue_Date`), and Custom Sheet Property (`Drawn_By`, `Checked_By`, `Sheet_Rev`) remains 100% intact when opened across mixed AutoCAD and GstarCAD workstations.

2. Preserving Dynamic Title-Block Fields (`%<\AcSm ...>%`)

Title blocks linked to a `.dst` file rely on embedded Field expressions (`FIELD` command) using `AcSm` (Sheet Set Manager) evaluator codes. GstarCAD 2027 natively evaluates all standard `AcSm` field expressions whenever `FIELDEVAL = 31` is active:

Title Block Attribute Underlying DWG Field Expression Syntax Evaluation Trigger (`FIELDEVAL=31`)
Sheet Number %<\AcSm Sheet.Number \f "%tc1">% Updates automatically when sheets are reordered or renumbered in the SSM tree.
Project Number (Custom) %<\AcSm SheetSet.Project_Code>% Propagates global project metadata across all 500 sheets upon `REGEN` or `PLOT`.
View Scale Callout %<\AcObjProp Object(%<\_ObjId ...>%).CustomScale \f "1:%lu2">% Reads the exact Paper Space viewport scale factor dynamically.

3. High-Speed Background PDF Publishing & `ETRANSMIT` Archiving

To publish an entire `.dst` sheet set into a single multi-page, bookmark-indexed vector PDF without freezing the engineer's workstation:

;; GstarCAD 2027 — Pre-Publish Sheet Set Field Refresh & Plot Environment Optimizer
(defun c:GCAD_PREP_SSM_PUBLISH ()
  (setvar "FIELDEVAL" 31)        ;; Evaluate fields on Open(1)+Save(2)+Plot(4)+eTransmit(8)+Regen(16)
  (setvar "BACKGROUNDPLOT" 2)    ;; Run PUBLISH in background worker process; PLOT in foreground
  (setvar "EPDFSHX" 0)           ;; Suppress ugly PDF comment boxes around SHX vector text
  (setvar "IMAGEFRAME" 0)        ;; Hide raster company logo bounding borders on plotted PDFs
  (command "_REGENALL")
  (princ "\n[SSM Ready] All dynamic fields refreshed. Ready for multi-sheet PDF Publish.")
  (princ)
)

4. Multi-User `.DST` Network Locking & Field Update Governance

Unlike individual `.dwg` files—which lock an entire drawing to a single editor via `.dwl` / `.dwl2` lock files—a Sheet Set database (`.dst`) is designed for concurrent multi-user collaboration across an entire project discipline. When ten engineers open the same `Project-Master.dst` in GstarCAD 2027's Sheet Set Manager (`SSM`), GstarCAD acquires brief, atomic write locks on the `.dst` file only during metadata transactions (such as adding a sheet, renumbering a subset, or editing custom project properties) and immediately releases the lock.

To prevent stale title-block fields or network file contention on SMB/CIFS shares, configure these production system variables across all workstations:

System Variable Recommended Setting Operational Impact on Sheet Sets & Fields
FIELDEVAL 31 (Bitmask: 1+2+4+8+16) Forces automatic recalculation of `CurrentSheetNumber`, `SheetSetPlaceholder`, and plot date fields on Open, Save, Plot, eTransmit, and Regen.
SSMAUTOOPEN 1 Automatically opens the associated `.dst` palette whenever an engineer opens any member `.dwg` sheet belonging to that Sheet Set.
SSLOCATE 1 Searches the drawing's folder and parent project directory tree for the governing `.dst` file upon `OPEN`.
SSMPOLTIME 60 (Seconds) Controls the polling interval between automatic tree status refreshes (lock icons, missing file alerts) across network shares.
BACKGROUNDPLOT 2 (Publish only) Runs single-sheet `PLOT` synchronously for instant PDF output while offloading 100-sheet `PUBLISH` jobs to an asynchronous worker process.
