Course 33: Multi-Story Stair Towers, ADA/Accessible Ramps, Railings & Fire Egress Compliance

Design U-shaped scissor stairs, spiral stairs, accessible ramps, handrails, and travel-distance life-safety egress plans in GstarCAD Architecture 2027.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process

1. Engineering Architecture & Core Methodology

Vertical circulation and life-safety egress are among the most strictly regulated elements in building codes (**IBC / NFPA 101 / EN 1991 / GB 50016**). In GstarCAD Architecture 2027, parametric **Staircase Objects (`RECTSTAIR`, `ARCSTAIR`, `MULTISTAIR`)** and **Accessible Ramps (`RAMP`)** automatically enforce Blondel's ergonomic stride formula ($2R + G \approx 600\text{–}640\text{ mm}$), generate cut-line break symbols (`Up / Down` arrows on ground vs. standard vs. top floors), and project complete multi-story stair core sections in seconds.

2. Step-by-Step Production Workflow & Command Modules

Module 1: Dog-Leg (U-Turn), L-Shape & Scissor Stair Generation (`RECTSTAIR`)

Launch RECTSTAIR, enter the floor-to-floor story height (e.g., `3600 mm`), stairwell clear width (`2600 mm`), flight width (`1200 mm`), and target riser height (`R <= 150–175 mm`, tread going `G >= 260–280 mm`). Toggle the **Floor Display Mode** between `Bottom Floor` (single cut line with `UP` arrow), `Intermediate Floor` (double cut line showing both `UP` and `DN`), and `Top Floor` (`DN` arrow viewing full landing below).

Module 2: Accessible Wheelchair Ramps (`RAMP`) & Guardrail/Handrail Systems (`HANDRAIL`)

Run RAMP to generate straight or switchback pedestrian/vehicular ramps with automatic `1:12` (`8.33%`) maximum ADA/ISO 21542 slope checks, `1500 mm` level intermediate landings every `9.0 m` of horizontal run, and continuous dual-height handrails (`900 mm` / `700 mm`) with `300 mm` horizontal extensions.

Module 3: Fire Compartment Boundaries & Egress Travel Distance Polylines

Use associative `SPACE` zones and travel-path polylines to verify maximum dead-end corridor limits and two-way travel distances to enclosed fire-rated stairwells (`REI 120` walls with `EI 60-C` self-closing fire doors), and export door width schedules to verify occupant-load egress capacity.

4. Automation Script & Reference Implementation (Blondel Stair Ergonomics & Riser/Tread Code Validator LISP)

(defun C:STAIRCHECK ( / storyH targetR numR actualR treadG blondel)
  (setq storyH  (getreal "\nEnter floor-to-floor height in mm (e.g. 3600): ")
        targetR (getreal "\nEnter target maximum riser height R in mm <165>: ")
        treadG  (getreal "\nEnter tread going depth G in mm <280>: "))
  (if (null targetR) (setq targetR 165.0))
  (if (null treadG)  (setq treadG 280.0))
  (if (and storyH (> storyH 500.0))
    (progn
      (setq numR    (fix (+ (/ storyH targetR) 0.999))
            actualR (/ storyH (float numR))
            blondel (+ (* 2.0 actualR) treadG))
      (princ (strcat "\nTotal Risers Required : " (itoa numR) " risers @ " (rtos actualR 2 2) " mm"))
      (princ (strcat "\nBlondel Formula 2R+G  : " (rtos blondel 2 1) " mm (Ideal: 600 to 640 mm)"))
      (if (or (< blondel 580.0) (> blondel 650.0))
        (princ "\n[WARNING] 2R+G falls outside ergonomic 600-640mm comfort band!")
        (princ "\n[PASS] Stair riser/tread geometry satisfies ergonomic & IBC/ISO standards.")
      )
    )
  )
  (princ)
)

5. Production QA Verification & Competency Checklist

  • Verify that the **Blondel comfort formula ($2R + G$)** sits between `600 mm` and `640 mm` and that public evacuation stairs never exceed `R = 175 mm` (`G >= 260–280 mm`).
  • Check that fire-exit doors opening into a stairwell landing do not reduce the effective clear path of travel radius (`>= 1200 mm`) when open at $90^\circ$.
  • Ensure the ground-floor stair representation shows a single diagonal break line (`UP`), intermediate floors show a double break line (`UP` + `DN`), and the top floor shows no break line (`DN`).

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

In multi-office engineering environments operating across GstarCAD 2027, GstarCAD Mechanical, GstarCAD Architecture, and legacy AutoCAD (2018–2027) seats, mastering Course 33: Multi-Story Stair Towers, ADA/Accessible Ramps, Railings & Fire Egress Compliance requires understanding how the underlying AC1032 DWG binary database serializes entity handles, symbol table records, and Named Object Dictionary (NOD) pointers.

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
  3. Submittal Packaging & Mobile Review: Lock all Paper Space viewports (`DisplayLocked = Yes`), bind or relative-path all external references via ETRANSMIT, and verify final plotted PDF/A lineweights (`ISO full bleed`) alongside DWG FastView mobile cloud markup links.
