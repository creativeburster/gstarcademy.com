Course 06: GstarCAD Mechanical Setup — ISO/DIN/ASME Standards, Mechanical Layers & Associative BOM

Initialize GstarCAD Mechanical 2027 drawing standards, automatic mechanical layer routing (AM_0..AM_12), Part References (AMPARTREF), smart Balloons (AMBALLOON), and live Parts Lists.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Key Commands: AMOPTIONS, AMPARTREF, AMBALLOON, AMPARTLIST, AMBOM Last reviewed 2026-10-19 Editorial Process & Testbed

Course Technical Scope & Production Competencies

Standard vanilla CAD treats a mechanical center-line, a hidden contour, and a bill-of-materials balloon as dumb graphical primitives. GstarCAD Mechanical 2027 overlays an intelligent mechanical engineering schema (fully compatible with AutoCAD Mechanical ACM databases) that automatically routes geometry to ISO/DIN/ANSI/JIS/GB layers and links Part References directly to associative Parts Lists.

  • Initialize mechanical drawing standards (AMOPTIONS) across ISO 128, DIN, ANSI/ASME Y14.5, JIS B 0001, and GB/T, configuring automatic contour, hatch, dimension, and centerline layer routing.
  • Attach non-graphical engineering metadata (Part Number, Description, DIN/ISO Standard, Material, Mass) to sub-assemblies using AMPARTREF and generate associative leader balloons via AMBALLOON.
  • Compile live multi-level BOM databases (AMBOM) and place formatted Parts Lists (AMPARTLIST) that automatically re-index item numbers and sum quantities when components are duplicated or erased.

Module 1: GstarCAD Mechanical (ACM) Standards Governance, Intelligent Layers & Live BOM Databases

In GstarCAD Mechanical, invoking a mechanical command such as AMCONCLINE (construction line), AMHATCH, or AMPOWERDIM activates the intelligent layer manager: even if your active layer is currently set to contour layer AM_0, dimensions are automatically placed onto AM_6 and centerlines onto AM_7 with standard-compliant line weights (0.50mm vs. 0.25mm).

Because GstarCAD Mechanical reads and writes native ACM entity structures, legacy drawings created in AutoCAD Mechanical 2015–2027 open with 100% live BOM database associativity—allowing engineers to edit existing balloons and parts lists without exploding or rebuilding data tables.

Module 2: Step-by-Step Hands-On Command Execution Lab

Follow this structured 4-step laboratory procedure directly at the GstarCAD command line or dynamic input prompt:

  1. Step 1 — Environment & System Variable Initialization: At the command prompt, verify the active state of core commands and variables: AMOPTIONS, AMPARTREF, AMBALLOON, AMPARTLIST, AMBOM. Ensure that object snap bitcodes (OSMODE=175), associative dimensioning (DIMASSOC=2), and multi-core display regeneration (WHIPTHREAD=3) are active.
  2. Step 2 — Primary Geometry & Metadata Authoring: Execute the primary workflow on standardized ISO 13567 or discipline-specific layers. Never place production geometry or block definitions on Defpoints, and keep internal block geometry on Layer 0 so instances inherit host layer properties dynamically.
  3. Step 3 — Associative Verification & Revision Auditing: Test parametric associativity by stretching or modifying parent geometry and confirming that linked dimensions, attributes, schedules, or section views update automatically without disassociation warnings (ANNOMONITOR=2).
  4. Step 4 — Pre-Transmittal Quality Assurance (QA/QC): Prior to saving or publishing the deliverable, run OVERKILL to eliminate duplicate vectors, -PURGE (RegApps and All) to strip orphaned symbol table bloat, and AUDIT to verify 100% AcDbObject handle integrity.
