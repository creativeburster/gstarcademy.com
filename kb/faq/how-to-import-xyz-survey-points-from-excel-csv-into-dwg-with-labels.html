How to Import X,Y,Z Survey Points from Excel / CSV into GstarCAD with Point ID Labels

Two fast methods to import hundreds of PENZD (Point, Easting, Northing, Elevation, Description) survey coordinates from Excel or CSV into GstarCAD with 3D nodes and text labels.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Use an Excel CONCATENATE formula (="_POINT "&B2&","&C2&","&D2) pasted directly into the GstarCAD command bar, or run our high-speed AutoLISP CSV parser (IMPORT-PENZD-CSV) to generate 3D POINT nodes and Point ID / Elevation text labels automatically.

1. Root Cause & DWG Database Symptom Analysis

Field surveyors deliver topographic data as a comma-separated `.csv` or Excel `.xlsx` file containing Point Number, Easting ($X$), Northing ($Y$), Elevation ($Z$), and Feature Code ($D$). Plotting these points manually is impossible; here are the two fastest automated methods in GstarCAD.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Method 1: The 30-Second Excel Formula Paste Trick (Zero Coding)

In Excel, assuming `B2=X`, `C2=Y`, `D2=Z`, enter the formula ="_POINT "&B2&","&C2&","&D2 in column E and fill down. Set OSMODE = 0 (turn off Osnaps so points don't snap to existing geometry!), copy column E, click inside the GstarCAD command bar, and press Ctrl+V.

Method 2: Set PDMODE = 34 & PDSIZE = 1.0 So Imported Points Are Visible

By default, CAD points (`PDMODE = 0`) render as a single 1-pixel dot that is nearly invisible. Type PDMODE and enter 34 (circle with crosshairs) or 35 (box with X), and set PDSIZE to 1.5 (or `-2` for 2% of screen height).

Method 3: Direct AutoLISP PENZD Importer with Automatic Text Labels

Use the AutoLISP script below to read any `ID,X,Y,Z,Desc` CSV file and place both the 3D `POINT` node on layer `V-NODE-3D` and the Point ID / Elevation callout text on layer `V-NODE-TEXT` in milliseconds.

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
OSMODE = 0 Turn Off Osnaps First! Prevents pasted command-line coordinates from snapping to nearby lines
PDMODE = 34 / 35 Point Display Symbol 34 = Circle + Crosshair; 35 = Box + X (makes points clearly visible)
PDSIZE = -2 Relative Point Size Negative value sizes points as % of viewport; positive sets exact units
(entmake) CSV Loop 10,000 Points / Sec Bypasses command echo for instant large-topography ingestion

4. One-Click AutoLISP Fix Script (AutoLISP High-Speed CSV Survey Point & Label Importer)

(defun c:IMPORT-PENZD-CSV ( / fn fp line parts pt id zstr)
  (setvar "PDMODE" 34)
  (setvar "PDSIZE" 1.5)
  (if (setq fn (getfiled "Select Survey CSV (ID,X,Y,Z)" "" "csv;txt" 0))
    (progn
      (setq fp (open fn "r"))
      (while (setq line (read-line fp))
        (setq parts (acet-str-to-list "," line))
        (if (and (>= (length parts) 4) (numberp (read (nth 1 parts))))
          (progn
            (setq id   (nth 0 parts)
                  pt   (list (atof (nth 1 parts)) (atof (nth 2 parts)) (atof (nth 3 parts)))
                  zstr (rtos (caddr pt) 2 2))
            (entmake (list '(0 . "POINT") '(8 . "V-NODE-3D") (cons 10 pt)))
            (entmake (list '(0 . "TEXT") '(8 . "V-NODE-TEXT") (cons 10 pt)
                           '(40 . 1.8) (cons 1 (strcat id " (" zstr ")")))))))
      (close fp)
      (command "_.ZOOM" "_E")
      (princ "\n[Survey Import] Imported 3D points and labels from CSV.")))
  (princ)
)

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.
