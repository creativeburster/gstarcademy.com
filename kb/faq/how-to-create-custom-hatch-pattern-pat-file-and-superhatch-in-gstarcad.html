How to Create Custom Hatch Patterns (.PAT) and Use SUPERHATCH in GstarCAD

Learn how to write vector .pat hatch pattern definitions (angle, origin, delta-x, delta-y, dash-gap) and tile blocks or raster textures using SUPERHATCH in GstarCAD.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

For simple repeating linear/brick patterns, create an ASCII .pat file named identically to the pattern (*MY_BRICK) inside your GstarCAD Support folder (ending with a mandatory blank carriage-return line). For complex curved tiles, stone masonry, or wood textures, use the Express Tool SUPERHATCH with a Block or Image.

1. Root Cause & DWG Database Symptom Analysis

Architectural elevations, landscaping paving plans, and geological cross-sections often require custom tile ratios, staggered timber cladding, or irregular stone patterns that go beyond standard `ANSI31` or `AR-BRSTD` hatches in GstarCAD.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Understand the 5-Parameter .PAT Vector Line Syntax

Each line in a `.pat` file defines an infinite family of parallel lines: Angle, X-Origin, Y-Origin, Delta-X, Delta-Y, [Dash, -Gap...]. Here, Delta-Y is the perpendicular spacing between parallel lines, while Delta-X shifts the dash pattern along each successive parallel line (used for staggered brick running bonds!).

Step 2: The Golden Rule of Custom .PAT Files

When saving a standalone custom pattern file (e.g., EuroTile_600x300.pat), the filename must exactly match the pattern header name (*EuroTile_600x300, 600x300mm Porcelain Tile), and you must leave at least one blank empty line at the bottom of the file or GstarCAD/AutoCAD will throw a "Missing parameter on line..." error.

Step 3: Use SUPERHATCH for Curved Roof Tiles, Blocks & Raster Textures

Because `.pat` files only support straight line segments and dots, use SUPERHATCH (Express Tools) to tile any CAD `BLOCK`, `XREF`, `WIPEOUT`, or raster `IMAGE` inside a closed boundary with automatic boundary clipping!

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
Delta-Y Perpendicular Spacing Distance between parallel hatch lines in the family
Delta-X Stagger Shift Shifts dashed segments along alternate rows (staggered brick/tile)
Trailing Blank Line Mandatory in .PAT Prevents 'Bad pattern definition' EOF parser error
SUPERHATCH Express Command Tiles any Block or Raster Image inside a closed polyline boundary

4. One-Click AutoLISP Fix Script (AutoLISP Custom 600x300mm Staggered Running-Bond Tile .PAT Generator)

(defun c:MAKE-TILE-PAT ( / fn fp)
  (setq fn (strcat (getvar "ROAMABLEROOTPREFIX") "Support\\TILE600X300.pat")
        fp (open fn "w"))
  (write-line "*TILE600X300, 600x300mm Staggered Running Bond Tile" fp)
  (write-line "0, 0,0, 0,300" fp)               ; Continuous horizontal joints every 300mm
  (write-line "90, 0,0, 300,300, 300,-300" fp)  ; Vertical joints staggered every 300/600mm
  (write-line "" fp) ; Mandatory trailing blank line!
  (close fp)
  (princ (strcat "\n[PAT Generator] Created custom hatch: " fn))
  (princ)
)
