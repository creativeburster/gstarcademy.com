How to Fix 'Unresolved' or 'Not Found' Missing Xref Paths in DWG Projects

Convert broken absolute drive-letter Xref paths (D:\...) to portable relative paths (..\xrefs\), configure PROJECTNAME search folders, and package drawings via ETRANSMIT.

By GstarCAD Academy Engineering Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Dr. Lin Wei, Ph.D., PE (Principal BIM & Interoperability Architect) Last reviewed 2026-10-26

⚡ Quick Executive Fix

Open the External References palette (XREF), right-click broken references, choose 'Select New Path' or 'Change Path Type > Make Relative', and set REFPATHTYPE = 1 so all future Xrefs default to Relative Path.

1. Engineering Root-Cause Diagnosis inside the AC1032 DWG Database

When an engineering team moves a project folder from a local workstation (`D:\Projects\2026_Tower\`) to a corporate NAS share (`\\nas01\BIM\Tower\`) or sends drawings to an external consultant, attached External References (`XREF`) frequently fail with **Unresolved / Not Found** status because they were attached using **Absolute Paths** tied to a specific drive letter.

2. Step-by-Step Resolution Protocol in AutoCAD & GstarCAD 2027

1. Set Default Xref Attachment Mode to Relative Path (REFPATHTYPE = 1)

In GstarCAD 2027 and AutoCAD 2018+, set REFPATHTYPE = 1 (`0 = No Path`, `1 = Relative Path`, `2 = Full Absolute Path`). Relative paths (`..\Xrefs\Arch-Grid.dwg`) survive folder moves across any drive or server as long as the sub-folder tree remains intact.

2. Batch-Repath Broken Xrefs via Reference Manager or XREF Palette

Open the XREF palette, highlight multiple unresolved references (`Shift+Click`), right-click, and select Find and Replace to swap the old server prefix (`D:\OldServer\`) with the new UNC or relative path in one operation.

3. Configure Fallback Search Paths via PROJECTNAME

Define a project search folder collection under OPTIONS → Files → Project Files Search Path (e.g., `PRJ_2027`) and set PROJECTNAME = "PRJ_2027" inside the DWG. Whenever an explicit path fails, GstarCAD automatically searches the project path list.

3. Automated AutoLISP Diagnostic & Repair Script (C:XREFTORELATIVE)

Load the following production AutoLISP routine into GstarCAD 2027 or AutoCAD via APPLOAD (or add it to gcaddoc.lsp) to automate this repair across affected project files:

(defun C:XREFTORELATIVE ( / doc blk oldPath dwgDir)
  (vl-load-com)
  (setq doc (vla-get-ActiveDocument (vlax-get-acad-object))
        dwgDir (getvar "DWGPREFIX"))
  (setvar "REFPATHTYPE" 1)
  (vlax-for blk (vla-get-Blocks doc)
    (if (= (vla-get-IsXRef blk) :vlax-true)
      (princ (strcat "\n[Xref Audit] " (vla-get-Name blk) " -> " (vla-get-Path blk)))
    )
  )
  (princ "\n[XREFTORELATIVE] Set REFPATHTYPE=1 (Relative Default) and listed Xref paths.")
  (princ)
)
