How to Create Sheets, Views & Drawing Sets in Revit: Viewports, Title Blocks & Revisions

Complete Revit documentation guide: creating title block sheets, placing and scaling floor plan/section views, managing sheet numbering conventions, and automated revision tracking.

Author: Gstarcademy Engineering Editorial Board Updated: 2026-08-16

⚡ Quick Answer / Key Takeaway

To create a sheet in Revit: Right-click 'Sheets (all)' in the Project Browser > New Sheet, select your company Title Block family (e.g., A1 Metric), drag desired views (Floor Plans, Elevations, Sections) from the Project Browser onto the sheet, and organize view titles.

Step-by-Step Instructions & Commands

Step 1: Creating a New Sheet and Loading Title Blocks

In the Project Browser, right-click Sheets and choose New Sheet. Choose an existing title block family or click Load to import a custom corporate title block (.RFA). Set sheet properties in the Properties palette: Sheet Number (e.g., A-101), Sheet Name (e.g., GROUND FLOOR PLAN), Drawn By, and Checked By.

Step 2: Placing Views and Managing Viewport Scales

Drag any plan, section, callout, or 3D view directly from the Project Browser onto the sheet area. Click to place. The Viewport Scale is controlled by the source view properties (e.g., 1:100 or 1:50). Note: A standard Revit model view can only be placed on ONE sheet at a time; to place the same view on multiple sheets, right-click the view > Duplicate as a Dependent.

Step 3: Configuring View Titles and Grid Alignment

Click the placed viewport to adjust its position. Click the View Title line independently to move it or adjust its length. Use Viewport Guide Grids (View tab > Guide Grid) to align floor plans, grids, and title blocks across consecutive sheets identically.

Step 4: Managing Sheet Lists & Automated Revisions

Create an automated drawing index: Go to View > Schedules > Sheet List. Add Sheet Number, Sheet Name, Current Revision, and Issue Date. Use the Sheet Issues/Revisions dialog (View tab) to log Delta Revisions (Add / Cloud / Issue), which automatically updates revision tables in title blocks.

Common Issues & Troubleshooting Guide

Common Failure / Problem Root Cause & Recommended Solution
Error: 'View is already placed on Sheet A-102' Revit enforces a strict rule that model views can only exist on a single sheet. To show the same view on another sheet, right-click the view in Project Browser > Duplicate View > Duplicate as a Dependent or Duplicate with Detailing.
Floor plan view boundaries overlap the entire sheet The view's Crop Region is too large or unclipped. Open the source view, check 'Crop View' and 'Crop Region Visible' in Properties, and drag the rectangular crop boundary handles tight around your building geometry.
Grid lines and level markers disappear on sheets Ensure Grid 3D extents intersect the view's cut plane, or adjust the Crop Region to include grid heads. Check Visibility/Graphic Overrides (VG) > Annotation Categories to confirm Grids are turned on.

Cross-CAD Compatibility & Alternatives

Revit sheets can be batch-exported to PDF or multi-layer DWG files using custom Layer Export Mapping (File > Export > CAD Formats > DWG > Export Setup).

Engineering Best Practices Checklist

  • Use View Templates to enforce consistent scale, detail level, and category visibility across all plan sheets.
  • Establish strict Sheet Numbering conventions (e.g., Disciplinary Prefix-Level-SheetType: A-101, M-201, S-301).
  • Leverage Guide Grids to ensure identical viewport placement and alignment across multi-story buildings.
  • Track project milestones with the integrated Sheet Issues/Revisions tool for automated title block updates.
