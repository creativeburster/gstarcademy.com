SOLIDWORKS File Formats Explained

Guide to SOLIDWORKS file types: SLDPRT, SLDASM, SLDDRW, eDrawings, and export formats (STEP, IGES, STL, PDF).

By Gstarcademy Editorial Team Updated 2026-06-30

What are the main SOLIDWORKS file types?

SLDPRT = Part file (single component), SLDASM = Assembly file (multiple parts constrained together), SLDDRW = Drawing file (2D documentation). Supporting: SLDDRT (drawing template), SLDLFP (library feature part), SLDPRT (sheet format).

What format should I use for 3D printing?

Export as STL (tessellated mesh) for FDM/SLA printers, or 3MF (newer, includes color/material info). Set resolution appropriately — Coarse for quick checks, Fine for production. Check for non-manifold geometry before export.

What format for sharing with non-SOLIDWORKS users?

STEP (.stp) is the universal choice for 3D data exchange. Use AP214 for visual properties. For viewing-only, eDrawings (.eprt/.easm) is free to view. For 2D drawings, export to PDF with embedded 3D (File > Save As > PDF with 3D option).
