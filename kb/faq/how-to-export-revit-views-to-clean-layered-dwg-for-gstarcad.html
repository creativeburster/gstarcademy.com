How to Export Revit Views to Clean, Standard-Layered DWG Files for GstarCAD

Step-by-step BIM-to-CAD export configuration in Autodesk Revit to produce clean ISO 13567 or AIA layered AC1032 DWG drawings with true polylines and colors for GstarCAD.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Dr. Lin Wei, Ph.D., PE (Principal BIM & Interoperability Architect) Last reviewed 2026-11-03 Editorial Process & Testbed
⚡ Quick Engineering Answer (TL;DR)

In Revit, go to File -> Export -> CAD Formats -> DWG, click the '...' Modify Export Setup button, map categories to AIA or ISO 13567 layers, set Colors to 'Index Color (255 Colors)' instead of TrueColor, set Polylines to 'Export rooms and areas as polylines', and export to AutoCAD 2018 DWG (AC1032) format.

1. Root Cause & DWG Database Symptom Analysis

Default Revit DWG exports often dump thousands of fragmented lines onto cryptically named layers with RGB TrueColor overrides (which bypass .ctb plot style tables in GstarCAD and AutoCAD) and split solid hatches into hundreds of individual triangles.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Configure Layer Mapping Standard (AIA / ISO 13567 / BS1192)

Open Modify DWG/DXF Export Setup → Layers tab and load the built-in AIA or ISO 13567 mapping table. Set Export layer options to Export category properties BYLAYER and overrides BYENTITY so objects inherit standard layer colors and linetypes.

Step 2: Force Index Colors (ACI 1–255) & TrueType Font Mapping

Switch to the Colors tab and select Index color (255 colors)—never leave it on Specified in view (True Color RGB) if your team plots with monochrome or grayscale .ctb tables! Under Units & Coordinates, select Shared Coordinates for civil site coordination or Internal Origin for architectural details.

Step 3: Run OVERKILL & PURGE in GstarCAD Post-Export

Open the exported DWG in GstarCAD, run OVERKILL (tolerance 0.01 mm) to merge overlapping wall projection segments, and run -PURGE → All to strip unused Revit view blocks.

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
Colors Tab Index Color (255 ACI) Ensures .ctb plot style tables control lineweights & black ink
Solids Tab (3D Views) ACIS Solids Exports watertight 3D solids instead of triangulated polyface meshes
Units & Coordinates Shared Coordinates Aligns exported DWG directly with Civil survey Xrefs
General -> File Format AutoCAD 2018 DWG (AC1032) 100% native format for GstarCAD 2027 without proxy warnings

4. One-Click AutoLISP Fix Script (AutoLISP Post-Revit Export TrueColor-to-ByLayer Cleaner)

(defun c:CLEAN-REVIT-DWG ( / ss i ent elist)
  (if (setq ss (ssget "_X"))
    (progn
      (setq i 0)
      (while (< i (sslength ss))
        (setq ent (ssname ss i) i (1+ i) elist (entget ent))
        ; Remove DXF 420 TrueColor override and force Color 256 (ByLayer)
        (setq elist (vl-remove-if '(lambda (x) (= (car x) 420)) elist))
        (if (assoc 62 elist)
          (setq elist (subst '(62 . 256) (assoc 62 elist) elist))
          (setq elist (append elist '((62 . 256)))))
        (entmod elist))))
  (command "_.REGEN")
  (princ "\n[Revit Cleaner] Stripped RGB TrueColor overrides -> ByLayer.")
  (princ)
)
