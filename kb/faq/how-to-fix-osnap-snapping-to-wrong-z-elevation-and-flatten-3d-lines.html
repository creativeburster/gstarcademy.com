How to Fix OSNAP Snapping to Wrong Z-Elevations and Flatten Non-Coplanar 3D Lines

Stop accidental non-zero Z coordinates in 2D drawings by enabling OSNAPZ = 1 and flattening elevated lines, polylines, and blocks back to Z = 0 in GstarCAD.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Type OSNAPZ and set it to 1 (paired with ELEVATION = 0) so all future object snaps automatically project onto the Z=0 XY plane. To flatten existing elevated geometry, run the Express Tool FLATTEN or use our high-speed Z-Zero AutoLISP normalizer.

1. Root Cause & DWG Database Symptom Analysis

When drafting over civil topographic contours or imported BIM backgrounds, snapping a 2D line from a contour at $Z = 142.50\text{ m}$ to a column at $Z = 0.00\text{ m}$ creates a skewed 3D space diagonal. Suddenly, DIST reports the wrong horizontal length, FILLET fails with "Lines are non-coplanar", and hatches refuse to close.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Lock OSNAPZ = 1 & ELEVATION = 0 Immediately

Type ELEVATION and enter 0, then type OSNAPZ and enter 1. With OSNAPZ = 1, even if you snap directly to a 3D survey point at $Z = 500\text{ m}$, GstarCAD automatically substitutes $Z = 0$ for the picked coordinate!

Step 2: Flatten Existing 3D Lines, Arcs & Polylines to Z = 0

Select the affected geometry and run the built-in Express command FLATTEN (answer No to Remove hidden lines?). Alternatively, for simple lines and polylines, select them in the Properties Palette (`Ctrl+1`) and set Start Z = 0, End Z = 0, and Elevation = 0.

Step 3: The Classic 1e99 Displacement Trick (Universal Fallback)

If third-party proxy objects resist `FLATTEN`, run MOVE → All → Basepoint 0,0,0 → Second point 0,0,1e99, then immediately run MOVE → Previous → Basepoint 0,0,0 → Second point 0,0,-1e99 to crush floating-point Z values to zero.

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
OSNAPZ 1 (Active Session) Replaces the Z-value of any Osnap point with current ELEVATION (0.0)
ELEVATION 0.0 (Drawing) Sets default Z-plane height for new 2D objects
FLATTEN Express Command Projects 3D objects onto the current UCS XY plane
DXF Group 38 0.0 (LWPOLYLINE) Stores the constant Z-elevation of a 2D lightweight polyline

4. One-Click AutoLISP Fix Script (AutoLISP Direct DXF Z=0 Flattener (Preserves Blocks & Layers))

(defun c:ZERO-Z-FAST ( / ss i ent elist)
  (setvar "ELEVATION" 0.0)
  (setvar "OSNAPZ" 1)
  (if (setq ss (ssget "_X" '((0 . "LINE,LWPOLYLINE,CIRCLE,ARC,INSERT,TEXT,MTEXT"))))
    (progn
      (setq i 0)
      (while (< i (sslength ss))
        (setq ent (ssname ss i) i (1+ i) elist (entget ent))
        (if (assoc 38 elist) (setq elist (subst '(38 . 0.0) (assoc 38 elist) elist)))
        (foreach code '(10 11)
          (if (assoc code elist)
            (setq elist (subst (list code (cadr (assoc code elist)) (caddr (assoc code elist)) 0.0)
                               (assoc code elist) elist))))
        (entmod elist))))
  (princ "\n[Z-Zero] Forced Z=0.0 across Model Space and locked OSNAPZ=1.")
  (princ)
)
