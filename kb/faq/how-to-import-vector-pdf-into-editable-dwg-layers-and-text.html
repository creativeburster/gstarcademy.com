How to Import Vector PDF Files into Editable DWG Polylines, Layers & TrueType Text

Convert vector PDF engineering drawings into accurate 1:1 CAD lines, arcs, layers, and editable MTEXT using PDFIMPORT and PDFSHXTEXT in GstarCAD 2027 and AutoCAD.

By GstarCAD Academy Engineering Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Zhang Mingyuan, B.Eng. (Distinguished DWG Graphics Kernel & GRX SDK Architect) Last reviewed 2026-10-26

⚡ Quick Executive Fix

Run PDFIMPORT, press Enter to choose 'File', select the vector PDF page, check 'Use PDF Layers', 'Import TrueType text', and 'Join line and arc segments', then scale the imported geometry to true 1:1 dimensions via ALIGN or SCALE > Reference.

1. Engineering Root-Cause Diagnosis inside the AC1032 DWG Database

Engineers frequently receive legacy equipment drawings or municipal utility plans exclusively in `.pdf` format. Provided the PDF was originally plotted from a CAD vector driver (rather than scanned on a flatbed copier as a raster JPEG/TIFF bitmap), the PDF stream contains exact mathematical Bézier curves, vector line segments, PDF layer groups (`Optional Content Groups`), and TrueType glyph strings that GstarCAD 2027's **`PDFIMPORT`** command reconstructs directly into native AC1032 DWG entities.

2. Step-by-Step Resolution Protocol in AutoCAD & GstarCAD 2027

1. Run PDFIMPORT with Optimal Vector Reconstruction Options

Type PDFIMPORT, choose File, and select the target PDF page. In the import dialog, enable **Vector geometry**, **Solid fills**, **TrueType text**, **Use PDF layers** (creates `PDF_A-WALL` layers), and **Joinigham line and arc segments into polylines**.

2. Convert Exploded SHX Stick-Font Lines Back to MTEXT (PDFSHXTEXT)

Because CAD `.shx` fonts are plotted to PDF as tiny geometric strokes, imported SHX labels initially arrive as hundreds of tiny polylines. Run PDFSHXTEXT (`Recognition Settings`), check `simplex.shx` and `romans.shx`, and select the stroked geometry to convert it back into editable `MTEXT`!

3. Calibrate True 1:1 Engineering Scale via SCALE > Reference

Measure a known dimension line on the imported PDF geometry using `DIST`. Run SCALE, select all imported objects, pick a base point, type R (Reference), click the two endpoints of the known dimension line, and type its true real-world length (e.g., `6000`).

3. Automated AutoLISP Diagnostic & Repair Script (C:PDFCALSCALE)

Load the following production AutoLISP routine into GstarCAD 2027 or AutoCAD via APPLOAD (or add it to gcaddoc.lsp) to automate this repair across affected project files:

(defun C:PDFCALSCALE ( / ss p1 p2 trueDist curDist scaleFac)
  (princ "\nSelect imported PDF geometry to calibrate to 1:1 scale: ")
  (if (and (setq ss (ssget))
           (setq p1 (getpoint "\nClick FIRST endpoint of a known dimension line: "))
           (setq p2 (getpoint p1 "\nClick SECOND endpoint of the known dimension line: "))
           (setq trueDist (getreal "\nEnter the TRUE engineering length of that dimension: ")))
    (progn
      (setq curDist  (distance p1 p2)
            scaleFac (/ trueDist curDist))
      (command "_.SCALE" ss "" "_non" p1 scaleFac)
      (princ (strcat "\n[PDFCALSCALE] Scaled geometry by factor " (rtos scaleFac 2 6) " to exact 1:1 units."))
    )
  )
  (princ)
)

4. Diagnostic System Variables & Edge-Case Matrix

Failure Symptom / Scenario Command / SysVar Production Remediation Rule
PDFIMPORT imports only an image frame, no lines Scanned Raster PDF The PDF is a scanned bitmap image; use Raster-to-Vector tracing instead.
Imported text is made of tiny line segments PDFSHXTEXT Original CAD used SHX fonts; run PDFSHXTEXT OCR to rebuild MTEXT.
Imported drawing measures 60mm instead of 6000mm SCALE > Reference (R) PDF was imported at 1:100 paper scale; scale by 100 or use Reference.
