How to Import Rhino (.3DM) NURBS Curves, Surfaces & Solids into GstarCAD Cleanly

Engineering guide to exchanging complex freeform NURBS geometry, façade panels, and 2D Make2D projections between McNeel Rhinoceros (.3dm) and GstarCAD DWG.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

When exporting from Rhino to GstarCAD, use the '2007 Solids' or '2018 Solids' DWG scheme for 3D BREPs/NURBS surfaces (stored as ACIS bodies), and use the '2004 Polylines' scheme (with chord height tolerance = 0.05 mm) when exporting 2D façade laser-cutting panels.

1. Root Cause & DWG Database Symptom Analysis

Complex double-curved architectural façades and marine hulls modeled in Rhino (`.3dm`) use degree-3 and degree-5 NURBS math. Exporting with the wrong DWG scheme turns smooth NURBS curves into millions of tiny straight line segments or explodes closed polysurfaces into unconnected faces.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Preserving True 3D NURBS & Closed Polysurfaces (ACIS Solids)

In Rhino, select your closed polysurfaces and curves, run Export → AutoCAD Drawing (*.dwg), and edit the Export Scheme: set Surfaces as: Solids and Meshes as: Meshes, targeting DWG version 2018 (AC1032). When opened in GstarCAD, closed polysurfaces arrive as native `3DSOLID` entities ready for `UNION`, `SUBTRACT`, and `MASSPROP`.

Step 2: Exporting 2D Unrolled Panels & Make2D Drawings for Fabrication

After running `UnrollSrf` or `Make2D` in Rhino, run `SimplifyCrv` first. If downstream CNC routers require arc-fitted polylines instead of Degree-3 `SPLINE` entities, convert curves using Rhino's `Convert` (`Output=Arcs`, `AngleTolerance=1deg`, `Tolerance=0.05mm`) or convert them inside GstarCAD via `SPLINEDIT`.

Step 3: Controlling SPLINESEGS & FACETRES in GstarCAD

If imported NURBS curves look jagged on screen in GstarCAD, type VIEWRES → Yes → 20000 and FACETRES → 8 followed by REGENALL—the underlying mathematical NURBS curve is already exact; only the display tessellation needed refreshing.

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
PLINECONVERTMODE = 1 GstarCAD System Variable Forces SPLINEDIT to generate smooth tangent arcs instead of line segments
VIEWRES = 20000 Display Resolution Eliminates visual polygonal faceting on true arcs and splines
FACETRES = 8..10 3D Solid Tessellation Smooths shaded and hidden-line rendering of imported ACIS solids
SPLINEDIT -> Convert (10) Curve Conversion Converts Degree-3 NURBS into LWPOLYLINE with high chord accuracy

4. One-Click AutoLISP Fix Script (AutoLISP High-Precision NURBS Spline-to-Arc Polyline Converter)

(defun c:NURBS-TO-PLINE ( / ss i ent)
  (setvar "PLINECONVERTMODE" 1) ; 1 = Fit tangent arcs instead of straight segments
  (if (setq ss (ssget '((0 . "SPLINE"))))
    (progn
      (setq i 0)
      (while (< i (sslength ss))
        (setq ent (ssname ss i) i (1+ i))
        (command "_.SPLINEDIT" ent "_P" 10))))
  (princ "\n[NURBS Converter] Converted selected SPLINEs to arc-fitted LWPOLYLINEs.")
  (princ)
)

Enterprise AC1032 Database Internals & Cross-Version Diagnostics

1. DWG Header & Registry Persistence Scope

Variables and object properties fall into three persistence scopes: Drawing-Saved (DXF Header) variables that travel with the .dwg file to subcontractors, Registry-Saved (Profile .arg) settings that persist per Windows workstation user, and Session-Volatile states that reset on every launch unless locked inside acaddoc.lsp. Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).

2. Multi-Core Regeneration & Memory Hygiene

When processing large civil corridors, dense plant P&IDs, or 50-sheet architectural Xref trees, unpurged Registered Application IDs (REGAPP), orphaned DGN stroke dictionaries, and redundant annotation scales degrade spatial index (INDEXCTL = 3) lookup speed. Executing a pre-submittal AUDIT, command-line -PURGE → Regapps, and OVERKILL pass keeps file open times under 2 seconds on GstarCAD's multi-threaded graphics kernel.

3. Hybrid AutoCAD + GstarCAD Team Coexistence

Because GstarCAD reads and writes native AC1032 binary records without intermediate import/export translation, dynamic block grips, associative hatches, XData payloads (DXF groups 1000–1071), Paper Space viewport layer overrides (VPLAYER), and X.509 digital signatures round-trip losslessly between AutoCAD and GstarCAD seats on shared SMB/BIM cloud folders.

Production Field Verification Protocol (ISO 9001 / ISO 19650 Gate)

  1. Baseline Template Audit: Confirm that the active drawing inherits layer naming, linetype scales (PSLTSCALE = 1, MSLTSCALE = 1, LTSCALE = 1.0), and dimension styles from the enterprise .dwt / .dws standards file via CHECKSTANDARDS.
  2. Coordinate & Unit Integrity: Run -DWGUNITS or check INSUNITS, LUNITS, and MEASUREMENT to guarantee 1:1 metric (`mm`/`m`) or imperial (`in`/`ft`) block and Xref insertion scaling, with OSNAPZ = 1 preventing unintended 3D elevation drift.
