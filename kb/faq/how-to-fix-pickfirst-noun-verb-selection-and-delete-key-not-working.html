How to Fix PICKFIRST: Pre-Selected Objects Dropped and DELETE Key Not Working in CAD

Restore noun-verb selection, the keyboard DELETE key, and Shift-to-deselect behavior by resetting PICKFIRST, PICKADD, and PICKAUTO in GstarCAD and AutoCAD.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Type PICKFIRST at the command prompt and set it to 1, then set PICKADD to 2 and PICKAUTO to 1. This immediately restores the ability to select objects first and press the DELETE key, launch commands on pre-selected objects, and view properties in Ctrl+1.

1. Root Cause & DWG Database Symptom Analysis

If you select 10 lines on screen, press the DELETE key on your keyboard, and nothing happens—or you select objects, type M (`MOVE`), and the software drops your selection and asks "Select objects:" all over again—a poorly written third-party LISP script crashed mid-execution and left PICKFIRST = 0.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Set PICKFIRST = 1 to Restore Noun-Verb Selection & DELETE Key

Type PICKFIRST in the command line and enter 1. In GstarCAD and AutoCAD, Noun-Verb Selection (picking the objects first, then invoking the action or pressing `DELETE`) is controlled entirely by `PICKFIRST`.

Step 2: Set PICKADD = 2 So Clicking Additional Objects Doesn't Drop Previous Ones

If clicking a second line automatically deselects the first line (forcing you to hold `SHIFT` to add objects), someone clicked the `+ / 1` icon at the top of the Properties palette. Type PICKADD and set it to 2.

Step 3: Set PICKAUTO = 1 for Automatic Crossing / Window Selection

Type PICKAUTO and set it to 1 (or `5`) so clicking in empty space automatically starts a Left-to-Right blue Window or Right-to-Left green Crossing selection box.

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
PICKFIRST 1 (Registry) Enables Noun-Verb selection, DELETE key, and Properties palette updates
PICKADD 2 (Registry) Clicking adds to selection set; holding SHIFT removes from selection
PICKAUTO 1 or 5 (Registry) Automatically starts Window/Crossing selection when clicking empty space
QAFLAGS 0 (Must be 0!) If QAFLAGS > 0, grip stretching and selection preview break; always keep 0

4. One-Click AutoLISP Fix Script (AutoLISP 1-Click Selection System Variables Restorer)

(defun c:FIX-SELECTION ()
  (setvar "PICKFIRST" 1) ; Enable Noun-Verb selection & Delete key
  (setvar "PICKADD"   2) ; Additive selection (Shift to remove)
  (setvar "PICKAUTO"  1) ; Automatic Window/Crossing box in empty space
  (setvar "PICKDRAG"  2) ; Support both click-click and click-drag selection
  (princ "\n[Selection Restored] PICKFIRST=1, PICKADD=2, PICKAUTO=1.")
  (princ)
)
