How to Convert SPLINE to Polyline (LWPOLYLINE) with Exact Arcs vs. Line Segments

Convert NURBS splines into lightweight polylines (LWPOLYLINE) in GstarCAD using SPLINEDIT, PEDIT, and PLINECONVERTMODE = 1 for smooth tangent arcs without excessive vertices.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Set the system variable PLINECONVERTMODE to 1 (Arcs) instead of 0 (Lines), then run SPLINEDIT (or PEDIT), select the spline, choose 'Convert to Polyline', and enter a precision value between 5 and 10.

1. Root Cause & DWG Database Symptom Analysis

Converting a freeform SPLINE (imported from Illustrator, Rhino, or SolidWorks) into an LWPOLYLINE with the wrong settings generates thousands of microscopic straight line segments that choke CNC controllers and bloat DWG file size.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Set PLINECONVERTMODE = 1 to Generate Tangent Arcs

Before converting any spline in GstarCAD, type PLINECONVERTMODE and set it to 1. When set to 0, conversion tessellates curves into faceted straight segments; when set to 1, GstarCAD fits smooth tangent circular arcs (`Bulge != 0`) with 90% fewer vertices!

Step 2: Convert Single or Multiple Splines via SPLINEDIT or PEDIT

Run SPLINEDIT, pick a spline, type P (Convert to Polyline), and enter a precision from 0 (coarse) to 99 (ultra-fine; 10 is ideal for engineering and CNC work). To convert dozens of splines at once, run PEDIT → Multiple, select all splines, confirm conversion, and enter precision 10.

Step 3: Preserve Original Splines on a Backup Layer via DELOBJ

If you want to keep the original mathematical NURBS spline while generating a polyline copy, set DELOBJ = 0 before converting, or copy the splines to a frozen `G-CONSTRUCTION-NURBS` layer first.

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
PLINECONVERTMODE = 1 Arc Segments (Recommended) Fits true circular arcs (G02/G03) with minimal vertex count
PLINECONVERTMODE = 0 Linear Segments Approximates curves using short straight lines (for polygonal GIS)
Precision (0..99) 10 (Standard Engineering) Controls chordal deviation tolerance; >25 rarely needed
PEDIT -> Multiple Batch Selection Converts hundreds of selected SPLINE entities in one operation

4. One-Click AutoLISP Fix Script (AutoLISP Batch Arc-Fitted Spline-to-Polyline Converter)

(defun c:BATCH-SPLINE2PLINE ( / prec ss)
  (setvar "PLINECONVERTMODE" 1) ; Fit smooth arcs
  (setq prec (getint "\nEnter Conversion Precision (1-99, Recommended 10) <10>: "))
  (if (not prec) (setq prec 10))
  (if (setq ss (ssget '((0 . "SPLINE"))))
    (command "_.PEDIT" "_M" ss "" "_Y" prec ""))
  (princ (strcat "\n[Spline->Pline] Converted splines to arc-polylines at precision " (itoa prec)))
  (princ)
)
