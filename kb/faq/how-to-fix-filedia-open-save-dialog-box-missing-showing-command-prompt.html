How to Fix FILEDIA: Open, Save & Plot File Dialog Box Missing (Showing Command Prompt)

Instant fix when clicking Open, Save As, or Export in GstarCAD or AutoCAD prompts for a file path on the command line instead of opening the Windows File Explorer dialog.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Type FILEDIA at the command prompt, press Enter, and type 1. Also set CMDDIA to 1 and ATTDIA to 1. This immediately restores the graphical Windows File Open/Save dialog boxes.

1. Root Cause & DWG Database Symptom Analysis

You press Ctrl+O or Ctrl+S, and instead of the standard Windows file browser window appearing, the command line asks: "Enter name of drawing to open <C:\...>:". This classic CAD symptom occurs whenever a batch script or LISP routine suppresses file dialogs via FILEDIA = 0 and exits before restoring FILEDIA = 1.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Reset FILEDIA = 1 and CMDDIA = 1

Type FILEDIA and enter 1, then type CMDDIA and enter 1. Your graphical Open, Save As, Xref Attach, and Layer State dialogs will return immediately in GstarCAD.

Step 2: Pro Tip — Press the Tilde (~) Key to Force a Dialog Anytime

Even if FILEDIA = 0 (or when running a command-line-only command like -INSERT or -VBARUN), typing a single tilde character ~ and pressing Enter at any filename prompt forces the graphical Windows file dialog box to open!

Step 3: Enable ATTDIA = 1 for Block Attribute Dialog Boxes

If inserting an attributed title block prompts for tags on the command line instead of opening the graphical Attribute Entry dialog, type ATTDIA and set it to 1 (and verify ATTREQ = 1).

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
FILEDIA 1 (Registry) Displays Windows GUI file navigation dialog boxes for Open/Save/Export
CMDDIA 1 (Registry) Enables graphical dialog boxes for PLOT, ARRAY, and database commands
ATTDIA 1 (Registry) Opens a dialog box when inserting blocks containing attributes
~ (Tilde Key) Prompt Shortcut Typing ~ at any command-line file prompt forces the GUI file browser

4. One-Click AutoLISP Fix Script (AutoLISP Error-Safe Dialog Box Guard (*error* Handler Template))

; Always restore FILEDIA=1 and CMDDIA=1 even if user presses ESC during a script
(defun c:RESTORE-DIALOGS ()
  (setvar "FILEDIA" 1)
  (setvar "CMDDIA"  1)
  (setvar "ATTDIA"  1)
  (setvar "ATTREQ"  1)
  (princ "\n[Dialog Guard] FILEDIA=1, CMDDIA=1, ATTDIA=1 restored.")
  (princ)
)
