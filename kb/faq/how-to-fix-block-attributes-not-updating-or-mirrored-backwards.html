How to Fix Block Attributes Not Updating (ATTSYNC) or Reading Backwards When Mirrored

Synchronize modified block attribute definitions across existing insertions via ATTSYNC/BATTMAN and stop mirrored text from flipping upside-down using MIRRTEXT = 0.

By GstarCAD Academy Engineering Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-10-26

⚡ Quick Executive Fix

Run ATTSYNC > Select and click an instance of the modified block to push new/moved attribute definitions to all existing insertions. To fix mirrored text reading backwards, set MIRRTEXT = 0 and re-mirror the block.

1. Engineering Root-Cause Diagnosis inside the AC1032 DWG Database

Unlike geometric lines inside an `AcDbBlockTableRecord`—which update automatically across every insertion when edited in `BEDIT`—**Block Attributes (`AcDbAttributeDefinition` → `AcDbAttribute`)** are copied as independent child entities (`SEQEND`-terminated sub-chains) attached to each individual `AcDbBlockReference` at the moment of insertion. Consequently, adding a new `ATTDEF`, deleting a tag, or moving an attribute inside the Block Editor does not automatically alter existing block references until you explicitly synchronize the attribute table.

2. Step-by-Step Resolution Protocol in AutoCAD & GstarCAD 2027

1. Push Attribute Changes to Existing Blocks via ATTSYNC

After saving changes in the Block Editor (`BEDIT`), type ATTSYNC, choose Select (or `Name`), click one instance of the block, and confirm Yes. GstarCAD 2027 updates all instances while preserving the custom text values already typed into existing tags.

2. Reorder Attribute Prompt Sequence & Visibility via BATTMAN

Run BATTMAN (Block Attribute Manager) to reorder the prompt order, rename tags without losing existing values, or toggle Invisible mode across all insertions.

3. Prevent Mirrored Block Text & Attributes from Flipping Backwards

Set system variable MIRRTEXT = 0 (default is `0`; if set to `1`, `MIRROR` reverses text like a physical mirror). Note that for an attribute inside a block to stay right-reading when the block is mirrored, the attribute must be a single-line or multiline `ATTDEF` (not exploded raw lines), and `ATTSYNC` should be run if `Lock Position = Yes`.

3. Automated AutoLISP Diagnostic & Repair Script (C:SYNCALLBLOCKS)

Load the following production AutoLISP routine into GstarCAD 2027 or AutoCAD via APPLOAD (or add it to gcaddoc.lsp) to automate this repair across affected project files:

(defun C:SYNCALLBLOCKS ( / doc blk name)
  (vl-load-com)
  (setvar "MIRRTEXT" 0)
  (setvar "ATTDIA" 1)
  (setvar "ATTREQ" 1)
  (setq doc (vla-get-ActiveDocument (vlax-get-acad-object)))
  (vlax-for blk (vla-get-Blocks doc)
    (setq name (vla-get-Name blk))
    (if (and (= (vla-get-IsXRef blk) :vlax-false)
             (= (vla-get-IsLayout blk) :vlax-false)
             (not (wcmatch name "`**,*|*")))
      (vl-catch-all-apply 'vl-cmdf (list "_.ATTSYNC" "_Name" name))
    )
  )
  (princ "\n[SYNCALLBLOCKS] Enforced MIRRTEXT=0 and synchronized all attributed blocks.")
  (princ)
)
