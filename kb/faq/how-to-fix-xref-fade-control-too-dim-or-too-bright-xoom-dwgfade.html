How to Fix Xref Fade (XDWGFADECTL) and Locked Layer Dimming (LAYLOCKFADECTL)

Adjust or disable on-screen dimming of external references (Xrefs) and locked layers in GstarCAD using XDWGFADECTL and LAYLOCKFADECTL without affecting PDF plot output.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Type XDWGFADECTL at the command prompt and enter a value between -90 and 90 (0 = no dimming, 50 = default 50% fade) to control Xref brightness on screen. Type LAYLOCKFADECTL (0 to 90) to control how much locked layers dim.

1. Root Cause & DWG Database Symptom Analysis

When attaching an architectural or civil survey Xref in GstarCAD, the background drawing may appear so faint and washed out on your monitor that you can barely read grid bubbles—or conversely, so bright that you cannot tell which lines belong to the Xref vs. the active drawing.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Adjust Xref On-Screen Fade via XDWGFADECTL (0 to 90)

Type XDWGFADECTL and enter 30 (subtle dimming) or 0 (100% full brightness). Adding a minus sign (e.g., -50) temporarily turns off Xref fading while storing your preferred `50%` value for quick toggling on the Ribbon! Note: XDWGFADECTL only affects your monitor display—it never affects PDF or paper plots.

Step 2: Adjust Locked Layer Dimming via LAYLOCKFADECTL

When you lock a layer in the Layer Manager, GstarCAD dims it by `50%` (`LAYLOCKFADECTL = 50`) so you know at a glance it cannot be erased. Set LAYLOCKFADECTL = 0 if you want locked layers to stay at full brightness.

Step 3: Control In-Place Reference Edit (REFEDIT) Fade via XFADECTL

When editing a block or Xref in-place via `REFEDIT`, surrounding inactive objects fade according to XFADECTL (default `70`, range `0–90`).

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
XDWGFADECTL 50 (Range -90..90) Controls on-screen dimming of attached DWG Xrefs (0 = full brightness)
LAYLOCKFADECTL 50 (Range -90..90) Controls on-screen dimming of locked layers in current drawing
XFADECTL 70 (Range 0..90) Controls dimming of background objects during in-place REFEDIT
Layer Transparency 0..90 (Plots when enabled) Unlike XDWGFADECTL, Layer Transparency plots to PDF if Plot Transparency is checked

4. One-Click AutoLISP Fix Script (AutoLISP Quick Toggle for Xref & Locked Layer Screen Fade)

(defun c:TOGGLE-FADE ( / cur)
  (setq cur (getvar "XDWGFADECTL"))
  (if (> cur 0)
    (progn (setvar "XDWGFADECTL" 0)  (setvar "LAYLOCKFADECTL" 0)
           (princ "\n[Display] Xref & Locked Layer Fade OFF (100% Brightness)."))
    (progn (setvar "XDWGFADECTL" 50) (setvar "LAYLOCKFADECTL" 50)
           (princ "\n[Display] Xref & Locked Layer Fade ON (50% Dimmed).")))
  (princ)
)

Always verify persistence scope via SYSVDLG before issuing sheets to an ISO 19650 Common Data Environment (CDE).
