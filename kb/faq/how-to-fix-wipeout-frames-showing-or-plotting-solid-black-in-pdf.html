How to Fix WIPEOUT Frames Showing on Screen or Plotting Solid Black Boxes in PDF

Eliminate visible WIPEOUT boundary borders via WIPEOUTFRAME = 0 or 2, and permanently fix WIPEOUT masks printing as solid black rectangles in PDF viewers and plotters.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

To hide WIPEOUT borders when plotting while keeping them selectable on screen, set WIPEOUTFRAME to 2. If WIPEOUT objects print as solid black rectangles in PDFs, replace the WIPEOUT with a Solid Hatch set to TrueColor RGB 255,255,255 (which never prints black on any PDF driver).

1. Root Cause & DWG Database Symptom Analysis

WIPEOUT entities are widely used to mask background gridlines or hatching behind text tags and electrical symbols. However, two notorious issues plague submittals: visible border outlines plotting around every tag, or the entire mask printing as a solid black rectangle on client PDF plotters.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Set WIPEOUTFRAME = 2 (Display Frame on Screen, Hide on Plot)

In GstarCAD and modern AutoCAD, WIPEOUTFRAME accepts three integer values: 0 (Frames completely hidden—cannot select them!), 1 (Frames visible AND plotted), and 2 (Frames visible on screen for editing, but suppressed during Plot/Publish). Always set WIPEOUTFRAME = 2.

Step 2: Why WIPEOUT Prints Black in Some PDF Drivers (Raster Mask Bug)

Internally, a `WIPEOUT` is a 1x1 pixel clipped raster image painted with the background color. Certain third-party PDF printers (and macOS Preview / mobile PDF viewers) invert 1-bit raster masks to solid black (`RGB 0,0,0`).

Step 3: The Bulletproof Fix — TrueColor 255,255,255 Solid Hatch or MTEXT Mask

For text notes, never draw a manual `WIPEOUT`: simply select the `MTEXT`, open Properties (`Ctrl+1`), set Background Mask = Yes (`Use drawing background color = Yes`, Offset = `1.15`). For dynamic blocks, replace the `WIPEOUT` with a `SOLID` hatch assigned explicitly to TrueColor 255,255,255 (because TrueColor bypasses `.ctb` monochrome conversion and plots pure white vector paper space!).

3. System Variables & Command Diagnostic Table
