How to Convert PDF to Editable DWG in GstarCAD & AutoCAD: Vector Import & SHX OCR

Convert vector and raster PDF drawings into accurate, layered DWG geometry using PDFIMPORT, PDFSHXTEXT recognition, and reference scale alignment.

Author: GstarCAD Academy Engineering BoardReviewed by: Elena Rostova, M.Eng., PE (SSE: 688657) Updated: 2026-10-12

⚡ Quick Answer / Key Takeaway

Run the PDFIMPORT command, select your vector PDF file, check 'Use PDF layers', 'Import as block' (optional), and 'Join line and arc segments', then run PDFSHXTEXT to convertstroked simplex geometry back into editable MTEXT.

Step-by-Step Instructions & Commands

Step 1: Execute Vector PDF Import (PDFIMPORT)

Type PDFIMPORT, press Enter, and browse to your PDF sheet. In the import dialog, select the target page, check Vector geometry, TrueType text, and Use PDF layers. Enable 'Infer linetypes from collinear dashes' so dashed hidden lines reconstruct as single dashed polylines instead of thousands of tiny segments.

Step 2: Convert Stroked SHX Geometry to Editable Text (PDFSHXTEXT)

Because CAD PDF plotters often export SHX fonts (such as romans.shx or simplex.shx) as tiny vector strokes rather than searchable fonts, run PDFSHXTEXT after import. Select the stroked text geometry to automatically match and convert it into true editable MTEXT entities.

Step 3: Calibrate True 1:1 Engineering Scale (SCALE -> Reference)

Measure a known dimension on the imported geometry using DIST. If the drawing imported at paper scale (e.g., 1:100), select all imported entities, run SCALE, pick a base point, type R (Reference), pick the two endpoints of a known dimension line, and type its true real-world length.

Common Issues & Troubleshooting Guide

Common Failure / Problem Root Cause & Recommended Solution
PDFIMPORT says 'No objects were imported' The PDF is a scanned raster image (pixel bitmap) rather than a vector CAD plot. Attach it as an underlay via PDFATTACH and use raster-to-vector tracing or redraw key baselines.
Circles import as faceted polygons Enable 'Convert closed polylines to circles' and 'Join contiguous segments' in the PDFIMPORT options panel before confirming.

Cross-CAD Compatibility & Alternatives

GstarCAD supports batch multi-page PDF import, allowing engineers to convert entire 30-page subcontractor PDF packages into separate DWG sheets in a single operation.

Engineering Best Practices Checklist

  • Always verify at least two orthogonal dimensions (X and Y) after scaling an imported PDF to confirm isotropic scaling.
  • Clean up imported layers using LAYMRG (Layer Merge) to align with corporate CAD standards.
  • Run OVERKILL on imported PDF geometry to remove duplicate boundary strokes.
