How to Import SketchUp (.SKP) Models into GstarCAD and Generate 2D Floor Plans

Step-by-step architectural workflow for importing SketchUp SKP models into GstarCAD, cutting horizontal section planes, and generating clean 2D vector floor plans and elevations.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Use GstarCAD's SKPIMPORT (or export 3D DWG/DXF from SketchUp Pro), scale to true metric/imperial units using Reference Scale, place a SECTIONPLANE at 1,200 mm (4'-0") above floor level, and run FLATSHOT or SECTIONPLANETOBLOCK to generate clean 2D Hidden-Line floor plans.

1. Root Cause & DWG Database Symptom Analysis

Architectural concept designers frequently mass buildings in SketchUp (`.skp`), leaving project architects to redraw 2D construction plans from scratch unless they know how to extract clean 2D vector sections directly from the 3D mesh/solid inside GstarCAD.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Import the .SKP Model or 3D DWG at 1:1 Scale

In GstarCAD, run IMPORT (select SketchUp *.skp) or import a 3D `.dwg` saved from SketchUp. Run DIST across a known doorway (`900 mm` or `36"`) to verify `INSUNITS` scaling matched 1:1.

Step 2: Generate 2D Elevations & Axonometrics via FLATSHOT

Switch to a standard Orthographic view (`FRONT`, `LEFT`, `TOP`, or `SE Isometric`) and run FLATSHOT. Set Foreground Lines to Layer `A-ELEV-VIS` (Color 7) and Obscured Lines to `Hidden` (or unchecked) to project a crisp 2D vector block onto the XY plane.

Step 3: Cut Horizontal Floor Plan Sections at +1,200 mm

Run SECTIONPLANE at elevation $Z = 1200\text{ mm}$ ($4'\text{-}0''$) looking downward, then execute SECTIONPLANETOBLOCK to separate cut wall profiles (`A-WALL-CUT`, `0.50 mm`) from background floor projections (`A-FLOR-PROJ`, `0.18 mm`).

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
FLATSHOT 2D Vector Block Projects any 3D ortho/isometric view to flat 2D lines & arcs
SECTIONPLANE Z = +1200 mm (4'-0") Cuts live horizontal plan or vertical building section
DISPSILH = 1 Drawing Variable Suppresses internal facet tessellation lines on curved solids
OVERKILL Post-Projection Collapses overlapping foreground projection segments

4. One-Click AutoLISP Fix Script (AutoLISP Coplanar Mesh Face Edge Cleanup Post-Import)

(defun c:CLEAN-SKP-IMPORT ()
  (setvar "DISPSILH" 1)
  (setvar "ISOLINES" 4)
  (command "_.OVERKILL" "_ALL" "" "")
  (princ "\n[SKP Import] Enabled silhouette display and removed duplicate mesh edges.")
  (princ)
)
