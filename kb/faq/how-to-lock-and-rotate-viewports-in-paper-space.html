How to Lock Viewport Scale & Rotate Viewport Views in Paper Space Without Rotating Model Geometry

Learn how to lock Paper Space layout viewports against accidental zooming, and rotate viewport camera angles using UCS + PLAN or MVSETUP Align without disturbing real-world Model Space coordinates.

Author: GstarCAD Academy Engineering BoardReviewed by: Chen Haoran, M.Sc., GDTP-S (SSE: 688657) Updated: 2026-10-12

⚡ Quick Answer / Key Takeaway

To lock a viewport: select its boundary frame, right-click → Display Locked → Yes (or click the padlock icon on the status bar). To rotate a view inside a viewport without rotating Model Space coordinates: double-click inside the viewport, type UCS -> Z -> enter angle, then type PLAN -> Current.

Step-by-Step Instructions & Commands

Step 1: Set Exact Viewport Scale & Lock Display

In your Layout tab, click the viewport frame, pick your engineering scale (e.g., 1:50 or 1:200) from the status bar dropdown, and immediately click the Lock/Unlock Viewport padlock icon (or run -VPORTS → Lock → On). Now zooming with the mouse wheel inside the activated viewport pans/zooms the whole sheet without ruining your scale.

Step 2: Rotate a Viewport View Using UCS + PLAN (Zero Model Modification)

Never rotate survey-referenced Model Space geometry just to make an angled building wing sit horizontally on a sheet! Instead, double-click inside the unlocked viewport, type UCS → Object (and click an angled building wall), then type PLAN → Current. The view rotates cleanly inside that viewport alone while World Coordinates remain untouched.

Step 3: Alternative Rotation via MVSETUP or VPROTATEASSOC

With VPROTATEASSOC set to 1, simply rotating the outer viewport frame in Paper Space using the standard ROTATE command automatically rotates the internal view to match. For precise angle alignment across sheets, use MVSETUP → Align → Rotate view.

Common Issues & Troubleshooting Guide

Common Failure / Problem Root Cause & Recommended Solution
Double-clicked inside a large viewport and now I'm stuck inside Model Space You are zoomed in beyond the viewport frame edges. Type PS (Paper Space) in the command line and press Enter to immediately exit back to Paper Space, then lock the viewport.
Rotating the viewport with UCS caused the view to zoom out to extents Set UCSFOLLOW = 0 inside the viewport before changing UCS if you want manual control over when the view updates.

Cross-CAD Compatibility & Alternatives

In GstarCAD 2027, selecting any viewport boundary displays both the Scale dropdown and Lock toggle directly on the Quick Properties bar for one-click governance.

Engineering Best Practices Checklist

  • Place all viewport boundary frames on a dedicated non-plotting layer (e.g., G-ANNO-VPRT with Plot turned Off).
  • Never draw or rotate shared survey models in WCS; always use named UCS views inside viewports.
  • Include a North Arrow block in Paper Space rotated to match the viewport's custom UCS angle.
