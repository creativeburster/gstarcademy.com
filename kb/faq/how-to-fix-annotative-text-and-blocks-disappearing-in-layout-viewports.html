How to Fix Annotative Text, Dimensions & Blocks Disappearing in Layout Viewports

Diagnose and fix annotative dimensions, MTEXT, and blocks vanishing when switching Paper Space viewport scales using ANNOALLVISIBLE, OBJECTSCALE, and ANNOAUTOSCALE.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Switch to the affected Layout viewport, type ANNOALLVISIBLE and set it to 1 to temporarily reveal all annotative objects, or select the missing objects in Model Space and run OBJECTSCALE to add the viewport's exact scale (e.g., 1:50 or 1:100) to their Annotative Scale List.

1. Root Cause & DWG Database Symptom Analysis

You set up a new Paper Space viewport at 1:100 scale in GstarCAD, and suddenly all your room tags, dimensions, and door blocks vanish—even though their layers are turned On and Thawed! This happens because Annotative Objects only display in viewports whose CANNOSCALE matches one of the scales attached to that object.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Toggle ANNOALLVISIBLE = 1 to Diagnose Missing Scales

Double-click inside the Paper Space viewport, type ANNOALLVISIBLE, and set it to 1 (the lightbulb/scale icon on the status bar). Note: ANNOALLVISIBLE is saved separately for Model Space and each Layout tab. If your text immediately reappears, the layer is fine—the object simply lacks the viewport's annotation scale!

Step 2: Add the Missing Viewport Scale via OBJECTSCALE (or ANNOAUTOSCALE)

Set ANNOALLVISIBLE = 0 (so wrong-sized text doesn't plot), select the annotative objects, type OBJECTSCALE, click Add, and choose the viewport's scale (e.g., 1:100). Alternatively, turn on ANNOAUTOSCALE = 4 and switch the viewport scale—GstarCAD automatically appends the new scale to all annotative entities.

Step 3: Purge Bloated Scale Lists via -SCALELISTEDIT

If third-party Xrefs injected 80 garbage scales (`1:50_1`, `1:100_XREF_02`), run -SCALELISTEDIT → Reset → Yes to restore a clean ISO/ANSI scale table.

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
ANNOALLVISIBLE = 1 Diagnostic Mode Forces all annotative objects to display regardless of viewport scale
ANNOALLVISIBLE = 0 Production Plot Mode Hides annotative objects that do not support the viewport's scale
OBJECTSCALE Scale List Manager Adds or deletes supported viewport scales on selected entities
-SCALELISTEDIT -> Reset Bloat Cleanup Purges corrupted or duplicated Xref annotation scales

4. One-Click AutoLISP Fix Script (AutoLISP Synchronize Current Annotation Scale Across Selected Entities)

(defun c:SYNC-ANNO-SCALE ( / ss curScale)
  (setq curScale (getvar "CANNOSCALE"))
  (if (setq ss (ssget '((0 . "TEXT,MTEXT,DIMENSION,MULTILEADER,INSERT,HATCH"))))
    (command "_.-OBJECTSCALE" ss "" "_A" curScale ""))
  (princ (strcat "\n[Annotative Sync] Added scale '" curScale "' to selected objects."))
  (princ)
)
