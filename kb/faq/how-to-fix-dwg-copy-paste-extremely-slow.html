How to Fix Extremely Slow Ctrl+C / Ctrl+V Copy-Paste in AutoCAD & GstarCAD

Resolve 10-to-60 second freezes when copying and pasting entities between DWG files by purging orphaned RegApps, DGN LineStyle dictionaries, and bloated annotative scale lists.

By GstarCAD Academy Engineering Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Zhang Mingyuan, B.Eng. (Distinguished DWG Graphics Kernel & GRX SDK Architect) Last reviewed 2026-10-26

⚡ Quick Executive Fix

Run -PURGE > Regapps (*), execute -SCALELISTEDIT > Reset > Yes, and run PURGE with 'Purge orphaned data (DGN linestyles)' checked. In GstarCAD 2027, these dictionary bottlenecks are scrubbed in under 2 seconds.

1. Engineering Root-Cause Diagnosis inside the AC1032 DWG Database

When pressing Ctrl+C (`COPYCLIP`) or Ctrl+V (`PASTECLIP`) freezes your CAD session for 30+ seconds on a seemingly simple 2D drawing, the culprit is almost never visible geometry. Instead, the AC1032 `WblockClone` deep-copy filer is cloning tens of thousands of unreferenced Registered Application IDs (`AcDbRegAppTableRecord`), orphaned MicroStation **DGN Complex Stroke Dictionaries (`AcDbLS*`)**, or thousands of duplicate **Annotative Scales (`ACDB_ANNOTATIONSCALES`)** attached to the root Named Object Dictionary.

2. Step-by-Step Resolution Protocol in AutoCAD & GstarCAD 2027

1. Purge Registered Application IDs (-PURGE Regapps)

Type -PURGE (with the leading hyphen) on the command line, enter R for Regapps, type * for all names, and enter N to skip confirmation. Removing 40,000 orphaned RegApps typically shrinks a 25 MB DWG down to 2 MB.

2. Reset Bloated Annotative Scale Lists (-SCALELISTEDIT)

Nested Xrefs often multiply custom scales (`1:100_1`, `1:100_2`...). Type -SCALELISTEDIT, enter R (Reset), and choose Y (Yes) to restore the clean default metric/imperial scale table.

3. Strip Orphaned DGN LineStyle Complex Strokes

Open the PURGE dialog, check Purge orphaned data (or run DGNPURGE), and click Purge All to strip invisible MicroStation dictionary trees.

3. Automated AutoLISP Diagnostic & Repair Script (C:FASTCLIP)

Load the following production AutoLISP routine into GstarCAD 2027 or AutoCAD via APPLOAD (or add it to gcaddoc.lsp) to automate this repair across affected project files:

(defun C:FASTCLIP ( / doc)
  (vl-load-com)
  (setvar "CMDECHO" 0)
  (command "_.-PURGE" "_Regapps" "*" "_No")
  (command "_.-PURGE" "_All" "*" "_No")
  (command "_.-SCALELISTEDIT" "_Reset" "_Yes" "_Exit")
  (setvar "ISAVEPERCENT" 0)
  (princ "\n[FASTCLIP] Purged RegApps, orphaned dictionaries, and reset scale list.")
  (princ)
)
