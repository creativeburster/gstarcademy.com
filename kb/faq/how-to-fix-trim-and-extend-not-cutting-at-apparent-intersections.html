How to Fix TRIM and EXTEND Not Cutting at Apparent or 3D Intersections (PROJMODE & EDGEMODE)

Fix TRIM and EXTEND commands failing to recognize cutting edges, implied extensions, or 3D elevated lines by configuring PROJMODE = 1 and EDGEMODE in GstarCAD.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Zhang Mingyuan, B.Eng. (Distinguished DWG Graphics Kernel & GRX SDK Architect) Last reviewed 2026-11-03 Editorial Process & Testbed
⚡ Quick Engineering Answer (TL;DR)

Type PROJMODE and set it to 1 (UCS XY Plane projection) so TRIM and EXTEND cut lines even if they sit at different Z elevations. Type EDGEMODE and set it to 0 (require actual intersection) or 1 (trim/extend to implied infinite extensions of cutting edges).

1. Root Cause & DWG Database Symptom Analysis

When TRIM or EXTEND ignores an obvious intersection right under your crosshairs, the culprit is almost always PROJMODE (3D projection mode) or EDGEMODE (implied edge extension mode).

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Set PROJMODE = 1 to Trim Across Different Z Elevations

If a civil contour at $Z = 50\text{ m}$ crosses a parcel boundary at $Z = 0\text{ m}$, they do not physically intersect in 3D space (`PROJMODE = 0`). Type PROJMODE and enter 1 (Project to current UCS XY plane) or 2 (Project to current View direction)—now `TRIM` and `EXTEND` slice cleanly across any Z elevation.

Step 2: Control Implied Infinite Cutting Edges via EDGEMODE (0 vs. 1)

When EDGEMODE = 1, GstarCAD treats every selected cutting line as infinitely long, which can cause `TRIM` to snip segments at invisible phantom extensions across the drawing. Set EDGEMODE = 0 so lines only trim at physical intersections.

Step 3: Hold SHIFT Inside TRIM to EXTEND (and Vice Versa)

While inside the `TRIM` command, simply hold down the SHIFT key and click any line to `EXTEND` it—no need to exit and launch a separate command!

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
PROJMODE = 1 UCS XY Projection (Recommended) Trims and extends objects even when their Z elevations differ
PROJMODE = 0 True 3D Intersection Only Fails to trim if two lines miss each other in Z by 0.0001 mm
EDGEMODE = 0 Actual Edges Only Prevents accidental trimming against invisible infinite line extensions
EDGEMODE = 1 Implied Extension On Extends or trims to the imaginary infinite projection of the cutting edge

4. One-Click AutoLISP Fix Script (AutoLISP Optimal TRIM / EXTEND Projection Configuration)

(defun c:FIX-TRIM-MODES ()
  (setvar "PROJMODE" 1) ; Project cutting edges onto UCS XY plane
  (setvar "EDGEMODE" 0) ; Only cut at actual intersections (no phantom infinite edges)
  (princ "\n[Trim/Extend Fixed] PROJMODE=1 (UCS Projection), EDGEMODE=0 (Actual Edges).")
  (princ)
)
