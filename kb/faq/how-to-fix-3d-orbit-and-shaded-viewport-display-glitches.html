How to Fix 3D Orbit Z-Fighting, Flickering & Shaded Viewport Glitches

Eliminate Z-fighting surface flicker, jagged 3D solids, and clipping plane disappears during 3DORBIT in GstarCAD 2027 and AutoCAD.

By GstarCAD Academy Engineering Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-10-26

⚡ Quick Executive Fix

Move 3D solids closer to WCS origin (0,0,0) to restore 24-bit GPU Z-buffer precision, increase VIEWRES to 5000 and FACETRES to 4.0, and enable DirectX 11 hardware acceleration in 3DCONFIG.

1. Engineering Root-Cause Diagnosis inside the AC1032 DWG Database

When orbiting 3D ACIS solids (`3DORBIT`), two visual artifacts commonly occur: **Z-fighting (coplanar surface flickering/striping)** and **facet fragmentation**, where cylindrical pipes appear hexagonal or disappear when zooming. In DirectX 11 viewports, the GPU depth buffer (`Z-Buffer`) uses 24-bit floating-point depth ratios between the Front and Back clipping planes. If your 3D model sits at civil coordinates (`X=500,000, Y=4,200,000`) or a single stray line sits 10 km away, the camera's near/far frustum spans kilometers—collapsing depth precision to several centimeters and causing overlapping flanges to flicker violently.

2. Step-by-Step Resolution Protocol in AutoCAD & GstarCAD 2027

1. Purge Stray Far-Flung Entities & Move Near 0,0,0

Run ZOOM → Extents. If the model shrinks to a tiny dot, use ERASE → All then hold Shift and window-deselect your main model to delete stray outlier geometry. For 3D visualization, relocate the project base point near WCS 0,0,0.

2. Calibrate ACIS Tessellation Smoothness (FACETRES & VIEWRES)

Set FACETRES = 4.0 (range `0.01` to `10.0`) to refine 3D solid mesh triangles in Shaded/Realistic modes, and run VIEWRES → Yes → 5000 for smooth 2D arcs.

3. Reset Clipping Planes in DVIEW / 3DCLIP

If the front of your 3D assembly vanishes when zooming in, run 3DCLIP (or PROPERTIES → 3D Visualization → Clipping) and toggle Front/Back Clipping Off.

3. Automated AutoLISP Diagnostic & Repair Script (C:FIX3DVIEW)

Load the following production AutoLISP routine into GstarCAD 2027 or AutoCAD via APPLOAD (or add it to gcaddoc.lsp) to automate this repair across affected project files:

(defun C:FIX3DVIEW ()
  (setvar "FACETRES" 4.0)
  (setvar "ISOLINES" 16)
  (setvar "DISPSILH" 1)
  (command "_.VIEWRES" "_Yes" 5000)
  (command "_.REGENALL")
  (princ "\n[FIX3DVIEW] Calibrated 3D ACIS tessellation & silhouette variables.")
  (princ)
)
