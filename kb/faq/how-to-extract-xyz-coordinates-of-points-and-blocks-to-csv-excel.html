How to Extract X, Y, Z Coordinates of Points, Blocks & Polylines to CSV / Excel in GstarCAD

Export survey monument coordinates, piling centers, and block attributes from GstarCAD directly to CSV or Excel spreadsheets using DATAEXTRACTION or AutoLISP.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Run the built-in DATAEXTRACTION wizard (or EATTEXT) in GstarCAD, select 'Point' or 'Block Reference' objects, check Position X, Position Y, Position Z (plus any block attributes like POINT_ID), and output directly to .csv or .xls. Or run our 1-click AutoLISP PENZD exporter.

1. Root Cause & DWG Database Symptom Analysis

Civil surveyors, structural piling engineers, and MEP layout crews frequently need to extract a schedule of Point ID, Easting ($X$), Northing ($Y$), and Elevation ($Z$) from a GstarCAD drawing into a `.csv` file for Total Station stakeout or Excel quantity takeoffs.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Use the Built-In DATAEXTRACTION Wizard (No Coding Required)

Type DATAEXTRACTION (or EATTEXT), create a `.dxe` template, select the target objects in the drawing, filter to Point, Circle, or your specific survey Block, check Position X, Position Y, Position Z under the Geometry category, and export to `.csv` or `.xls`.

Step 2: Export Ordered LWPOLYLINE Vertices for Boundary Stakeout

Standard `DATAEXTRACTION` extracts block/point centers, but what if you need the sequential $X, Y$ corner coordinates of a closed property parcel `LWPOLYLINE`? Use the `LIST` command or the AutoLISP vertex/point exporter below.

Step 3: Instant PENZD CSV Export via AutoLISP

Load the routine below and run EXPORT-XYZ-CSV: select any combination of `POINT`, `CIRCLE`, or `INSERT` (blocks), and GstarCAD writes a clean `PENZ` CSV file ready for Leica/Trimble/Topcon survey controllers.

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
DATAEXTRACTION Built-in Wizard Extracts X, Y, Z plus Block Attributes to CSV/XLS or CAD Table
EXPORT-XYZ-CSV AutoLISP Utility Exports POINT, INSERT, and CIRCLE centers to CSV in 1 second
LIST Quick Inspection Prints sequential vertex X,Y coordinates of selected Polylines
LUPREC = 4 Precision Variable Controls decimal precision in LIST output (rtos uses explicit 4)

4. One-Click AutoLISP Fix Script (AutoLISP 1-Click Point / Block / Circle X,Y,Z to CSV Exporter)

(defun c:EXPORT-XYZ-CSV ( / ss fn fp i ent elist pt lay)
  (if (and (setq ss (ssget '((0 . "POINT,INSERT,CIRCLE"))))
           (setq fn (getfiled "Save XYZ Coordinates CSV" "Survey_Coords.csv" "csv" 1)))
    (progn
      (setq fp (open fn "w") i 0)
      (write-line "ID,Layer,X_Easting,Y_Northing,Z_Elevation" fp)
      (while (< i (sslength ss))
        (setq ent (ssname ss i) i (1+ i) elist (entget ent)
              pt  (cdr (assoc 10 elist)) lay (cdr (assoc 8 elist)))
        (write-line (strcat (itoa i) "," lay "," (rtos (car pt) 2 4) ","
                            (rtos (cadr pt) 2 4) "," (rtos (caddr pt) 2 4)) fp))
      (close fp)
      (princ (strcat "\n[CSV Export] Wrote " (itoa i) " coordinates to " fn))))
  (princ)
)
