How to Fix Distorted or Overlapping Text During CAD PDF Publishing?

Overlapping or distorted text in PDF exports occurs when fonts are converted to geometry, non-standard text width factors are applied, or system variable TEXTFILL is disabled. Resolve by enabling font embedding in PDF driver properties and ensuring standard 1.0 width factors.

Direct Diagnostic Solution & Protocol

Quick Resolution: Overlapping or distorted text in PDF exports occurs when fonts are converted to geometry, non-standard text width factors are applied, or system variable TEXTFILL is disabled. Resolve by enabling font embedding in PDF driver properties and ensuring standard 1.0 width factors.

Step-by-Step Engineering Execution

Step 1: Verify Text Style Width Factors

Type STYLE. Select your active text styles. If 'Width Factor' is set to non-integer values like 0.73, third-party PDF rasterizers miscalculate character kerning, causing glyphs to overlap. Reset to 1.0.

Step 2: Configure Built-in PDF Plotter Properties

Type PLOT → select 'DWG to PDF.pc3' → click 'Properties'. Under 'Device and Document Settings', expand 'Custom Properties'. Ensure 'Capture fonts used in drawing' is checked.

Step 3: Enable Font As Text (Disable Geometry Stroke)

In PDF options, toggle 'Convert text to geometry' OFF. Leaving text as native TrueType fonts keeps text searchable in Adobe Acrobat and prevents letter distortion.

Step 4: Reset TEXTFILL & FILLMODE System Variables

Type TEXTFILL and verify it is set to 1. Ensure FILLMODE is also set to 1. Execute REGENALL before publishing.
