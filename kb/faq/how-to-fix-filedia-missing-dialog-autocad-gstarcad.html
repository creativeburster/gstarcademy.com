How to Fix Missing Open/Save File Dialog Box in AutoCAD & GstarCAD (FILEDIA = 1)

Fix the issue where clicking Open, Save, or Export in AutoCAD or GstarCAD only prompts on the command line instead of opening a Windows file browser window.

Author: GstarCAD Academy Engineering BoardReviewed by: Zhang Mingyuan, B.Eng. (SSE: 688657) Updated: 2026-10-12

⚡ Quick Answer / Key Takeaway

Type FILEDIA in the command line, press Enter, type 1, and press Enter again. If attribute prompts or plot dialogs are also missing, set CMDDIA to 1 and ATTDIA to 1.

Step-by-Step Instructions & Commands

Step 1: Restore the File Navigation Dialog (FILEDIA)

When an AutoLISP script or batch plot macro crashes mid-execution, it often leaves system dialogs suppressed. Click into the command line, type FILEDIA, press Enter, and change the value from 0 to 1. Press Ctrl+O to verify that the standard Windows Explorer file dialog reappears.

Step 2: Restore Command & Attribute Dialogs (CMDDIA & ATTDIA)

If commands like PLOT, ARRAY, or block attribute insertions still prompt on the command bar instead of opening a modal window, enter CMDDIA and set it to 1, then enter ATTDIA and set it to 1.

Step 3: Lock System Variables via Startup LISP (acaddoc.lsp / gcaddoc.lsp)

To prevent poorly written third-party LISP plugins from permanently disabling your file dialogs, add (setvar "FILEDIA" 1) and (setvar "CMDDIA" 1) to your corporate startup script or configure the System Variable Monitor (SYSVARMONITOR) to alert and auto-reset whenever FILEDIA drops to 0.

Common Issues & Troubleshooting Guide

Common Failure / Problem Root Cause & Recommended Solution
Pressing Ctrl+O still freezes the entire screen The file dialog may be opening off-screen on a disconnected secondary monitor. Press Alt+Space, press M (Move), tap any arrow key once, and move your mouse to bring the hidden dialog back onto your primary screen.
FILEDIA resets to 0 every time I open a specific drawing Check for an embedded drawing script or malicious/buggy acad.lsp file residing in the same folder as the DWG. Set SECURELOAD to 1 or 2 to restrict untrusted code execution.

Cross-CAD Compatibility & Alternatives

Both GstarCAD and AutoCAD share the exact same FILEDIA, CMDDIA, and ATTDIA system variables. In GstarCAD 2027, the System Variable Monitor automatically flags abnormal variable modifications on status bar notifications.

Engineering Best Practices Checklist

  • Always include an *error* handler in custom AutoLISP routines to restore FILEDIA to 1 if the user presses ESC.
  • Use the ~ (tilde) character at a command-line file prompt to force a one-time file dialog even when FILEDIA is 0.
  • Register FILEDIA, PICKFIRST, and VISRETAIN in SYSVARMONITOR across all enterprise workstations.
