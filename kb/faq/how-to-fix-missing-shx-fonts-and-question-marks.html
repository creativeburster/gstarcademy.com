How to Fix Missing SHX Fonts & '???' Question Mark Text in AutoCAD and GstarCAD

Resolve garbled characters, question marks (???), and missing SHX/BigFont dialogs when opening DWG files across regional engineering teams.

Author: Gstarcademy Engineering Editorial Board Updated: 2026-10-12

⚡ Quick Answer / Key Takeaway

Copy missing .shx and BigFont files into your CAD Fonts directory, set the FONTALT system variable to a universal fallback font (such as simplex.shx or gbcbig.shx), or remap corrupted text styles in the STYLE command.

Step-by-Step Instructions & Commands

Step 1: Map a Universal Fallback Font via FONTALT

When opening a drawing with missing proprietary fonts, type FONTALT and set it to simplex.shx (for Western drawings) or configure your font mapping table (acad.fmp / gcad.fmp) so missing fonts automatically substitute without halting batch operations.

Step 2: Fix CJK / Regional Question Marks (???) in Text Styles

If Asian or Eastern European annotations display as ???, type STYLE (or ST) to open the Text Style Manager. Select the affected style, either check Use Big Font and assign gbcbig.shx / hztxt.shx, or switch the font family to a universal Unicode TrueType font like Arial Unicode MS, then run REGENALL.

Step 3: Package Fonts Automatically with ETRANSMIT

When sending DWG deliverables to external clients, never email bare .dwg files. Run ETRANSMIT and check 'Include fonts' in the Transmittal Setup so all referenced SHX and TrueType fonts travel inside the archive.

Common Issues & Troubleshooting Guide

Common Failure / Problem Root Cause & Recommended Solution
Installed the .shx file into Windows Fonts but CAD still can't find it Windows Fonts only accepts TrueType/OpenType (.ttf/.otf) fonts. Compiled CAD shape fonts (.shx) must be placed directly inside the GstarCAD/Fonts or AutoCAD/Fonts installation folder.
Some MTEXT strings still show question marks after changing STYLE The MTEXT entity contains internal inline character formatting overrides. Use the STRIPMTEXT LISP utility to strip hardcoded font overrides.

Cross-CAD Compatibility & Alternatives

GstarCAD and DWG FastView include an intelligent cloud font matching library that automatically downloads and caches missing regional SHX and BigFont files upon file open.

Engineering Best Practices Checklist

  • Standardize corporate templates on 2–3 universal SHX/TTF fonts to eliminate cross-office font drift.
  • Add a shared network Fonts directory to your Support File Search Path in OPTIONS.
  • Always run ETRANSMIT before archiving contractual deliverables.
