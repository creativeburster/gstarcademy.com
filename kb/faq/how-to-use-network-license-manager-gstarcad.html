How to Configure GstarCAD Network License Manager: Floating Seats, Borrowing & Firewall Ports

Enterprise IT guide to deploying GstarCAD Network License Manager (FlexNet / GLM): server activation, TCP firewall port configuration, offline seat borrowing, and multi-subnet options files.

Author: GstarCAD Academy Engineering BoardReviewed by: Zhang Mingyuan, B.Eng. (SSE: 688657) Updated: 2026-10-12

⚡ Quick Answer / Key Takeaway

Install Gstarsoft Network License Manager on a static-IP Windows or Linux server, activate your XML/online license key, open TCP ports 27000–27009 and the vendor daemon port in your firewall, and point client workstations to 'Server_IP' via the GstarCAD License Manager.

Step-by-Step Instructions & Commands

Step 1: Server Installation & Master License Activation

Assign a static IP address to your license server. Install the Gstarsoft Network License Manager service, launch the activation utility, and bind your enterprise Entitlement ID (either online or via offline XML request/response for air-gapped defense networks).

Step 2: Configure Static TCP Firewall Ports in the License File

To allow workstations across VLANs or VPNs to check out licenses rapidly, lock the ports in the license file header: append 27000 to the SERVER line and PORT=11000 to the VENDOR line. Add inbound TCP firewall rules allowing ports 27000 and 11000.

Step 3: Configure Seat Borrowing & Group Reservation (Options File)

Field engineers traveling with laptops can borrow a floating license offline for up to 30 days via the client License Manager's Borrow tab. IT admins can also configure an options file (gstar.opt) using RESERVE and MAX_BORROW_HOURS to guarantee seats for priority production teams.

Common Issues & Troubleshooting Guide

Common Failure / Problem Root Cause & Recommended Solution
Client takes 45 seconds to connect or fails with Error -15 The vendor daemon port is shifting randomly on server reboot and being blocked by Windows Firewall. Explicitly pin PORT=11000 on the VENDOR line and restart the license service.
VPN users cannot check out floating licenses Set the environment variable FLEXLM_TIMEOUT=3000000 (3 seconds) on client laptops to accommodate higher WAN/VPN ping latency.

Cross-CAD Compatibility & Alternatives

A single Gstarsoft Network License Server can concurrently serve hybrid fleets of GstarCAD Windows, GstarCAD Linux, GstarCAD Mechanical, and Architecture workstations.

Engineering Best Practices Checklist

  • Host the license manager on a highly available virtual machine with static MAC address binding.
  • Return borrowed licenses early when returning to the office to free up concurrent pool capacity.
  • Monitor peak concurrency logs monthly to optimize seat-to-engineer ratios.
