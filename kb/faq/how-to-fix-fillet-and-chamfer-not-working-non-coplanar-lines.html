How to Fix FILLET and CHAMFER Not Working ('Lines Are Non-Coplanar' or 'Radius Too Large')

Resolve every reason why FILLET or CHAMFER fails in GstarCAD and AutoCAD: non-coplanar Z elevations, TRIMMODE=0, locked layers, or polyline arc segment conflicts.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

If FILLET says 'Lines are non-coplanar', flatten both objects to Z=0 (set Start Z = 0, End Z = 0, Elevation = 0 in Properties) and set OSNAPZ=1. If FILLET creates the arc without trimming the corner, type TRIMMODE and set it to 1. Hold the SHIFT key while picking two lines to force a sharp 0-radius corner.

1. Root Cause & DWG Database Symptom Analysis

When FILLET or CHAMFER refuses to join two intersecting walls or mechanical edges, the command line usually prints one of three diagnostic messages: "Lines are non-coplanar", "Radius is too large", or "Cannot fillet between these two entities".

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Cause 1: 'Lines are non-coplanar' (Mismatched Z Coordinates or Extrusion Normals)

Even a $0.0001\text{ mm}$ difference in `Start Z`, `End Z`, or `Elevation`—or an inverted extrusion direction `DXF 210 = (0 0 -1)` from a 3D mirror—prevents a 2D fillet. Select both objects, open Properties (Ctrl+1), set Start Z = 0, End Z = 0, and Elevation = 0, or run FLATTEN.

Cause 2: Fillet Arc Draws But Original Corner Lines Do Not Trim (TRIMMODE = 0)

If GstarCAD draws the fillet arc but leaves the sharp corner extensions intact, type TRIMMODE at the command prompt and change it from 0 to 1 (or choose Trim → Trim inside the `FILLET` prompt).

Cause 3: Pro Tip — Hold SHIFT to Force a Zero-Radius Corner Join

You never need to change `FILLETRAD` to `0` just to close a sharp corner! Keep your working `FILLETRAD` (e.g., `5.0 mm`), launch FILLET, and hold down the SHIFT key while clicking the second line—GstarCAD temporarily overrides the radius to `0.0` for that click.

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
TRIMMODE 1 (Registry) 1 = Trims intersecting lines at fillet/chamfer; 0 = Leaves original lines
FILLETRAD 0.0 (or Design R) Stores current fillet radius inside the drawing
SHIFT + Click Temporary Override Forces a sharp R=0 corner join without erasing your saved FILLETRAD
DXF Group 210 (0.0 0.0 1.0) Normal vector; run FLATTEN if an entity has inverted (0 0 -1) normal

4. One-Click AutoLISP Fix Script (AutoLISP Coplanar Normalizer & Trim-Enabled Fillet Reset)

(defun c:FIX-FILLET-STATE ()
  (setvar "TRIMMODE" 1)
  (setvar "OSNAPZ" 1)
  (setvar "ELEVATION" 0.0)
  (princ (strcat "\n[Fillet Doctor] TRIMMODE=1 (Trim On), OSNAPZ=1, Current FILLETRAD="
                 (rtos (getvar "FILLETRAD") 2 2)))
  (princ)
)
