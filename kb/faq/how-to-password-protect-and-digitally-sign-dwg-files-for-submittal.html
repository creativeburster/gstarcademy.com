How to Password-Protect, Digital-Sign & Lock DWG Files for Submittal in GstarCAD

Protect intellectual property and authenticate PE engineering seals on DWG submittals using X.509 Digital Signatures (DIGITALSIGN), DWFx/PDF publishing, and block locking.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Use DIGITALSIGN (with a Windows X.509 certificate) to attach a tamper-evident cryptographic seal to your DWG files. To prevent clients from extracting your proprietary Dynamic Block libraries while allowing measurement, bind Xrefs, run BURST on title blocks, and issue signed PDF/DWFx alongside clean flattened DWGs.

1. Root Cause & DWG Database Symptom Analysis

Engineering consultancies frequently need two distinct levels of submittal security in GstarCAD: Cryptographic Tamper Detection (proving a stamped PE/Chartered Engineer drawing has not been altered after issue) and Intellectual Property (IP) Sanitization (preventing recipients from harvesting proprietary dynamic blocks and LISP dictionaries).

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Attach an X.509 Cryptographic Digital Signature (DIGITALSIGN)

Install your state-board or corporate X.509 digital certificate into the Windows Certificate Store (`certmgr.msc`). In GstarCAD, run DIGITALSIGN (or check Attach digital signature after saving drawing under `OPTIONS -> Open and Save`), select your certificate, and add a timestamp server plus submittal note. If anyone modifies even a single vertex and saves, the signature automatically invalidates!

Step 2: Verify Incoming Signed Drawings via SIGVALIDATE

Run SIGVALIDATE on any incoming subcontractor `.dwg` to inspect the signer's identity, Certificate Authority chain, and whether the file has remained 100% unaltered since signing.

Step 3: Strip Proprietary Dynamic Block Logic Before External Issue

Before sending background DWGs to external vendors, run a submittal-strip copy where dynamic blocks are converted to static anonymous blocks or single polylines so competitors cannot copy your studio's parametric block library.

4. One-Click AutoLISP Fix Script (AutoLISP Submittal IP Stripper (Converts Dynamic Blocks to Static Blocks))

(defun c:STRIP-DYN-BLOCKS ( / ss i ent obj)
  (if (setq ss (ssget "_X" '((0 . "INSERT"))))
    (progn
      (setq i 0)
      (while (< i (sslength ss))
        (setq ent (ssname ss i) i (1+ i) obj (vlax-ename->vla-object ent))
        (if (= (vla-get-IsDynamicBlock obj) :vlax-true)
          (vla-ConvertToAnonymousBlock obj)))))
  (princ "\n[IP Guard] Converted Dynamic Blocks to locked static anonymous blocks.")
  (princ)
)
