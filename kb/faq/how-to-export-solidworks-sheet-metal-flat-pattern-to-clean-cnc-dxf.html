How to Export SolidWorks & 3D Sheet Metal Flat Patterns to Clean CNC Laser DXF in GstarCAD

Complete workflow for cleaning 3D MCAD sheet metal flat-pattern DXF exports in GstarCAD: joining open splines into closed LWPOLYLINE contours and separating bend lines.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Export the Flat Pattern from SolidWorks/Inventor with 'Bend Lines' enabled and 'Splines exported as Polylines', open the DXF in GstarCAD, run OVERKILL to delete duplicate lines, use PEDIT -> Multiple -> Join (Fuzz = 0.01 mm) to create closed outer/inner cut loops, and save as AutoCAD 2004/R12 ASCII DXF.

1. Root Cause & DWG Database Symptom Analysis

CNC laser, plasma, and waterjet nesting software (BySoft, TruTops, SigmaNEST) rejects DXF files containing open contours, self-intersecting splines, title block borders, or bend centerlines left on the same layer as the cutting kerf path.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Separate Outer Cut, Inner Cut & Bend Layers in GstarCAD

Open the flat pattern DXF in GstarCAD. Keep outer perimeter profiles on layer 0 or CUT_OUTER (Color 7), internal hole cutouts on CUT_INNER (Color 3), and move upward/downward bend lines to BEND_UP (Color 1) and BEND_DOWN (Color 5). Delete all bounding-box sketches and text annotations unless laser-etching is required.

Step 2: Convert Splines & Join Disconnected Segments into Closed Polylines

If curved cutouts exported as `SPLINE` entities, select them and run SPLINEDIT → Convert to Polyline (precision 10). Next, run OVERKILL, then execute PEDIT → Multiple → Join with a fuzz distance of 0.005 mm and verify in Properties (`Ctrl+1`) that every cut loop shows Closed = Yes.

Step 3: Move Part Lower-Left Corner to 0,0,0 and Save as R12/2004 DXF

Move the flat pattern so its lower-left bounding box sits at 0,0,0, run FLATTEN to guarantee Z = 0 on all vertices, and run SAVEAS → AutoCAD 2004 DXF (*.dxf).

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
PEDIT -> Multiple -> Join Fuzz = 0.005 mm Welds segmented lines and arcs into continuous closed loops
SPLINEDIT -> Convert Precision = 10 Converts NURBS splines into CNC-compatible G02/G03 arcs
OVERKILL Tolerance = 0.001 mm Deletes stacked double lines that cause double laser burns
DXF Output Version 2004 or R12 ASCII DXF Maximum compatibility across Trumpf, Amada, and Bystronic CAM

4. One-Click AutoLISP Fix Script (AutoLISP CNC Laser DXF Open-Contour Inspector)

(defun c:CHECK-CNC-CLOSED ( / ss i ent openCnt)
  (setq openCnt 0)
  (if (setq ss (ssget "_X" '((0 . "LWPOLYLINE") (8 . "0,CUT*"))))
    (progn
      (setq i 0)
      (while (< i (sslength ss))
        (setq ent (ssname ss i) i (1+ i))
        (if (= (logand 1 (cdr (assoc 70 (entget ent)))) 0)
          (progn
            (setq openCnt (1+ openCnt))
            (command "_.CIRCLE" (cdr (assoc 10 (entget ent))) 5.0))))))
  (princ (strcat "\n[CNC DXF QA] Open Cut Polylines Found (marked with R=5 circles): " (itoa openCnt)))
  (princ)
)
