How to Create and Use Blocks in AutoCAD

Complete guide to AutoCAD blocks: creation, insertion, attributes, dynamic blocks, and block libraries for reusable content.

By Gstarcademy Editorial Team Updated 2026-06-30

How do I create a block in AutoCAD?

Use BLOCK command (B shortcut): name the block, select objects, pick an insertion base point, and choose whether to convert/retain/delete the original objects. The block is stored in the current drawing. Use WBLOCK to save as a separate .dwg file for use in other drawings.

How do I add attributes to a block?

Before creating the block, use ATTDEF to place attribute definitions (tag, prompt, default value) alongside the geometry. When you create the block including these ATTDEF objects, they become fillable fields on insertion. Use EATTEXT or DATAEXTRACTION to export attribute data to tables.

What are dynamic blocks?

Dynamic blocks contain parameters (distances, angles, flip states) and actions (stretch, rotate, array) that let users modify instances without exploding. Created in the Block Editor (BEDIT), they reduce library size dramatically — one dynamic door block replaces 50 fixed-size blocks.
