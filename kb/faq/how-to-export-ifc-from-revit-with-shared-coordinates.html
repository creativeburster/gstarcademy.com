How to Export IFC 4 / IFC 4.3 from Revit with Accurate Shared Coordinates & Custom Property Sets

Configure lossless OpenBIM IFC exports from Autodesk Revit: set Coordinate Base to Shared Coordinates, map Revit categories to IFC classes, and export custom schedules as buildingSMART Property Sets.

Author: Gstarcademy Engineering Editorial Board Updated: 2026-10-12

⚡ Quick Answer / Key Takeaway

In File -> Export -> IFC -> Modify Setup: set IFC Version to 'IFC4 Reference View' (or Design Transfer View), set Coordinate Base under General to 'Shared Coordinates', and check 'Export Revit property sets' or attach a custom Property Mapping .txt file under Property Sets.

Step-by-Step Instructions & Commands

Step 1: Verify Survey Point, Project Base Point & Shared Site

Before exporting, confirm that your Revit model acquired shared coordinates from the civil control file (`Manage` → `Coordinates` → `Acquire Coordinates`). In the IFC Export Setup (`Modify Setup` → `General` tab), set Coordinate Base to Shared Coordinates so the exported `IfcSite` aligns seamlessly with Civil 3D and Navisworks.

Step 2: Map Revit Categories & Built-In Parameters (`IfcExportAs`)

To override individual families (such as a generic model acting as a structural precast girder), bind the official shared parameters IfcExportAs (e.g., value IfcBeam) and IfcExportType (e.g., GIRDER) to the family categories.

Step 3: Export Custom Schedules as Standardized Property Sets

In the `Property Sets` tab of the IFC Export dialog, check Export schedules as property sets and Export only schedules containing IFC, Pset, or Common in the title. Create a Revit schedule named `Pset_CustomAssetData` containing your exact required parameters to embed clean, uncluttered metadata.

Common Issues & Troubleshooting Guide

Common Failure / Problem Root Cause & Recommended Solution
Exported IFC lands 500 kilometers away from other models in Navisworks One discipline exported using 'Internal Origin' while another used 'Shared Coordinates'. Enforce 'Shared Coordinates' across all trades in the BIM Execution Plan.
IFC file size is over 800MB for a medium building Set 'Level of detail for some element geometry' to Low or Medium in the Advanced tab; High tessellation turns every curved pipe elbow and railing baluster into tens of thousands of triangles.

Cross-CAD Compatibility & Alternatives

Always inspect your exported IFC file in an independent viewer (such as BIMcollab Zoom, Solibri Anywhere, or DWG FastView 3D) before uploading to the project CDE.

Engineering Best Practices Checklist

  • Save your configured IFC Export Setup as an in-session JSON preset and distribute it to all project consultants.
  • Keep 'Split Walls, Columns, Ducts by Level' checked when exporting for 4D construction scheduling or 5D quantity takeoff.
  • Validate exported IFC files against buildingSMART IDS rulesets prior to milestone handoff.
