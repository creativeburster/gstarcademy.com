How to Fix Double-Click Editing (DBLCLKEDIT) Not Working for Text, Blocks & Hatches

Restore double-click editing for MTEXT, TEXT, Attributes (EATTEDIT), Blocks (BEDIT), and Quick Properties by setting DBLCLKEDIT = 1 and PICKFIRST = 1 in GstarCAD.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-11-03 Editorial Process
⚡ Quick Engineering Answer (TL;DR)

Type DBLCLKEDIT and set it to 1 (ON), then type PICKFIRST and set it to 1. Both variables must be set to 1 simultaneously for double-click editing to launch the In-Place Text Editor, Enhanced Attribute Editor, or Block Editor.

1. Root Cause & DWG Database Symptom Analysis

When double-clicking on a text note, dimension, hatch, or attributed title block does nothing at all in GstarCAD or AutoCAD, two interdependent system variables are responsible: DBLCLKEDIT and PICKFIRST.

2. Step-by-Step Resolution in GstarCAD & AutoCAD

Step 1: Enable Both DBLCLKEDIT = 1 and PICKFIRST = 1

Even if DBLCLKEDIT is set to 1, double-click actions are completely disabled if PICKFIRST = 0! Type DBLCLKEDIT → 1 and PICKFIRST → 1 at the command prompt (or check both boxes under OPTIONS → User Preferences → Selection).

Step 2: Customize Double-Click Actions in the CUI Editor

Want double-clicking a standard block to open REFEDIT (In-Place Reference Edit) instead of BEDIT (Block Editor)? Run CUI, expand Double Click Actions → Block, and drag your preferred command onto the action node.

Step 3: Control Quick Properties Popup via QPMODE

If a small floating mini-properties card pops up every time you click or double-click an entity—or if you want it back—toggle QPMODE (`0 = Off`, `1 = On for all objects`, `2 = On for CUI-defined objects`) or press Ctrl+Shift+P.

3. System Variables & Command Diagnostic Table

Variable / Command Default / Target Value Diagnostic Function & Fix Behavior
DBLCLKEDIT 1 (ON) Enables double-click actions across the drawing editor
PICKFIRST 1 (ON - Mandatory) Required prerequisite for DBLCLKEDIT to recognize the clicked entity
MTEXTED "Internal" Restores the built-in ribbon/in-place MTEXT formatting editor
QPMODE 0 or 1 Toggles floating Quick Properties card on single/double click

4. One-Click AutoLISP Fix Script (AutoLISP Double-Click & Text Editor Restorer)

(defun c:FIX-DBLCLICK ()
  (setvar "DBLCLKEDIT" 1)
  (setvar "PICKFIRST"  1)
  (setvar "MTEXTED"    "Internal")
  (princ "\n[UI Fixed] DBLCLKEDIT=1, PICKFIRST=1, Internal MTEXT editor active.")
  (princ)
)
