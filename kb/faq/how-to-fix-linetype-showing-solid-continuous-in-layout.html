How to Fix Dashed Linetypes Showing as Solid Continuous Lines in Layout Viewports

Synchronize LTSCALE, PSLTSCALE, MSLTSCALE, and CELTSCALE so dashed, hidden, and centerlines display identically in Model Space and Paper Space Layout Viewports.

By GstarCAD Academy Engineering Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by Zhang Mingyuan, B.Eng. (Distinguished DWG Graphics Kernel & GRX SDK Architect) Last reviewed 2026-10-26

⚡ Quick Executive Fix

Set LTSCALE = 1.0, PSLTSCALE = 1 (in every Layout tab), MSLTSCALE = 1, and CELTSCALE = 1.0, then run REGENALL. This standard 4-variable matrix guarantees identical dash lengths across all viewport scales.

1. Engineering Root-Cause Diagnosis inside the AC1032 DWG Database

When a `HIDDEN` or `CENTER` line displays clear dashes in Model Space but collapses into a solid continuous line inside a Paper Space Layout Viewport (or vice versa), the drawing's four linetype scale multipliers are fighting each other. Specifically, when `PSLTSCALE = 0`, dash lengths inside a `1:100` viewport are shrunk by $1/100\times$—making a 3 mm dash appear `0.03 mm` long on paper (indistinguishable from a solid line).

2. Step-by-Step Resolution Protocol in AutoCAD & GstarCAD 2027

1. Enforce the Universal '1-1-1-1' Linetype Scale Matrix

Set LTSCALE = 1.0 (or `0.5` for dense metric ISO sheets), MSLTSCALE = 1 (scales dashes by `CANNOSCALE` in Model Space), PSLTSCALE = 1 (normalizes dash length to paper millimeters across all viewports), and CELTSCALE = 1.0.

2. Remember PSLTSCALE Is Stored Per-Layout Tab

In AC1032 DWG files, `PSLTSCALE` is saved separately inside each Layout dictionary (`Layout1`, `Layout2`...). After switching to a new Layout tab, verify `PSLTSCALE = 1` and run REGENALL (`REA`) inside the viewport.

3. Enable Polyline Linetype Generation (PLINEGEN = 1)

If a dashed `LWPOLYLINE` with closely spaced curve vertices still looks solid, select it, open `PROPERTIES` (`Ctrl+1`), and change **Linetype Generation** from `Disabled` to `Enabled` (and set `PLINEGEN = 1` for future polylines).

3. Automated AutoLISP Diagnostic & Repair Script (C:SYNC_LTSCALE)

Load the following production AutoLISP routine into GstarCAD 2027 or AutoCAD via APPLOAD (or add it to gcaddoc.lsp) to automate this repair across affected project files:

(defun C:SYNC_LTSCALE ( / doc lay)
  (vl-load-com)
  (setq doc (vla-get-ActiveDocument (vlax-get-acad-object)))
  (setvar "LTSCALE" 1.0)
  (setvar "MSLTSCALE" 1)
  (setvar "CELTSCALE" 1.0)
  (setvar "PLINEGEN" 1)
  ;; Apply PSLTSCALE = 1 across all Paper Space layouts
  (vlax-for lay (vla-get-Layouts doc)
    (if (/= (vla-get-Name lay) "Model")
      (progn
        (setvar "CTAB" (vla-get-Name lay))
        (setvar "PSLTSCALE" 1)
      )
    )
  )
  (vla-Regen doc acAllViewports)
  (princ "\n[SYNC_LTSCALE] Unified LTSCALE=1, MSLTSCALE=1, PSLTSCALE=1 across all layouts.")
  (princ)
)

4. Diagnostic System Variables & Edge-Case Matrix

Failure Symptom / Scenario Command / SysVar Production Remediation Rule
Dashes look fine in Model, solid in Viewport PSLTSCALE = 1 + REGENALL Scales dashes to paper units regardless of viewport zoom factor.
Curved dashed polyline looks solid continuous PLINEGEN = 1 (Ctrl+1) Enables continuous dash pattern calculation across dense polyline vertices.
Individual line ignores global LTSCALE CELTSCALE = 1.0 Entity-level linetype scale override was set to 100 or 0.01; reset to 1.0.
