How to Print/Plot in AutoCAD

Complete guide to plotting in AutoCAD: page setup, plot styles (CTB/STB), PDF output, and batch plotting multiple layouts.

By Gstarcademy Editorial Team Updated 2026-06-30

How do I print to PDF in AutoCAD?

Use PLOT command > select DWG to PDF.pc3 as the printer > choose paper size > set plot area (Layout or Window) > select plot style table > Preview > OK. For multi-sheet PDFs, use PUBLISH command.

What is the difference between CTB and STB plot styles?

CTB (Color Table Based) maps line appearance by color number — all red objects print the same. STB (Style Table Based) assigns plot styles by name independent of color. STB is more flexible for detailed projects; CTB is simpler for small teams.

How do I batch plot multiple drawings?

Use PUBLISH command or Sheet Set Manager. PUBLISH lets you add multiple DWG files and their layouts to a batch list, then plot all at once to DWF, PDF, or paper. Sheet Set Manager automates this for organized projects.
