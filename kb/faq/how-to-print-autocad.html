How to Print and Plot in AutoCAD: CTB, STB, PDF Output & Batch Publishing

Complete guide to AutoCAD plotting: page setup configurations, CTB vs STB plot style tables, vector PDF export, and batch plotting multiple drawing sheets with Sheet Set Manager.

Author: Gstarcademy Engineering Editorial Board Updated: 2026-08-16

⚡ Quick Answer / Key Takeaway

To plot a clean drawing to PDF in AutoCAD: Press Ctrl+P (or type PLOT), select 'AutoCAD PDF (General Documentation).pc3', choose your paper size (e.g., ISO A1 or ANSI D), set Plot Area to 'Layout' or 'Window', select your monochrome.ctb plot style table, and verify via Preview before printing.

Step-by-Step Instructions & Commands

Step 1: Page Setup Configuration

Right-click your layout tab and open the Page Setup Manager. Select Modify to lock in standard plotter presets. Choose AutoCAD PDF (General Documentation).pc3 or your network plotter. Set the Paper Size (e.g., ARCH D 24x36 in or ISO A1 594x841 mm). Set Plot Area to Layout for 1:1 paper space sheets, and ensure Plot Scale is fixed at 1:1 (1 mm = 1 unit or 1 inch = 1 unit).

Step 2: Assigning and Managing Plot Styles (CTB vs STB)

In the top right of the Plot dialog, select your Plot Style Table. For color-dependent plotting (CTB), assign line weights and screening by AutoCAD color index (e.g., Color 1 Red = 0.18mm, Color 7 White = 0.50mm, monochrome.ctb for solid black lines). For named plot styles (STB), styles are assigned directly to layers or objects regardless of display color.

Step 3: Generating High-Fidelity Searchable PDFs

Click PDF Options in the Plot dialog. Ensure 'Capture fonts used in the drawing' and 'Include layer information' are enabled. This ensures that TrueType text remains searchable and selectable in Adobe Acrobat and Bluebeam Revu, and allows recipients to toggle CAD layers on and off directly in the PDF.

Step 4: Batch Plotting Multi-Sheet Sets (PUBLISH Command)

To export an entire drawing set (20+ sheets) at once, enter PUBLISH. Load all target DWG files and layout tabs, select 'Publish to: PDF', apply Page Setup overrides to ensure consistent plotting parameters, and click Publish. Alternatively, manage project-wide multi-sheet submissions through the Sheet Set Manager (SSM).

Common Issues & Troubleshooting Guide

Common Failure / Problem Root Cause & Recommended Solution
Lineweights appear too thick or muddy in print Check the 'Plot object lineweights' and 'Plot with plot styles' checkboxes in the Plot dialog. Ensure your viewport lineweight scale is not compounding object lineweights. Verify that CTB line weight assignments match title block standards.
PDF text is converted to graphical outlines and is not searchable AutoCAD SHX fonts cannot be embedded as live vector text in PDFs and are turned into geometry. Switch annotations to standard TrueType fonts (such as Arial, Inter, or Roboto), or enable 'Convert text to geometry' settings wisely.
Missing custom CTB plot style files when opening external files Place shared .ctb files in the AutoCAD Printer Support File Path (Options > Files > Printer Support File Path > Plot Style Table Search Path), or type STYLESMANAGER to open the directory directly.

Cross-CAD Compatibility & Alternatives

GstarCAD and ZWCAD fully support all AutoCAD CTB and STB files, PC3 configurations, and the PUBLISH batch plotting engine without any format translation. GstarCAD includes an ultra-fast multi-core PDF printer engine that accelerates large sheet sets.

Engineering Best Practices Checklist

  • Standardize Page Setups in your seed drawing templates (.DWT) so all new sheets inherit correct plot configurations.
  • Always inspect drawing outputs in the full-screen 'Preview' window before executing the physical plot.
  • Use eTransmit when sending drawings to external partners so custom CTB plot styles and font files travel together.
  • Set PDF vector resolution to at least 600 DPI (1200 DPI for dense schematics) to guarantee razor-sharp lines.
