How to Fix Xref Circular References & Unresolved Path Errors in Production?

Circular Xref errors happen when Drawing A references Drawing B as an 'Attachment', and Drawing B also references Drawing A. Resolve by changing reference types from Attachment to 'Overlay', standardizing on Relative Paths, and using Reference Manager to batch-relink missing server drive mappings.

Step-by-Step Engineering Execution

Step 1: Identify Circular Nesting in XREF Palette

Open the External References manager (XREF). Expand Tree View (F6). Look for recurring circular tree loops where files reference each other recursively.

Step 2: Convert Attachments to Overlays

Select the referenced drawings in the list, right-click, and select Xref Type → Overlay. Unlike Attachments, Overlay references do not travel into downstream host files.

Step 3: Convert Absolute Paths to Relative Paths

Right-click the Xrefs and choose Change Path Type → Make Relative. This prevents broken links when files are moved across VPN shares or cloud directories.

Step 4: Batch Relink with Standalone Reference Manager

If a server drive letter changes (e.g., Z: to S:), launch the standalone AdRefMan.exe or GstarCAD Reference Manager to batch-repath hundreds of DWGs in seconds without opening them.
