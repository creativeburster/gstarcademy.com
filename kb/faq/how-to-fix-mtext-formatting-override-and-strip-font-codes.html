How to Strip MTEXT Inline Formatting Overrides (Color, Font & Width Codes)

Remove hardcoded RTF inline color (\C), font (\f), height (\H), and width (\W) overrides inside MTEXT and Multileaders so text obeys ByLayer and TextStyle standards.

By GstarCAD Academy Engineering Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-10-26

⚡ Quick Executive Fix

Double-click the MTEXT to open the In-Place Editor, press Ctrl+A to select all text, and click 'Remove Formatting > Remove All Formatting' on the Ribbon (or press Ctrl+Spacebar). For 1,000+ objects, run our StripMtext AutoLISP scrubber.

1. Engineering Root-Cause Diagnosis inside the AC1032 DWG Database

A chronic frustration for CAD Managers occurs when changing a layer's color in the Layer Properties Manager—or updating the font inside `STYLE`—has **zero effect** on dozens of `MTEXT`, `MLEADER`, and `DIMENSION` callouts. Inspecting the entity's DXF Group `1` string via `(entget (car (entsel)))` reveals embedded Rich-Text control sequences such as {\fArial|b1|i0;\C1;\H2.5x;NOTES:} pasted from Word/PDF or applied via the MTEXT ribbon toolbar, which override `ByLayer` and `TextStyle` inheritance.

2. Step-by-Step Resolution Protocol in AutoCAD & GstarCAD 2027

1. Single-Entity Fix: Ctrl+A + Ctrl+Spacebar in MTEXT Editor

Double-click the offending `MTEXT` object, press Ctrl+A to highlight all paragraphs, and press Ctrl+Spacebar (or click **Clear → Remove All Formatting** in the Text Editor contextual ribbon tab).

2. Prevent Future Word/Excel Paste Pollution (PASTESPEC)

When copying specification clauses from Microsoft Word or PDF into a drawing, do not press `Ctrl+V` directly inside the MTEXT editor. Instead, use **Paste Special → Paste as Plain Text (Unformatted Unicode Text)**.

3. Batch-Scrub Inline Codes Across Entire Drawings via AutoLISP

Use the production regular-expression / string-parser AutoLISP routine below (`C:CLEANMTEXT`) to strip `\f`, `\C`, `\H`, `\W`, `\Q`, and `\T` inline overrides across thousands of `MTEXT` and `MULTILEADER` entities in one second.

3. Automated AutoLISP Diagnostic & Repair Script (C:CLEANMTEXT)

Load the following production AutoLISP routine into GstarCAD 2027 or AutoCAD via APPLOAD (or add it to gcaddoc.lsp) to automate this repair across affected project files:

(defun C:CLEANMTEXT ( / ss i ent obj regEx raw clean)
  (vl-load-com)
  (princ "\nSelect MTEXT entities to strip inline font/color/height overrides: ")
  (if (setq ss (ssget '((0 . "MTEXT"))))
    (progn
      (setq regEx (vlax-create-object "VBScript.RegExp"))
      (vlax-put-property regEx 'Global :vlax-true)
      (vlax-put-property regEx 'IgnoreCase :vlax-true)
      ;; Match inline control codes: \f...; \C...; \H...; \W...; \A...;
      (vlax-put-property regEx 'Pattern "(\\[fFcChHwWtTqQaA][^;]+;|[{}])")
      (repeat (setq i (sslength ss))
        (setq ent   (ssname ss (setq i (1- i)))
              obj   (vlax-ename->vla-object ent)
              raw   (vla-get-TextString obj)
              clean (vlax-invoke regEx 'Replace raw ""))
        (vla-put-TextString obj clean)
        (vla-put-Color obj acByLayer)
      )
      (vlax-release-object regEx)
      (princ (strcat "\n[CLEANMTEXT] Scrubbed inline overrides from " (itoa (sslength ss)) " MTEXT objects."))
    )
  )
  (princ)
)
