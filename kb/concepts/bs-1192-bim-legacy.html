BS 1192 / PAS 1192 (Legacy BIM Standards)

UK BIM standards history: BS 1192, PAS 1192 parts 2-5, and their transition to ISO 19650 international framework.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-08-16 Editorial Process

Definition & Context

BS 1192:2007 and the PAS 1192 suite were the UK standards that pioneered structured BIM information management — defining the CDE, status/revision codes, and naming conventions. They established the collaborative process later internationalised as ISO 19650, which has now superseded them.

Understanding this legacy matters because much UK guidance, terminology, and existing project documentation still references BS/PAS 1192 concepts that map onto ISO 19650.

Why It Matters

The BS/PAS 1192 framework is the origin of modern BIM information management. Recognising how its concepts map to ISO 19650 helps interpret legacy documents and transition older projects.

Best Practices

  • Map BS/PAS 1192 terms to their ISO 19650 equivalents on legacy projects.
  • Adopt ISO 19650 for new work while honouring existing 1192 references.
  • Preserve the CDE/status-code discipline the standards introduced.
  • Update templates and BEPs to current ISO terminology.

Common Pitfalls

  • Treating BS/PAS 1192 as current for new projects.
  • Confusing 1192 and 19650 terminology in documentation.
  • Losing the underlying CDE discipline during the transition.
  • Assuming a rename is all that changed between the standards.

Core Commands & Practical System Operations

Executing BS 1192 / PAS 1192 (Legacy BIM Standards) effectively relies on specialized CAD/BIM command workflows and system variable configurations: BIM & CAD tools: WALL, FLOOR, ROOF, FAMILY, XREF, IFCEXPORT. Setup: Coordinate shared project base points, configure Level/Grid datum.

Standard Engineering Workflow for BS 1192 / PAS 1192 (Legacy BIM Standards)

1. Spatial Programming & Shared Georeferencing

Establish project base points, survey coordinates, building storeys, and column grid systems coordinated across architectural, structural, and MEP consultants.

2. LOD 200 - 300 Parametric Component Assembly

Model multi-layer architectural assemblies (curtain walls, structural framing, floor slabs, MEP risers) using intelligent parametric family components.

3. Interdisciplinary Clash Detection & Coordination

Federate discipline models in Navisworks or Solibri. Run automated hard/soft clash tests and track issues using BCF (BIM Collaboration Format) workflows.

4. 2D Construction Documentation & Quantity Schedules

Extract live plans, building sections, elevations, and automated component schedules (doors, windows, concrete volume) linked directly to the central model.
