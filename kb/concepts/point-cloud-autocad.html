Point Cloud Attachment

Attaching and working with laser-scan point cloud data (RCS/RCP) in AutoCAD for as-built documentation.

By Gstarcademy Editorial Team Updated 2026-07-28 Editorial process

Definition & Context

AutoCAD attaches indexed point clouds from laser scanning/LiDAR as external references in the RCP/RCS format created by Autodesk ReCap (POINTCLOUDATTACH). The cloud is referenced rather than embedded, keeping the DWG small.

Once attached you can clip/crop, adjust display (color by intensity, elevation, or RGB), snap to points with point-cloud object snaps, and use section planes and dynamic UCS to model against the scan.

Why It Matters

Point clouds let you model as-built/existing conditions directly against surveyed reality, which is essential for renovation and verification work.

Because the cloud is referenced through ReCap, managing the RCP project and clipping is what keeps performance workable on large scans.

Best Practices

  • Index raw scans in ReCap to RCP/RCS first; attach the RCP, not raw scan files
  • Clip to the working area and control point density/display to keep performance up
  • Use point-cloud osnaps and section planes to extract geometry accurately
  • Keep the RCP with the project so the referenced attachment doesn't go missing

Common Pitfalls

  • Attaching without clipping — sluggish performance on dense clouds
  • Broken references when the RCP/RCS files move
  • Treating the cloud as solid geometry — it's points; you still model the CAD objects
