CONNECT Edition

The next generation: A modernized, 64-bit infrastructure platform designed for cloud collaboration and massive data performance.

The 64-bit Leap

The CONNECT Edition is the most significant update to Bentley's software in decades. By moving to a full 64-bit architecture, it breaks the memory barriers of legacy software, allowing designers to load and manipulate massive 3D reality meshes and complex drawing sets that would crash other CAD tools. It also introduces a unified, cloud-connected environment for project delivery.

Modern Platform Features

  • Ribbon UI: A modernized, context-sensitive user interface that increases productivity by putting the right tools at your fingertips.
  • Connected Projects: Built-in integration with the ProjectWise Connection Client for instant access to project data and news.
  • Constraint-Based Modeling: Powerful parametric modeling tools that allow you to define geometric relationships and rules.
  • Personal Portal: Each user has a personalized dashboard to track project status, learning progress, and software updates.

Future-Ready Design

The CONNECT Edition ensures that Bentley users are ready for the era of digital twins, cloud collaboration, and the ever-increasing scale of global infrastructure projects.
