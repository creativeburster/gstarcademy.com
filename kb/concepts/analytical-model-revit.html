Analytical Model

Revit's analytical model for structural analysis export — nodes, members, loads, and boundary conditions linked to physical elements.

By Gstarcademy Editorial Team Updated 2026-06-30 Editorial process

Definition & Context

Revit's analytical model is a simplified geometric representation of structural elements used for export to analysis software (Robot Structural Analysis, ETABS, SAP2000, RISA). Physical columns become centerline stick elements; walls become shell elements; floors become plate elements. The analytical model carries load cases, boundary conditions (fixed, pinned, roller), member releases, and cross-section properties.

Key workflow: enable Analytical Model visibility in View Visibility Graphics > Analytical Model Categories. Adjust analytical representations using the Analytical Adjust tool to fix misaligned nodes, ensure member connectivity, and verify support conditions. The Analytical Consistency Check identifies disconnected members and unsupported nodes.

Export paths: direct link to Robot Structural Analysis Professional (bi-directional), or generic export via IFC Structural Analysis View, CIS/2 (steel), or third-party plugins (ETABS Link, RISA Link). Revit 2024+ includes the new Analytical Model category with explicit node/member management.

Why It Matters

Mastery of Analytical Model directly impacts productivity, output quality, and cross-discipline collaboration in Autodesk Revit projects. Engineers and designers who command this feature reduce rework cycles, meet tighter deadlines with fewer errors, and produce deliverables that downstream consumers (fabricators, analysts, facility managers) can use without manual data reconstruction.

In competitive workflows where multiple stakeholders depend on model data quality, proficiency with Analytical Model distinguishes experienced practitioners who deliver right-first-time results from novice users who generate downstream coordination issues.

Best Practices

  • Run Analytical Consistency Check before every export to identify disconnected nodes and unsupported members
  • Adjust analytical alignment so beam endpoints meet column centerlines precisely — 1mm gaps cause disconnected models in FEA
  • Define load cases (dead, live, wind, seismic) and load combinations within Revit before transferring to analysis software
  • Use analytical links (Robot, ETABS) for bi-directional workflows: analyze → resize members → update back to physical model
  • Set correct boundary conditions at foundations (fixed) and expansion joints (roller) to reflect real structural behavior

Common Pitfalls

  • Physical model modifications don't always propagate to analytical model — re-check analytical alignment after major edits
  • Curved beams have no analytical equivalent in most FEA links — they export as chord-approximated segments or are skipped
  • Load path discontinuities (floating beams, columns not reaching foundations) pass silently in Revit but cause solver failures in FEA
  • Exporting to Robot without checking unit consistency between Revit's project units and Robot's model units
