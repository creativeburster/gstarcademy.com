INSUNITS, INSUNITSDEFNAME & Insertion Units Scaling

Technical guide to INSUNITS, INSUNITSDEFNAME, and INSUNITSSOURCENAME system variables. Eliminate 25.4x block scaling errors between Metric and Imperial DWGs.

By Gstarcademy Editorial Team Updated 2026-10-12 Editorial process

1. Definition & Engineering Significance

The INSUNITS system variable specifies drawing-level units for automatic scaling when inserting blocks, images, or external references into host drawings. Paired with INSUNITSSOURCENAME and INSUNITSDEFNAME, it establishes the dimensional truth of the DWG database. When unit definitions mismatch—such as dragging an architectural millwork block drawn in millimeters into a civil plan drawn in meters or feet—CAD applies real-time automatic scale factors to preserve true physical dimensions.

2. Technical Architecture & Key Parameters

  • Unit Code 0 (Unspecified): Disables automatic scaling. Entities are inserted 1:1 by raw coordinate units, relying entirely on manual scale factors.
  • Unit Code 1 (Inches) vs 4 (Millimeters): Inserting a millimeter block (4) into an inch drawing (1) automatically scales the inserted geometry down by a factor of 1/25.4 (0.03937).
  • Unit Code 6 (Meters): Standard for civil engineering, infrastructure, and landscape master plans. Millimeter details inserted here scale down by 0.001 automatically.
  • INSUNITSDEFNAME & SOURCENAME: Specify default fallback units when an inserted DWG or host drawing has INSUNITS set to 0 (unitless).

3. Industry Best Practices & Failure Modes

The infamous '25.4x scaling explosion or shrinkage' is the most ubiquitous error caused by improper INSUNITS configuration. When a draftsman draws in millimeters but leaves INSUNITS=1 (Inches), inserting that block into an architectural millimeter project multiplies its size by 25.4 times, burying the entire layout inside an enormous component. Conversely, inserting into a foot-based template shrinks components to microscopic specks.

4. Production Governance & Standard Protocols

To enforce international engineering standards, enterprise templates must declare explicit units via UNITS or (setvar "INSUNITS" 4) for metric mm, 6 for meters, or 1/2 for imperial inches/feet. Eliminating unitless '0' configurations prevents unexpected scaling anomalies across cross-firm submittals and vendor part libraries.
