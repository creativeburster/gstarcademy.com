Config.pro Mastery

The engine room: Using the master configuration file to tailor every aspect of the Creo experience.

The Core Configuration

Almost everything about how Creo looks, feels, and calculates is controlled by a simple text file called config.pro. From the default unit system (mm vs inch) to the search paths for your part library, this file is the brain of your Creo installation.

The Loading Sequence

Creo loads configuration files in a specific order, with later files overriding earlier ones:

  • Loadpoint: Global settings for all users in an organization.
  • Home Directory: Personal settings that follow the user.
  • Current Working Directory: Project-specific settings (e.g., custom tolerances for a specific client).
  • Config.sup: A 'super-config' that cannot be overridden by users (for IT enforcement).

Critical Options

Essential options include template_solidpart for default templates, drawing_setup_file for drafting standards, and search_path for linking external libraries without moving files.
