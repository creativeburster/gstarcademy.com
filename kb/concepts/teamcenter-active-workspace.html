Active Workspace

PLM anywhere, anytime: Empowering the entire enterprise with intuitive, high-speed access to product data.

The Modern Face of PLM

Traditionally, PLM systems were difficult to use and required powerful desktop computers. Active Workspace is Siemens' web-based interface for Teamcenter. Built with modern HTML5 technology, it provides a fast, touch-friendly, and intuitive way to find, view, and approve product data from a browser on any device—tablet, smartphone, or laptop.

Core UX Features

  • Zero-Install: No client software needed; access PLM directly via a secure URL.
  • Smart Search: Find parts and documents as easily as using a search engine, with intelligent filtering (facets).
  • Visual Review: View and markup 3D JT models and 2D drawings without needing a CAD license.
  • Workflow Participation: Approve design changes or sign off on milestones with a single tap.

Democratizing Data

Active Workspace brings PLM to the non-experts, allowing the entire value chain (marketing, sales, manufacturing, and supply chain) to participate in the product lifecycle.
