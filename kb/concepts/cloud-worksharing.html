Cloud Worksharing

Enabling real-time collaborative modeling for distributed teams using a centralized model hosted on Autodesk cloud servers.

Core Mechanism

Cloud Worksharing replaces the traditional local server 'Central Model' with a cloud-hosted repository. Each user maintains a local cache, and changes are synchronized via delta-transfer technology, ensuring only modified elements are uploaded/downloaded.

Key Advantages

  • Location Independence: Teams in different cities or working from home can model in the same file simultaneously.
  • Automated Versioning: BIM 360 / Autodesk Docs maintains a history of every 'Sync with Central' event.
  • Clash Avoidance: Real-time element borrowing prevents two users from editing the same wall or pipe at the same time.

Troubleshooting Sync Issues

If synchronization fails, verify the Revit Version (Build Number) is identical across all machines. Discrepancies in service packs can lead to data corruption in the cloud central model.
