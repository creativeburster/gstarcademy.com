Layer Management

The primary organizational tool in CAD for grouping related objects and controlling visual properties.

Core Definition

Layers act like transparent overlays. By assigning objects to layers, you can control visibility (On/Off, Freeze/Thaw), lock states, and plotting behavior globally.

Standard Properties

  • Color: Visual distinction on screen and plotting logic (CTB/STB).
  • Linetype: Continuous, dashed, or dotted definitions.
  • Lineweight: Physical thickness for printed deliverables.
  • Transparency: Visual fading for background elements.

Best Practices

ByLayer vs ByBlock

Always set properties to 'ByLayer' for maximum control through the Layer Manager.

Layer Filters

Use Property Filters to manage hundreds of layers in large-scale AEC projects.
