Parasolid Geometry Kernel

The Parasolid geometric modeling kernel used by SOLIDWORKS, NX, Solid Edge, and other major CAD systems.

By Gstarcademy Editorial Team Updated 2026-07-28 Editorial process

Definition & Context

Parasolid is a geometric modeling kernel developed by Siemens Digital Industries Software that provides B-Rep solid and surface modeling to host applications. It powers SOLIDWORKS, Siemens NX, and Solid Edge, and is licensed to hundreds of other products — it is the engine beneath the CAD UI, not an end-user program.

Parasolid handles the underlying mathematics of solids: Boolean operations, blends/fillets, sweeps, lofts, tolerant modeling, and topology queries. Data is serialized as Parasolid XT (text .x_t / binary .x_b), a widely supported transmit format for moving true solids between Parasolid-based systems.

Why It Matters

Because so many CAD systems share Parasolid, an .x_t/.x_b transmit file usually round-trips solids more reliably between them than a generic IGES/STEP export — handy when moving models between, say, SOLIDWORKS and NX.

Recognizing that a kernel (Parasolid vs ACIS) sits under the interface explains cross-system translation behavior: mismatched tolerance and healing between different kernels is what produces slivers and failed Booleans.

Best Practices

  • For solid exchange between Parasolid-based systems, prefer XT (.x_t/.x_b) over IGES to preserve true B-Rep solids
  • Use binary .x_b for large models (smaller, faster); use text .x_t when you need to inspect or debug
  • When translating to a non-Parasolid (ACIS) host, expect and plan for healing at surface boundaries
  • Match modeling tolerance to the receiving application to minimize tiny-edge/sliver artifacts

Common Pitfalls

  • Assuming XT carries features or history — it transmits geometry and topology, not the feature tree
  • Mixing kernels (Parasolid ↔ ACIS) without healing, leaving micro-gaps that break downstream Booleans
  • Confusing the kernel with the CAD application — Parasolid is the engine, not the user-facing product
