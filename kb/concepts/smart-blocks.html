Smart Blocks

Leveraging Machine Learning to identify patterns and automate the conversion of static geometry into reusable blocks.

Core Definition

Smart Blocks (introduced in the 2024/2025/2026 cycle) use the BSEARCH command to scan a drawing. The engine identifies sets of lines, arcs, and text that match existing block definitions or common symbol patterns and offers to replace them with block references.

Key Workflow Components

  • Auto-Mapping: Automatically detects text inside geometry and converts it to block attributes.
  • Placement Suggestions: Predicts where a block should be inserted based on the existing context of the drawing.
  • Standardization: Ideal for cleaning up legacy drawings where blocks were "exploded" or created inconsistently.

Related System Variables

BCONVERTLAYER

Controls whether objects are moved to 'Layer 0' during conversion, which is essential for ensuring block visibility follows layer properties correctly.
