DIMASSOC System Variable & Associative Dimensions

In-depth reference for DIMASSOC system variable. Learn how to prevent exploded or disassociated dimensions that fail to update when geometry stretches.

By Gstarcademy Editorial Team Updated 2026-10-12 Editorial process

1. Definition & Engineering Significance

The DIMASSOC system variable governs the associative relationship between dimension objects and the geometric entities they measure in AutoCAD, GstarCAD, and BricsCAD. When associative dimensioning is enabled, modifying the underlying geometry—such as moving an endpoint, stretching a wall, or filleting a plate corner—automatically causes the dimension line, witness extension lines, and numerical text to update synchronously in real time.

2. Technical Architecture & Key Parameters

  • Value = 2 (Associative Dimensions): Dimensions are fully associative. They bind to geometric entity snap points and automatically recalculate values and positions when geometry is stretched. Supports Model-to-Paper space dimensioning across viewports.
  • Value = 1 (Non-Associative Dimensions): Dimensions are unified single objects, but they lack geometric binding. Stretching measured lines leaves dimension values unchanged at their original coordinates.
  • Value = 0 (Exploded Dimensions): Dimensions are created as disconnected primitive lines, arrows, solids, and text strings. Heavily discouraged in modern drafting due to total loss of parametrics.
  • DIMREASSOCIATE Command: Re-attaches dangling non-associative dimensions back to geometric vertices when model edits break original handles.

3. Industry Best Practices & Failure Modes

Operating with DIMASSOC=1 or 0 introduces catastrophic risk into engineering manufacturing and fabrication drawings. When a mechanical designer stretches a shaft diameter by 5mm, non-associative dimensions continue to display the obsolete measurement, resulting in incorrectly machined components on the shop floor. Furthermore, paper space dimensions placed across viewports require DIMASSOC=2 to calculate true Model Space scale factors correctly.

4. Production Governance & Standard Protocols

Corporate CAD standards mandate setting DIMASSOC=2 across all production drawing templates. Drafters should monitor disassociated dimensions using the Dimension Monitor feature (controlled by ANNOMONITOR=2), which displays an alert badge over any dimension whose geometric anchor has been deleted or detached.
