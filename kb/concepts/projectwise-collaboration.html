Enterprise Strategy

ProjectWise

The collaborative backbone: Connecting distributed engineering teams through a unified, high-performance project information hub.

Global Design Integration

AEC projects involve thousands of files and hundreds of external references (XREFs). ProjectWise is the information management system that ensures everyone is working on the correct version of every file. It automates the synchronization of data across global offices, eliminating the delays and errors associated with manual file transfers.

Core Collaborative Tools

  • XREF Management: Automatically resolves and updates complex links between CAD, BIM, and reality modeling files.
  • Workflow Control: Manage the lifecycle of documents (Draft, Review, Approved) with strict permissions and audit trails.
  • Delta File Transfer: Sync only the bits of a file that have changed, enabling real-time collaboration even on low-bandwidth connections.
  • Standards Enforcement: Ensure that every file created across the enterprise follows strict project naming and layer standards.

Connecting the World

ProjectWise is the 'secret sauce' behind the world's largest engineering projects, allowing global giants like AECOM and Jacobs to operate as a single, unified design office.
