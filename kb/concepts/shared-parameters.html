Shared Parameters

The backbone of BIM data consistency: ensuring that information can be tracked, tagged, and scheduled across any project.

Universal Data Definitions

Unlike 'Project Parameters', which are internal to a single Revit file, Shared Parameters are defined in an external text file. This GUID-based system ensures that a parameter named 'Maintenance_Date' in a Pump family is recognized as the SAME parameter when placed into a Project file.

Why They are Essential

  • Tagging: Only Shared Parameters can be displayed in Tags.
  • Scheduling: Essential for combining data from different family categories into a single schedule.
  • Cross-Project Standards: Allows multi-discipline firms to maintain consistent COBie or facility management data.
  • Automation: API scripts rely on Shared Parameter GUIDs for robust data writing and reading.

Management Tip

Never edit the Shared Parameter .txt file manually. Always use the Revit interface to add or modify parameters to avoid corrupting the GUID mapping, which would render your existing project data unreachable.
