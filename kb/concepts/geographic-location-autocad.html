Geographic Location & GIS

AutoCAD's geographic information features including coordinate systems, map imagery, and GIS data integration.

By Gstarcademy Editorial Team Updated 2026-07-28 Editorial process

Definition & Context

GEOGRAPHICLOCATION assigns a real-world coordinate system and position to a drawing, letting AutoCAD place it on the earth. Once set, GEOMAP can display online aerial/road imagery aligned to the model, and coordinates report in the assigned GIS coordinate system.

The geographic marker defines latitude/longitude and north; drawings can be reprojected between supported coordinate systems, and map imagery can be captured to raster for plotting. This gives a CAD drawing a mapping context without being a full GIS.

Why It Matters

Geolocation lets site and infrastructure drawings sit on real-world coordinates and against aerial imagery, which matters for civil/site coordination and for exchanging data with GIS.

Getting the coordinate system right is what makes the model line up with survey and GIS data instead of floating in arbitrary space.

Best Practices

  • Set the coordinate system for the project region so data aligns with survey/GIS
  • Insert the geographic marker at a known surveyed point
  • Use GEOMAP imagery as reference; capture to raster when you need it on a plot
  • Confirm units and north orientation match the survey

Common Pitfalls

  • Choosing the wrong coordinate system — the model ends up misaligned with real-world data
  • Treating map imagery as survey-accurate geometry
  • Assuming AutoCAD geolocation replaces a real GIS for analysis
