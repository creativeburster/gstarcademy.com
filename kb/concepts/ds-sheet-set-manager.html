Sheet Set Manager

Orchestrating complex drawing packages: A centralized hub for multi-file project documentation and publishing.

Beyond Single Files

When a project grows to dozens of drawings, managing them individually becomes a liability. The Sheet Set Manager (SSM) in DraftSight creates a project link (.dst file) that treats multiple DWGs as a single logical 'Set'.

SSM Advantages

  • Global Properties: Change the project name or date once in the SSM, and it updates every title block in the entire set via Fields.
  • Automated Indexing: Generate a Sheet List Table that automatically updates as you add or remove drawings.
  • One-Click Publishing: Plot the entire set to a single multi-page PDF with one command.
  • Structured Navigation: Organize drawings into 'Subsets' (e.g., Civil, Structural, MEP) for easier access.

Professional Workflow

DraftSight's SSM is fully compatible with AutoCAD's .dst format, allowing teams to collaborate on project structures regardless of which software they are using.
