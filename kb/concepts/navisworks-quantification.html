Quantity Takeoff

Quantification

Automating material takeoff (MTO) and cost estimation by extracting quantities directly from federated coordination models.

The 5D BIM Workflow

Quantification in Navisworks (often called 5D BIM) allows estimators to move away from manual 'ruler and paper' takeoffs. It uses the properties embedded in BIM models (Volume, Length, Area) and maps them to a project-specific Workbook for instant calculation of materials.

Key Tool Features

  • Automated Takeoff: Map Revit categories to specific items in your cost catalog for instant counting.
  • Virtual Takeoff: Manually measure items in the 3D model that were NOT modeled by the designer (e.g., temporary bracing).
  • 2D & 3D Integration: Combine quantities from 3D models with manual takeoffs from 2D PDF/DWF sheets within the same workbook.
  • Change Tracking: Compare two versions of a model to see how material quantities have changed between design iterations.

Project Setup

Before starting, import a standardized Catalog (e.g., MasterFormat or UniFormat) to ensure that the extracted quantities match your company's existing estimation software structure.
