ACIS Geometry Kernel

The ACIS (SAT/SAB) 3D modeling kernel used by AutoCAD, BricsCAD, SpaceClaim, and other CAD platforms.

By Gstarcademy Editorial Team Updated 2026-06-30 Editorial process

Definition & Context

ACIS (originally Alan, Charles, Ian's System) is a geometric modeling kernel developed by Spatial (Dassault Systèmes subsidiary) that provides B-Rep (boundary representation) solid modeling capabilities to host CAD applications. AutoCAD, BricsCAD, SpaceClaim, and approximately 50 other products embed ACIS for solid/surface operations.

The kernel supports: precise NURBS surfaces, analytic surfaces (planes, cylinders, cones, spheres, tori), Boolean operations, blending (fillets/chamfers), sweeps, lofts, shelling, and topology queries. Data is serialized in SAT (text) or SAB (binary) file formats. AutoCAD's ACISOUT/ACISIN commands export/import native kernel data.

ACIS differs from Parasolid (used by SOLIDWORKS, NX) in its tolerance handling, healing algorithms, and surface intersection strategies. Translation between ACIS-based and Parasolid-based CAD often introduces tiny geometric mismatches at surface boundaries requiring healing operations.

Why It Matters

Mastery of ACIS Geometry Kernel directly impacts productivity, output quality, and cross-discipline collaboration in AutoCAD projects. Engineers and designers who command this feature reduce rework cycles, meet tighter deadlines with fewer errors, and produce deliverables that downstream consumers (fabricators, analysts, facility managers) can use without manual data reconstruction.

In competitive workflows where multiple stakeholders depend on model data quality, proficiency with ACIS Geometry Kernel distinguishes experienced practitioners who deliver right-first-time results from novice users who generate downstream coordination issues.

Best Practices

  • Use SAT format (text-based) for debugging geometry issues — open in any text editor to inspect entity topology
  • When exchanging between ACIS and Parasolid hosts, export via STEP AP214 to minimize kernel translation artifacts
  • Set appropriate tolerance values (typically 1e-6 for mechanical, 1e-4 for architectural) before Boolean operations
  • Validate solid topology after complex Boolean chains with CHECKSOLID or equivalent host commands
  • Prefer the binary SAB format for production file exchange — 3-5x smaller than SAT with faster parsing

Common Pitfalls

  • ACIS version mismatches cause import failures — older hosts cannot read SAT files written by newer kernel versions
  • Slivers and micro-edges from imprecise Boolean operations accumulate and eventually crash downstream operations
  • ACIS does not natively support mesh/facet bodies — importing STL into ACIS-based CAD requires conversion to B-Rep
  • Stitching open surfaces into solids fails when edge gaps exceed the session tolerance — increase tolerance or heal edges first
