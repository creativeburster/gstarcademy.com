Product Template Studio (PTS)

Encapsulating excellence: Turning complex, expert-level CAD models into simple, fail-safe templates for the entire team.

Codeless Automation

Capturing engineering knowledge often requires complex programming. NX PTS allows experts to build custom User Interfaces (UIs) for their models without writing a single line of code. By dragging and dropping controls (sliders, checkboxes, input fields), you can create a simplified dashboard that allows non-experts to configure complex designs safely.

Core PTS Features

  • UI Authoring: Create professional dialog boxes that look and behave like native NX commands.
  • Rule Enforcement: Build 'checkers' into the template to prevent users from entering invalid values (e.g., 'Diameter must be > 10mm').
  • Visual Feedback: Include images and instructional text directly in the template interface to guide the user.
  • Associative Propagation: When a user updates a template value, the underlying complex feature tree regenerates automatically.

Scalable Engineering

PTS enables companies to protect their intellectual property (IP) while empowering designers to reuse proven engineering logic, leading to massive gains in design speed and quality.
