DWG Compare

A visual verification workflow that highlights geometry and property differences between two drawing versions.

Core Definition

DWG Compare allows users to identify changes by overlaying a "comparison" drawing on top of a "current" drawing. Typically, objects that exist in only one of the drawings are color-coded (often Green/Red), while identical objects remain neutral (Gray).

Technical Implementation

  • Geometric Analysis: Compares vectors, arcs, and polylines for spatial deviation.
  • Attribute Tracking: Detects changes in layers, colors, and line types.
  • Xref Integration: High-end implementations can compare differences within External References (Xrefs).

Software Availability

GstarCAD 2026

Fully optimized engine. Supports fast comparison of large site plans and complex Xrefs. Includes a comparison toolbar for live toggling.

AutoCAD

Native feature since 2019. Offers cloud-based comparison and robust local engine with "Compare" workspace.
