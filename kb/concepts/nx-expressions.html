Mathematical Design

NX Expressions

The logic engine: Using formulas and variables to drive geometry with engineering intelligence.

More Than Dimensions

In NX, every dimension (length, angle, radius) is an Expression. You can rename these expressions (e.g., from 'p1' to 'Shaft_Dia') and build complex mathematical relationships between them. This allows you to create 'smart' parts that adjust their shape automatically based on a few input variables.

Expression Power Tools

  • Formulas: Use trigonometry, logarithms, and standard arithmetic to calculate dimensions (e.g., Hole_Spacing = Length / (Num_Holes + 1)).
  • Conditional Logic: Use 'If-Then-Else' statements to change geometry based on thresholds.
  • Unit Management: Seamlessly mix and convert between Metric and English units within the same model.
  • External Linking: Connect the Expression Editor to Excel for mass-driving complex design tables.

Intelligent Automation

By mastering Expressions, NX users can build modular, reusable templates that reduce the time to create design variants from hours to minutes.
