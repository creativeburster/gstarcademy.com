SOLIDWORKS eDrawings

Lightweight CAD viewer and collaborative review for cross-functional teams.

Core Concepts

eDrawings is a lightweight, high-fidelity CAD visualization utility. It allows engineers to publish compressed CAD assemblies and drawings that can be easily shared, reviewed, and marked up by project managers, purchasing teams, and shop-floor technicians without high-end CAD seats.

Key Advantages & Applications

  • Self-Contained Previews: Embedded model geometries allow full pan, zoom, and section cuts in email-friendly files.
  • Interactive Markups: Draw redlines, add text comments, and measure 3D coordinates directly.
  • AR & VR Support: View assemblies at 1:1 scale using mobile cameras and VR headsets.

Industry Best Practices

Enable measurement protection when sending models to external partners. Combine multi-sheet drawings into a single eDrawings package for client reviews.
