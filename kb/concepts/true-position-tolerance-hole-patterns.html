True Position Tolerance for Hole Patterns

A GD&T control defining a cylindrical tolerance zone within which the center axis of a manufactured hole must lie relative to specified datums.

By Gstarcademy Editorial Team Updated 2026-09-30 Editorial process

1. Definition & Engineering Significance

Traditional ±0.1mm linear coordinate tolerances create a square tolerance zone, artificially rejecting good parts whose diagonal deviation is functionally acceptable. True Position defines a round cylindrical zone, providing 57% more usable tolerance area without compromising fastener clearance.

2. Key Technical Characteristics & Rules

  • Cylindrical Tolerance Zone (⌀ symbol): Encompasses all 360 degrees equally around the theoretically exact basic dimension.
  • Fastener Clearance Formula: Minimum Clearance Hole = Maximum Fastener Body + Positional Tolerance Zone.
  • Composite Positional Control: Top segment controls pattern location to datums; bottom segment tightens hole-to-hole spacing within the pattern.

3. Cylindrical Tolerance Zones & True Position Math

True Position per ASME Y14.5 replaces legacy rectangular plus-minus coordinate tolerance zones with cylindrical tolerance fields:

  • 57% Extra Usable Area: A cylindrical tolerance zone (∅ 0.28mm) circumscribes a square ±0.10mm box, providing 57% more allowable manufacturing zone without reducing functional clearance.
  • True Position Formula: Position Deviation = 2 * √((X_actual - X_basic)² + (Y_actual - Y_basic)²).
  • Pattern Composite Callouts: Dual-tier feature control frames control pattern location relative to external datums in the top tier, while tightly controlling hole-to-hole spacing in the lower tier.

4. Functional Assembly Verification

When inspecting multi-hole flange patterns, coordinate deviation must be evaluated simultaneously across all holes when Maximum Material Condition is invoked. Inspecting holes individually on calipers masks collective pattern rotation errors that cause assembly bolt jamming.
