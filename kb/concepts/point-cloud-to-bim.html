Point Cloud to BIM (Scan-to-BIM)

Scan-to-BIM workflows: laser scanning existing buildings, registering point clouds, and modeling BIM elements from scan data.

By Gstarcademy Editorial Team Updated 2026-06-30 Editorial process

Definition & Context

Scan-to-BIM converts reality-capture data (laser scans, photogrammetry) into a BIM model. The workflow is capture (terrestrial/handheld LiDAR, drones) → register multiple scans into one coordinate system → import the point cloud (RCP/RCS, E57, LAS) → model walls, structure, and MEP to the required LOD.

Tools include Autodesk ReCap, Leica Cyclone/CloudWorx, and modelling in Revit/ArchiCAD. Semi-automated feature extraction speeds modelling of planar and cylindrical elements.

Why It Matters

Scan-to-BIM captures existing/as-built conditions accurately for renovation, heritage, and verification — replacing error-prone manual measurement of complex existing buildings.

Best Practices

  • Plan scan coverage/overlap and register to a known coordinate system.
  • Decimate/clean clouds to keep models workable.
  • Model only to the LOD the project actually needs.
  • Verify the model against the cloud with deviation checks.

Common Pitfalls

  • Poor registration causing misaligned, unusable clouds.
  • Over-modelling every scan artefact instead of design intent.
  • Massive un-decimated clouds crippling performance.
  • No verification, so the model drifts from as-built reality.
