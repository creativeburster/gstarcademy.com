Point Cloud to BIM (Scan-to-BIM)

Scan-to-BIM workflows: laser scanning existing buildings, registering point clouds, and modeling BIM elements from scan data.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-08-16 Editorial Process & Testbed

Definition & Context

Scan-to-BIM converts reality-capture data (laser scans, photogrammetry) into a BIM model. The workflow is capture (terrestrial/handheld LiDAR, drones) → register multiple scans into one coordinate system → import the point cloud (RCP/RCS, E57, LAS) → model walls, structure, and MEP to the required LOD.

Tools include Autodesk ReCap, Leica Cyclone/CloudWorx, and modelling in Revit/ArchiCAD. Semi-automated feature extraction speeds modelling of planar and cylindrical elements.

Why It Matters

Scan-to-BIM captures existing/as-built conditions accurately for renovation, heritage, and verification — replacing error-prone manual measurement of complex existing buildings.

The value is a coordinated, dimensionally-trustworthy model of what is actually there — not what old drawings claim — so designers can fit new work to reality and catch conflicts before construction. The main effort is deciding the level of detail worth modelling: teams should agree the target LOD/LOIN per element up front, because modelling every scanned artefact wastes time while under-modelling misses the conditions the project needs.

Best Practices

  • Plan scan coverage/overlap and register to a known coordinate system.
  • Decimate/clean clouds to keep models workable.
  • Model only to the LOD the project actually needs.
  • Verify the model against the cloud with deviation checks.

Common Pitfalls

  • Poor registration causing misaligned, unusable clouds.
  • Over-modelling every scan artefact instead of design intent.
  • Massive un-decimated clouds crippling performance.
  • No verification, so the model drifts from as-built reality.

Standards & Interoperability

  • Agree a target LOD (level of development) / LOIN (ISO 19650) per element before modelling
  • Import via E57 (ASTM E2807) or RCP/RCS (ReCap); register to the project coordinate reference system
  • Deliver the model as IFC for openBIM coordination and archiving
  • Eurocode 7 (Geotechnical Design - EN 1997)
  • ISO 19650 (BIM for Civil Infrastructure)

Horizontal curve radius triggers AASHTO violation flagsAdjust minimum transition spiral length or increase curve radius to meet minimum design speed superelevation criteria.
Coordinates offset by several meters after CAD/GIS importVerify projection datum and false easting/northing parameters in MAPCSASSIGN before importing geospatial shapefiles.
