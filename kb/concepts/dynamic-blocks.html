Dynamic Blocks

Flexible block definitions that can change shape, size, or configuration using predefined parameters and actions.

Beyond Static Symbols

A static block for a door requires a separate file for every width (600, 800, 900mm). A Dynamic Block uses a 'Linear Parameter' and a 'Stretch Action' to allow a single block instance to be adjusted to any width on-the-fly.

Key Components

  • Parameters: Define the geometry that can change (Distance, Rotation, Visibility).
  • Actions: Define HOW the geometry changes (Move, Scale, Stretch, Flip, Array).
  • Visibility States: Allow you to store different 'views' (e.g., Top, Front, Side) within a single block.
  • Block Authoring Palette: The specialized workspace where these rules are defined.

Best Practice: Reset Block

If a dynamic block becomes distorted, use the RESETBLOCK command to restore it to its default definition state.
