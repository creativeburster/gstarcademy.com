ISO 19650 BIM Information Management

ISO 19650 framework for BIM information management: naming conventions, model production delivery tables, and CDE workflows.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-07-28 Editorial Process

Definition & Context

ISO 19650 is the international standard for managing information over the whole life cycle of a built asset using BIM. It defines roles, an information delivery cycle, and the concept of a Common Data Environment (CDE) with states (Work in Progress, Shared, Published, Archived).

Key artefacts include the OIR/AIR/EIR/PIR requirement hierarchy, the BIM Execution Plan (BEP), and the Master Information Delivery Plan (MIDP). It evolved from the UK BS 1192 / PAS 1192 suite and is now the global reference for BIM information management.

Why It Matters

ISO 19650 provides the contractual and procedural backbone that makes multi-party BIM collaboration auditable and repeatable. Clients increasingly mandate compliance, so knowing the terminology and deliverables is essential for winning and delivering work.

The standard is deliberately process-first, not software-specific: it says nothing about which BIM tool to use, only how information is requested (EIR/PIR), planned (BEP/MIDP), produced, checked, and approved through the CDE states. That is why “doing ISO 19650” is an organisational capability — appointing information managers, agreeing naming and status conventions, and gating deliverables — rather than a feature you switch on in an authoring tool.

Best Practices

  • Define the Exchange Information Requirements (EIR) up front so everyone knows what to deliver and when.
  • Operate a single CDE with disciplined status codes and revision control.
  • Produce and maintain the BEP and MIDP as living documents, not tick-box paperwork.
  • Use consistent naming conventions and information containers across all parties.

Common Pitfalls

  • Treating ISO 19650 as software rather than a process/management standard.
  • A CDE in name only, with files emailed around outside it.
  • Vague EIRs leading to under- or over-delivered information.
  • Confusing UK National Annex specifics with the core international standard.

Enterprise Production Implementation & GstarCAD 2027 Workflow

In industrial engineering production, mastering ISO 19650 BIM Information Management is essential for maintaining strict drawing database hygiene, geometric precision, and cross-disciplinary interoperability across DWG, BIM (IFC 4.3), and mechanical (STEP AP242 / ASME Y14.5) deliverables. When implementing this concept within GstarCAD 2027 Professional, GstarCAD Mechanical, or heterogeneous multi-CAD environments, engineering teams should adhere to the following standardized verification protocol:

  • Database Serialization & Binary Fidelity: Ensure all entities and symbol table records associated with ISO 19650 BIM Information Management are authored on standardized ISO 13567 layers rather than Layer 0 or Defpoints, and verify lossless round-trip persistence in native DWG (AC1032) format.
Implementation Stage GstarCAD / AutoCAD Execution Quality Assurance (QA/QC) Gate
1. Environment Setup Load corporate .dwt template; verify INSUNITS and LUNITS. Confirm 1:1 metric (mm) or imperial unit consistency across all linked Xrefs.
2. Geometry & Metadata Authoring Apply associative constraints, block attributes, or GD&T tolerance frames. Verify zero disassociated annotations via ANNOMONITOR = 2.
3. Deliverable Exchange Publish via Sheet Set Manager (SSM) or export to DWG / IFC / STEP. Inspect output in DWG FastView or FastView 3D before client release.
