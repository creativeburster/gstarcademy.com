Model Based Definition (MBD)

Drawingless Engineering: Using 3D models as the single source of truth for all Product and Manufacturing Information (PMI).

Beyond the 2D Sheet

Traditional 2D drawings are prone to interpretation errors. Model Based Definition (MBD) in Creo allows you to add all dimensions, tolerances (GD&T), and manufacturing notes directly onto the 3D model. This ensures that everyone from the designer to the machinist is looking at the exact same data, formatted for machine readability.

Key MBD Features

  • 3D Annotations: Place dimensions and notes on semantic planes within the 3D space.
  • Combination States: Create specific 3D views (e.g., 'Top View', 'Isometric Section') that show only relevant annotations for a specific step.
  • GD&T Advisor: A built-in expert system that checks your 3D tolerances for compliance with ASME and ISO standards.
  • STEP AP242 Export: Share your annotated 3D models with suppliers using neutral, machine-readable file formats.

Future-Proofing Data

MBD is the cornerstone of the 'Model-Based Enterprise' (MBE), reducing the time to manufacture by up to 50% by eliminating redundant drawing creation and manual data entry.
