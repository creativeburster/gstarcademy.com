Mapkeys & Macros

The Expert's shortcut: Automating complex UI workflows into single-key strokes for unparalleled speed.

Recording Actions

Creo's interface is powerful but often requires multiple clicks to find specific tools. Mapkeys allow you to record your actions—including menu selections, dialog box inputs, and screen picks—and save them as a short keyboard sequence (e.g., 'VD' for 'View Datums').

Mapkey Power Tips

  • Nested Mapkeys: You can create a mapkey that calls another mapkey, allowing for modular automation.
  • Pause for Input: Insert a 'Pause' into your mapkey to allow the user to select a face or enter a value manually during the macro.
  • OS Scripting: Mapkeys can call external OS commands, allowing you to trigger shell scripts or file operations from within Creo.
  • Icon Integration: You can assign your custom Mapkeys to buttons on the Ribbon or the Quick Access Toolbar.

The Config.pro Link

Mapkeys are stored within your config.pro file. Mastering Mapkeys is often what separates an average user from a high-performance Creo Power User.
