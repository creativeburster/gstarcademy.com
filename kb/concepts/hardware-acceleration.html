Performance Tech

Hardware Acceleration

Offloading vector calculation and rendering tasks to the Graphics Processing Unit (GPU) for seamless navigation.

The Core Problem

When working with massive site plans or complex 3D models, the CPU can become a bottleneck during real-time pan, zoom, and orbit operations. Hardware Acceleration allows the CAD engine to use dedicated GPU memory (VRAM) and shader cores to handle these display tasks.

Key Features in GstarCAD 2026

  • Optimized Shaders: Improved anti-aliasing for smoother lines without performance hits.
  • GPU Selection: Explicitly choose which graphics card (Discrete vs. Integrated) to use.
  • Large Memory Support: Efficiently swaps geometry data between RAM and VRAM for 1GB+ DWG files.

Command Reference

GRAPHICSCONFIG

Opens the Graphics Performance dialog. Recommended settings: Enable 'Hardware Acceleration', 'Smooth Line Display', and 'Advanced Graphic Effects'.
