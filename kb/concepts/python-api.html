Python API (PyRx)

Modernizing CAD automation with a robust Python interface integrated directly into the GRX engine.

The Evolution of API

While LISP remains popular for simple macros, the Python API in GstarCAD 2026 brings the power of modern data science and automation to CAD. The PyRx library provides an object-oriented wrapper over the GRXSDK (C++), allowing developers to build complex add-ins with fewer lines of code.

Key Technical Specs

  • 790+ Interfaces: Comprehensive coverage of drawing database and editor operations.
  • Native .py Loading: Use the PYLOAD command to run scripts without compilation.
  • Integration: Seamlessly call LISP functions from Python and vice-versa.
  • Python Manager: A built-in GUI for managing, editing, and running script libraries.

Sample Use Cases

Data Extraction

Export block attributes and geometry coordinates to Excel or SQL databases using Python's standard libraries.

AI Integration

Leverage Python's ML libraries (like TensorFlow or Scikit-learn) to analyze drawing patterns or automate layout generation.
