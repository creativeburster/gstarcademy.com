External References (Xrefs, GstarCAD)

DWG files referenced into another DWG drawing as live links — site plans referenced into building plans, structural drawings referenced into MEP plans.

By LearnCAD Editorial Team Reviewed by AEC Review Desk Last reviewed 2026-05-24 Editorial process

Definition

External references (xrefs) embed a DWG file as a referenced overlay or attachment into a host drawing. The xref content remains in its source file; the host displays the latest content on each open. Xrefs support relative or absolute paths, layer visibility overrides, clipping boundaries, and demand loading.

The Reference Manager and XREF palette manage the references — bind to convert xrefs into permanent blocks, detach to remove, reload to refresh.

Why it matters

Xrefs are the standard pattern for multi-discipline coordination in DWG-based workflows. Architecture xrefs into structural, structural xrefs into MEP, civil xrefs into all. Without xrefs, every coordination meeting requires manual file consolidation.

Common pitfalls

  • Absolute paths on a network share — moves break references.
  • Nested xrefs (xref inside an xref) — complicates reload behavior.
  • Binding xrefs prematurely — loses the live update relationship.
