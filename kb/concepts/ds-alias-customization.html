Alias Customization

Optimizing the keyboard interface: Mapping command shortcuts to match your personal drafting rhythm.

Muscle Memory Migration

Professional CAD users rely on keyboard shortcuts (Aliases) to execute commands without searching through ribbons or menus. Alias Customization in DraftSight allows you to define these shortcuts or import them from existing .pgp files used in other CAD software.

Key Features

  • Import PGP: Directly load acad.pgp files to keep your existing AutoCAD shortcuts active in DraftSight.
  • Command Search: Search through the entire command database to find the exact internal name for any tool.
  • Multiple Shortcuts: Assign multiple aliases to the same command (e.g., 'C' and 'CIR' both trigger the Circle command).
  • Profile Integration: Save your alias settings to a DraftSight Profile to easily transfer them between workstations.

One-Handed Drafting

Experienced drafters often customize their aliases to keep their most-used commands on the left side of the keyboard, allowing the right hand to remain exclusively on the mouse for continuous drafting.
