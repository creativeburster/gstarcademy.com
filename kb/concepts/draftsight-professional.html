2D Drafting

DraftSight Professional

Highly compatible and cost-effective 2D DWG drafting software.

Core Concepts

DraftSight Professional is Dassault Systemes' professional 2D drafting alternative. Supporting native DWG file handling, it offers AutoCAD users a familiar user interface, full command line compatibility, and advanced APIs for LISP/C++ automation.

Key Advantages & Applications

  • Native DWG Support: Seamlessly open, edit, and save DWG files without importing or format loss.
  • Familiar Interface: Traditional workspace options minimize employee retraining times.
  • Smart Block Conversion: Easily translate dynamic blocks and scripts into the DraftSight format.

Industry Best Practices

Set up your custom system paths for DWG template files. Back up your command aliases to ease user onboarding during transition cycles.
