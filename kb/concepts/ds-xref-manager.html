Xref Manager

Managing complex project hierarchies: Linking external DWG files to maintain a single source of truth across massive projects.

Dynamic Referencing

The Xref Manager in DraftSight allows you to attach external drawings to your current file without increasing its file size. When the external file is updated by another team member, DraftSight alerts you, ensuring you are always working with the latest design context.

Management Features

  • Attach/Overlay: Choose how files are linked to control whether references nest into other drawings.
  • Clipping: Define specific regions of an Xref to display, hiding unnecessary context.
  • Path Management: Easily switch between Absolute and Relative paths to ensure links don't break when moving folders.
  • In-Place Editing: Edit the referenced file directly from within your host drawing (Edit Reference).

Team Collaboration

Effective Xref management is the backbone of architectural and engineering teams, allowing civil, structural, and MEP engineers to coordinate their work in a shared 2D space.
