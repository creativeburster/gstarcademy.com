iLogic Automation

Enabling non-programmers to create complex, rule-based design automation within Autodesk Inventor.

Rules-Driven Design

iLogic is a technology that allows you to embed rules (if-then-else logic) directly into your parts, assemblies, and drawings. These rules can control parameters, feature suppression, component replacement, and even property updates based on user input or external data.

Key Capabilities

  • Parameter Linkage: Dynamically adjust dimensions based on logical conditions (e.g., 'If Length > 2000, add a center support').
  • Forms: Create custom User Interfaces (UIs) without coding to allow sales or junior engineers to configure products safely.
  • Component Replacement: Switch between different sub-assemblies or parts automatically.
  • iProperty Management: Standardize file metadata and drawing title blocks using rules.

Under the Hood

iLogic is based on VB.NET. While you can write simple rules using snippets, you also have full access to the Inventor API and .NET libraries for high-end customization.
