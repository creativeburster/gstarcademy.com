LISP & API Compatibility

Leveraging GstarCAD's industry-leading compatibility engine to run AutoCAD-native scripts and applications.

Zero-Cost Migration

For many firms, the cost of switching CAD software isn't the license—it's the custom scripts built over decades. GstarCAD supports Visual LISP (VLX/FAS), .NET, and C++ (GRX) with nearly 1:1 API mapping to AutoCAD, ensuring your automation tools work out of the box.

Compatibility Levels

  • LISP/VLISP: Full support for (vlax-...) and (vla-...) functions. Most .lsp files run without modification.
  • .NET SDK: Strong compatibility with AutoCAD's .NET API. GstarCAD provides a translation tool to update DLL references automatically.
  • GRX vs. ARX: GstarCAD's C++ SDK (GRX) is source-compatible with ARX, allowing high-end plugins to be recompiled for GstarCAD.
  • VBA: Support for legacy VBA scripts via an optional module.

Developer Tool: APPLOAD

Use the APPLOAD command to manage and automatically load your custom scripts upon startup, just as you would in AutoCAD.
