Conceptual Design

NX Layout

Planning for success: Using a 2D conceptual environment to drive the foundation of complex 3D assembly structures.

2D Thinking for 3D Success

Before committing to 3D modeling, engineers often need to iterate on 2D layouts to verify space constraints and kinematic paths. NX Layout provides a dedicated 2D environment where you can use 'Intelligent 2D Components' to build your product architecture. These components can represent real 3D parts and maintain a bidirectional link to them.

Core Layout Tools

  • 2D Components: Group geometry into reusable objects with their own metadata and behavior.
  • Assembly Hierarchy: Define the sub-assembly structure directly in the 2D layout.
  • 2D to 3D Sync: Automatically create 3D part placeholders from 2D components to begin the detail design phase.
  • Parametric Sketching: Use NX's powerful constraints to explore different mechanical configurations rapidly.

Streamlined Concepting

NX Layout bridges the gap between 'the back of a napkin' sketch and a formal CAD model, ensuring that early design decisions are captured and leveraged throughout the project.
