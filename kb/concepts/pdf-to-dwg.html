PDF to DWG Conversion

Recovering design data from PDF files: Converting vector information back into native CAD entities.

Vector vs. Raster

Not all PDFs are equal. A Vector PDF (created directly from CAD) contains geometric data that GstarCAD can perfectly reconstruct into lines, arcs, and layers. A Raster PDF (scanned paper) is just an image and will remain a non-editable underlay.

Conversion Settings

  • Layers: Create CAD layers based on the PDF layers or the colors of the entities.
  • Text Recognition: Convert PDF text objects into editable MText using SHX font recognition.
  • Solid Fills: Convert PDF fills into solid hatches in DWG.
  • Join Geometry: Automatically join adjacent lines and arcs into polylines during import.

The Command

PDFIMPORT

Select an existing PDF underlay to convert or browse for a new file to import directly into the drawing.
