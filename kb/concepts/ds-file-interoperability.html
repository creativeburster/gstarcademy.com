File Interoperability

Collaborating without borders: Ensuring 100% data integrity when exchanging files across the CAD ecosystem.

Universal DWG Support

DraftSight's primary file format is native DWG. It uses the Open Design Alliance (ODA) libraries to ensure that files saved in DraftSight are perfectly readable in AutoCAD, GstarCAD, and other DWG-based platforms, maintaining layers, blocks, and styles.

Supported Formats

  • DWG/DXF: Full read/write support from version R12 up to the latest 2018 format.
  • DGN: Import MicroStation V7 and V8 files as editable entities or underlays.
  • PDF: Export high-quality vector PDFs or import PDF files as vector geometry (Premium).
  • STL/OBJ: Export 3D models for 3D printing and external visualization software.

Clean Data Handover

DraftSight includes a 'Save As' feature that allows you to down-save to older DWG versions, ensuring that your contractors using legacy software can still open and work with your files.
