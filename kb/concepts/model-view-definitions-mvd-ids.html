Model View Definitions (MVD) & IDS Specification

Understand buildingSMART MVD (Model View Definition) and IDS (Information Delivery Specification) for automated BIM model validation and compliance.

By Gstarcademy Editorial Team Updated 2026-10-12 Editorial process

1. Definition & Engineering Significance

In openBIM collaboration, the entire IFC data schema contains thousands of classes and property sets—far more data than needed for any single project exchange. Model View Definitions (MVDs) define specialized subsets of the broader IFC schema tailored for specific exchange scenarios (such as Coordination View 2.0, Design Transfer View, or Reference View). To solve the historical complexity of MVD authoring, buildingSMART introduced the modern Information Delivery Specification (IDS)—a lightweight, human-readable XML/JSON standard that defines machine-interpretable data requirements for automated compliance checking.

2. Technical Architecture & Key Parameters

  • IFC Reference View vs Design Transfer View: Reference View freezes geometry for clash detection and coordination (tessellated/B-Rep); Design Transfer View supports parametric editing and element modification.
  • Information Delivery Specification (IDS): A machine-readable XML standard that specifies exactly which IFC classes must contain specific Property Sets, attributes, classifications, and data types.
  • Automated Quality Assurance (QA/QC): BIM validation tools (Solibri, BlenderBIM, SimpleBIM) parse the project IDS file and automatically audit thousands of model components in seconds.
  • Contractual Compliance Verification: Replaces ambiguous 100-page written PDF BIM Execution Plans with an executable digital contract that automatically passes or rejects consultant model submissions.

3. Industry Best Practices & Failure Modes

In large public hospital projects, general contractors frequently discover missing fire-rating or acoustic classifications on door models only after fabrication orders have been signed. Without automated schema validation, manual visual inspection of 5,000 door elements is impossible, leading to costly building code violations and re-work.

4. Production Governance & Standard Protocols

Implementing an automated IDS validation pipeline guarantees that all exported IFC models conform strictly to owner asset requirements before milestone sign-off, dramatically elevating design coordination quality.
