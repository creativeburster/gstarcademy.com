Data Link (Excel Integration)

Connecting the spreadsheet and the drawing: Maintaining live, synchronized data between Excel and CAD tables.

Beyond OLE

While OLE (Object Linking and Embedding) inserts a static-like image of a table, Data Link creates a true connection. The Excel data is rendered using native CAD Table entities, allowing for perfect plotting, text styling, and automated updates when the source spreadsheet changes.

Core Capabilities

  • Bi-directional Sync: Update the Excel file from CAD, or update the CAD table from Excel.
  • Range Mapping: Link an entire sheet or just a specific range of cells (e.g., A1:D20).
  • Formatting Control: Choose whether to use Excel's formatting or enforce CAD-native table styles.
  • Security: Lock cells in the CAD table to prevent accidental overwriting of linked data.

Status Bar Notification

When the source Excel file is saved, GstarCAD displays a notification in the status bar. Simply click 'Update Tables' to pull the latest data into your drawing immediately.
