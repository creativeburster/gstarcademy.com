Action Recorder

Capturing and replaying your drafting workflows without writing a single line of LISP or C++ code.

The Macro Approach

The Action Recorder (ACTRECORD) acts like a digital 'tape recorder' for your CAD commands. Once you start recording, every command, input, and coordinate is saved into an .atmx file. You can then 'Play' this macro on any drawing to repeat the same steps instantly.

Key Features

  • User Prompts: Insert 'Pause for User Input' to allow variable data (like custom text or a specific point) during playback.
  • Base Point Management: Define relative or absolute coordinates to ensure macros work across different project files.
  • Action Macros Palette: A dedicated manager for organizing, editing, and sharing your library of automation tools.
  • Low-Code entry: Perfect for drafters who want to automate but aren't ready for LISP scripting.

System Variable Connection

Macros can also record changes to system variables, making them ideal for setting up 'Standard Drafting Environments' (e.g., setting OSNAP, ORTHOMODE, and PICKBOX in one click).
