External References (Xref)

Linking external DWG files into a current drawing to enable multi-user collaboration and modular project management.

Core Definition

Unlike Blocks, which are stored inside the drawing, an Xref is a separate file that is "referenced" or "attached" to the host drawing. When the source file is modified, the changes are reflected in the host drawing upon reloading.

Why Use Xrefs?

  • Collaboration: Multiple designers can work on different parts of a building simultaneously.
  • Modularity: Keep the host file lightweight by only loading necessary references.
  • Single Source of Truth: Changes to a base plan update all sheets (plans, elevations, sections) linked to it.
