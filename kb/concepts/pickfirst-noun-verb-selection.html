PICKFIRST System Variable & Noun/Verb Selection

Technical guide to PICKFIRST system variable in AutoCAD and GstarCAD. Fix pre-selection issues where objects deselect when invoking commands.

By Gstarcademy Editorial Team Updated 2026-10-12 Editorial process

1. Definition & Engineering Significance

The PICKFIRST system variable governs whether objects can be selected before entering a modification command (Noun/Verb selection) or whether the user is strictly forced to issue the command first and then select objects (Verb/Noun selection). When PICKFIRST is active (value 1), drafters enjoy modern graphical editing ergonomics: selecting an entity activates its grips, and pressing the Delete key, Move, or Copy operates immediately on that pre-selected entity set.

2. Technical Architecture & Key Parameters

  • Value = 1 (Noun/Verb Enabled): Allows selecting objects before issuing commands. Displays grips, enables direct 'Delete' key operations, and populates the Properties Palette instantly upon click.
  • Value = 0 (Verb/Noun Only): Disables object pre-selection. If geometry is highlighted and a command (e.g., MOVE, ERASE) is invoked, the selection is cleared and the prompt 'Select objects:' appears. The Delete key stops functioning.
  • Root Causes of Setting 0: Incomplete third-party plugin routines, crashed LISP selection reactors, or corrupted CAD registry profiles frequently flip PICKFIRST to 0.

3. Industry Best Practices & Failure Modes

When PICKFIRST=0 occurs, drafters commonly assume their keyboard Delete key is broken or their mouse drivers have failed. In reality, the DWG graphic engine simply refuses to pass pre-selected object IDs into command buffers. Furthermore, right-click contextual menus lose their entity-specific tools, and double-clicking text or blocks fails to trigger the in-place text editor or block editor.

4. Production Governance & Standard Protocols

Restoring normal operation takes seconds: type PICKFIRST and enter 1. In GstarCAD and AutoCAD Options, this toggle is also accessible under the 'Selection' tab as 'Noun/Verb selection'. CAD system administrators should include (setvar "PICKFIRST" 1) in their corporate startup files to safeguard against rogue plug-ins resetting user preferences.
