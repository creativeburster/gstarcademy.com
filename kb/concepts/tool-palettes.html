Tool Palettes

The ultimate productivity dashboard: Consolidating your most frequently used content into a single, accessible sidebar.

One-Click Drafting

Searching through folders for blocks or manually setting layers for hatches is a time-sink. Tool Palettes store blocks, hatches, and even complex command macros with predefined properties. Dragging a block from the palette automatically places it on the correct layer with the correct scale.

Standardizing Content

  • Block Management: Right-click a block in the palette to set its default rotation, scale, and layer.
  • Hatch Palettes: Pre-set the angle, scale, and transparency for architectural hatches.
  • Command Macros: Create a single tool that draws a polyline on the 'A-WALL' layer and starts the 'OFFSET' command automatically.
  • Palette Groups: Organize multiple palettes into groups (e.g., 'Civil Tools', 'Electrical Tools') to avoid clutter.

Enterprise Deployment

Palettes can be hosted on a network server. By setting the Tool Palette File Locations in the Options dialog to a shared path, CAD managers can push standardized tools to all users instantly.
