ATTREQ & ATTDIA Block Attribute Prompt Controls

Master ATTREQ and ATTDIA system variables to control automatic attribute prompting and dialog boxes during CAD block insertion.

By GstarCAD Academy Engineering Editorial Board (Suzhou Gstarsoft Co., Ltd.) Reviewed by GstarCAD Academy Editorial Team Last reviewed 2026-10-12 Editorial Process & Testbed

1. Definition & Engineering Significance

In DWG drafting workflows, blocks with embedded attributes (such as architectural door tags, electrical instrument bubbles, and mechanical title blocks) rely on the dual system variables ATTREQ and ATTDIA. Together, these two controls govern whether the CAD software actively requests attribute values upon block insertion and whether that data entry happens inside a convenient multi-field graphical dialog box or as serial text prompts in the command history.

2. Technical Architecture & Key Parameters

  • ATTREQ = 1 (Prompts Active): Enables attribute prompting. When inserting a title block or tag, the user is required to supply attribute strings according to block definition defaults.
  • ATTREQ = 0 (Prompts Suppressed): Suppresses all attribute prompts. Blocks are instantly placed with their predefined default attribute values, which is essential for rapid repetitive component placement.
  • ATTDIA = 1 (Dialog Box Mode): Directs attribute entry into the Edit Attributes graphical dialog box, allowing engineers to view all tags, prompts, and default values simultaneously.
  • ATTDIA = 0 (Command-Line Mode): Forces attribute input into sequential command-line text prompts, commonly utilized in automated LISP insertion scripts.

3. Industry Best Practices & Failure Modes

A frequent support ticket among engineering teams involves title blocks inserting without displaying editable project information. When ATTREQ is inadvertently set to 0 by an imported third-party macro, inserting a multi-attribute border block places the geometry immediately, leaving attribute tags blank or populated with raw placeholder text like 'XXX-001'. The drafter must then manually invoke EATTEDIT or double-click each inserted block to input sheet numbers and drawing titles.

4. Production Governance & Standard Protocols

For optimized productivity, standard CAD workstations should configure ATTREQ=1 and ATTDIA=1. This combination ensures that the moment a block is anchored, an ergonomic pop-up window lists every tag in logical order, complete with validation limits and multiline text capabilities. For mass automated stamping scripts, temporary toggling to ATTREQ=0 streamlines bulk insertions without UI blocking.
