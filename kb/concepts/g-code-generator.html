G-Code Generator

Bridging CAD and CNC: Directly converting 2D designs into industry-standard numerical control instructions.

From Lines to Paths

DraftSight Premium and Enterprise include a built-in G-Code Generator. This tool eliminates the need for separate CAM software for simple 2D cutting profiles. It converts DWG geometry into .nc or .gcode files that CNC machines can read.

Key Features

  • Geometry Selection: Select specific layers or entities to include in the toolpath.
  • Post-Processor Support: Tailor the G-Code output to specific machine controllers (Fanuc, Siemens, Haas).
  • Lead-In / Lead-Out: Automatically generate start and end paths for the cutting head to prevent damage to the final part.
  • Simulation: Preview the toolpath movement within the DraftSight interface before exporting.

Optimized for 2D Fabrication

This tool is ideal for laser, plasma, and waterjet cutting workflows where the Z-depth is constant and the primary focus is on 2D profile accuracy.
