Presentations (.ipn, Inventor)

Animated exploded-view files derived from an assembly — used for assembly instructions and animations.

By Gstarcademy Editorial Team Reviewed by Mechanical Review Desk Last reviewed 2026-05-24 Editorial process

Definition

An IPN file references an IAM and adds tweaks (offsets, rotations) to components, creating an exploded view. Snapshots define key positions over time; an exploded-view animation interpolates between snapshots. Output: animations (AVI, MP4), exploded-view drawings, and lightweight web-viewable presentations.

Why it matters

Assembly instructions need exploded views; service manuals need them animated. Presentations produce both from one file linked to the assembly.

Common pitfalls

  • Static tweak values — when the assembly changes, tweaks no longer align.
  • Long animations with many snapshots — file becomes unwieldy.
  • Forgetting to link to current assembly version — IPN shows old geometry.
