Sheet Set Manager (SSM)

The central command for organizing multiple drawings and layouts into a single, cohesive project hierarchy.

Managing Complexity

When a project scales to hundreds of DWG files, opening them individually to plot or update title blocks becomes impossible. Sheet Set Manager creates a .dst file that acts as a database, allowing you to manage all layouts without opening the source files.

Key Features in GstarCAD

  • Batch Plotting: Plot the entire project to PDF or physical printer with one click.
  • Automatic Callouts: Cross-reference view labels automatically; if a sheet number changes, all callouts update.
  • Global Fields: Update 'Project Number' or 'Client Name' in the SSM database to update all title blocks globally.
  • Archive & E-Transmit: Bundle the entire project (Xrefs, Fonts, Plot Styles) for sharing in seconds.

Command Shortcut

SSM

Opens the Sheet Set Manager palette. Drag-and-drop existing layouts directly from your file explorer into the palette to begin organizing.
