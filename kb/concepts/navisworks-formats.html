Navisworks Formats

Understanding the trifecta of Navisworks file types: The key to managing complex multidisciplinary coordination models.

NWC, NWF, and NWD Explained

Navisworks doesn't edit geometry; it aggregates it. To do this efficiently, it uses three distinct file formats that serve different purposes in the coordination lifecycle.

The Three Formats

  • NWC (Cache File): A lightweight 'snapshot' of a native file (like Revit or DWG). It contains geometry and metadata but no coordination data.
  • NWF (Federated File): The 'Live' coordination file. It contains NO geometry; instead, it contains links to NWC files plus all your clashes, redlines, and viewpoints.
  • NWD (Document File): A compiled, 'frozen' version of the entire project. It embeds all geometry and coordination data into a single file for sharing with clients or subcontractors.

Workflow Strategy

Always work in the NWF. This ensures that when the native Revit or CAD files are updated, you only need to refresh the NWC links to see the latest changes in your coordination model.
