Batch Print & Plotting

High-volume documentation: Automating the publishing process for massive architectural and engineering drawing sets.

Efficiency at Scale

Printing 100 drawings one-by-one is an invitation for error and a waste of time. Batch Print in DraftSight allows you to queue up multiple files, specify layout rules, and run the entire plotting job in the background while you continue working.

Automation Workflow

  • File Selection: Add individual DWGs or entire folder hierarchies to the print job.
  • Layout Mapping: Choose whether to print only specific Sheets or everything in Model space.
  • Configuration (PC3): Apply standardized plotter configurations (PDF, Physical Printer, DWF) globally to all files.
  • Job Reports: Receive a detailed log once the job is complete, highlighting any files that encountered errors.

Professional Packaging

Combined with the Sheet Set Manager, Batch Print becomes a powerhouse for creating indexed, multi-page PDF sets that are ready for contractor bidding and construction site usage.
