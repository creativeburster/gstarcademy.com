Dynamic Input

The 'Heads-Up' drafting interface: Bringing command line tools and dimension input directly to your cursor.

Eyes on the Screen

Before Dynamic Input, drafters had to constantly look down at the command line. Dynamic Input provides a floating tooltip near the crosshairs that displays coordinate values, command options, and prompts in real-time.

Key Behaviors

  • Pointer Input: Enter coordinates relative to your last point or as absolute values directly at the cursor.
  • Dimensional Input: Enter length and angle values as you draw lines or arcs without typing '@' symbols.
  • Dynamic Prompts: Use the DOWN arrow key to see and select command sub-options (e.g., Arc, Close, Width) from a floating menu.
  • DYNMODE: The system variable that controls the behavior and visibility of Dynamic Input.

Performance Tip

In extremely dense drawings, the real-time calculation of dynamic tooltips can cause slight cursor lag. Toggle it off instantly using the F12 key if you need maximum graphics performance during large move/copy operations.
