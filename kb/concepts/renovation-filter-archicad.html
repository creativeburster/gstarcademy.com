Renovation Filter

ArchiCAD's renovation workflow for managing existing, demolished, and new elements in refurbishment projects.

By Gstarcademy Editorial Team Updated 2026-07-28 Editorial process

Definition & Context

ARCHICAD's Renovation feature manages refurbishment projects by tagging every element with a renovation status — Existing, To Be Demolished, or New — and using Renovation Filters to display the model in Existing, Demolition, or Planned states from one model. Filters control visibility and graphic overrides per status.

This lets a single BIM model generate existing, demolition, and proposed drawings without maintaining separate files.

Why It Matters

Renovation filters let one model produce coordinated existing/demolition/new drawing sets — exactly what refurbishment documentation needs — and avoid the errors of parallel model copies.

Consistent status tagging is what makes those views and demolition scopes reliable.

Best Practices

  • Tag every element's renovation status as you model
  • Use Renovation Filters (not manual hide) to produce existing/demolition/new views
  • Set graphic overrides per status for clear demolition drawings
  • Recheck status on reused elements when phasing changes

Common Pitfalls

  • Untagged or mis-tagged elements appearing in the wrong phase
  • Manually hiding elements instead of using filters, breaking coordination
  • Inconsistent status leading to wrong demolition scope
