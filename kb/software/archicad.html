Archicad

BIM authoring (architectural-first)

GRAPHISOFT · status: draft

Architectural BIM modeling and documentation with strong publishing workflows.

Overview

Archicad is common in architectural practices that want model-based documentation and coordination. OpenBIM/IFC usage depends on project standards and exchange agreements.

Typical outputs & exchange

  • PLN
  • IFC (context-dependent)
  • PDF

Where it commonly shows up
