Revit

The Preeminent AEC Building Information Modeling (BIM) Platform

Autodesk · status: enriched

Revit is Autodesk's flagship authoring software for Building Information Modeling (BIM). Unlike CAD software that relies on 2D linework, Revit builds a unified, 3D relational database of a building. This single source of truth means that a change made in a 3D view is instantly and bidirectionally updated across all floor plans, elevations, sections, and schedules. It is the dominant architectural and engineering tool for large-scale commercial and infrastructure projects globally.

Core BIM Paradigms

  • Bidirectional Associativity: The fundamental engine of Revit. Everything is a view of the same database. If you delete a window in an elevation view, it disappears from the floor plan and the window schedule simultaneously.
  • Worksharing & Cloud Collaboration: Enterprise teams work concurrently via Worksharing. Users sync local copies of the model to a Central Model (often hosted on Autodesk Construction Cloud/BIM 360), borrowing elements and worksets to avoid conflicts.
  • Project Phasing & Design Options: Built-in timelines allow architects to model "Existing", "Demolition", and "New Construction" in the same file, while Design Options allow teams to present multiple layouts (e.g., Option A vs Option B) without duplicating the file.
  • Data-Driven Schedules: The "I" (Information) in BIM. Revit schedules are not dumb spreadsheets; they are live views of the model data. Changing a door's fire rating in the schedule updates the physical 3D door's metadata instantly.

Revit Family Hierarchy

In Revit, every element is a "Family". Understanding the hierarchy is crucial for modeling discipline:

  • System Families: Built-in elements that assemble continuously on site (Walls, Floors, Roofs, Ceilings). You cannot save these as separate .rfa files; they live strictly within the project.
  • Loadable Families: Standalone components that are purchased and delivered to the site (Doors, Windows, Furniture, MEP Equipment). These are created in the Family Editor and loaded into projects as .rfa files.
  • In-Place Families: Custom, one-off geometry modeled directly in the project context (e.g., a highly specific reception desk). Highly discouraged for repetitive elements due to file performance impacts.

Multi-Discipline Coordination

Revit acts as the central hub for the three major AEC disciplines, allowing intense clash detection and coordination:

  • Revit Architecture: Focused on space planning, envelope design, and life-safety compliance.
  • Revit Structure: Used for analytical modeling of steel and concrete framing, rebars, and foundation loads.
  • Revit MEP: Mechanical, Electrical, and Plumbing engineering. Evaluates pressure drops, duct routing, electrical panel schedules, and HVAC spatial coordination.
