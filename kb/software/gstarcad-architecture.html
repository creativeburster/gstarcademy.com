Architectural drawing environment with wall/door/window style objects and project-oriented layer conventions.

What it is & Core Architecture

GstarCAD Architecture is an object-oriented, parametric CAD solution purpose-built for architectural design, construction documentation, and building renovation workflows. Rather than drafting walls and doors with disconnected 2D lines, architects work with intelligent, parametric AEC objects—multi-layer walls, associative doors and windows, parametric stairs, roofs, slabs, and structural grids—directly inside native .dwg files.

When a drafter inserts or moves a window inside a GstarCAD Architecture wall, the multi-cavity wall heals automatically in both 2D plan view and 3D model view, and the associated Door & Window Schedule updates dynamically. From a single set of floor plan drawings, the software automatically generates full building 3D models, exterior elevations, cross-sections, and room area calculation tables.

Where it is used in Industry

Adopted by architectural design institutes, residential and commercial EPC contractors, interior fit-out firms, and municipal housing authorities that require fast construction drawing production without the massive hardware overhead and steep learning curve of heavy BIM platforms.

Learning curve and getting started

Any AutoCAD drafter can become productive in GstarCAD Architecture within 3 to 5 days. Because the workspace retains full DWG command compatibility alongside a dedicated tool palette of parametric architectural components, teams can adopt 3D parametric walls and automated schedules incrementally without disrupting active project deadlines.

Commercial Licensing & TCO Reality

Offered as a permanent perpetual license (Standalone or Floating Network). Compared to annual AEC Collection subscriptions, GstarCAD Architecture saves architectural studios over $7,500 per seat over a 5-year lifecycle while maintaining 100% DWG deliverable compatibility with structural and MEP consultants.

Ecosystem, Standards & Interoperability

Features full custom AEC object display representations (2D Plan vs. 3D Isometric view switching), automated 3-tier exterior wall dimensioning, intelligent room tagging with net/gross floor area compliance calculation, custom curtain wall grids, and seamless export to IFC and DWG FastView for construction site inspection.

Common Engineering Pitfalls & Best Practices

Sharing drawings with plain CAD users: When sending GstarCAD Architecture drawings to contractors using basic 2D CAD, set PROXYGRAPHICS = 1 or run the built-in Export to 2D DWG utility so custom wall/window objects render accurately on third-party systems.

Frequently asked questions (3)

How do I create custom wall styles?

Open the Style Manager, select Wall Styles, click New, define wall layers (material, thickness, offset), and save the style to your templates.

Can I generate 3D models from 2D architectural plans?

Yes. Wall, door, and window elements in GstarCAD Architecture are intelligent 3D elements that automatically render in 3D when switching the viewpoint.

How do I export architectural models to IFC?

Use the IFCEXPORT command, map GstarCAD Architecture layers to standard IFC classes, and save the coordinates relative to the project base point.
