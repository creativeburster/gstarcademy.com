What it is & Core Architecture

Houseplan is Gstarsoft's lightweight, real-time 3D architectural conceptual modeling, terrain landscaping, and GPU photorealistic rendering software. It allows architects, urban planners, and interior designers to import 2D DWG floor plans, extrude 3D buildings in minutes, populate scenes with thousands of PBR vegetation/furniture assets, and produce cinematic 4K walkthrough animations and VR panoramas in real time.

Where it is used in Industry

Used by architectural visualization studios, urban planning bureaus, landscape designers, and interior renovation contractors for rapid client pitch presentations.

Learning curve and getting started

Extremely fast—designers can go from a 2D DWG plan to a rendered 3D daytime/nighttime architectural animation within a single afternoon.

Commercial Licensing & TCO Reality

Delivers integrated 3D modeling + real-time PBR rendering in a single lightweight package (< 1 GB installer), replacing costly combinations of SketchUp + Lumion/Enscape subscriptions.

Ecosystem, Standards & Interoperability

Directly imports .dwg, .dxf, .skp, .fbx, and .obj files; includes built-in UV material editors, dynamic weather/sunlight simulation, animated vehicles/pedestrians, and one-click video/panorama export.

Common Engineering Pitfalls & Best Practices

Clean up stray far-origin entities and unused layers in your 2D DWG base file before importing into Houseplan to ensure optimal GPU viewport frame rates.

Frequently asked questions (3)

How do I export Houseplan files to GstarCAD?

Use the Export command and select DWG format. Intelligent walls and massing elements will convert to standard 2D/3D entities.

Can I import custom material texture files?

Yes, in the Material panel, add a new material and browse to import PNG/JPG files for diffuse and normal mappings.

How to create visual animations of the 3D model in Houseplan?

Set up multiple camera viewpoints along a path, and click Export Video in the presentation panel to render a walk-through.
