GstarCAD

2D/3D DWG-native CAD (desktop)

Gstarsoft · status: draft

Cross-platform CAD platform that emphasizes DWG compatibility and familiar AutoCAD-style workflows.

Overview

GstarCAD 2026 is a major performance-focused release. Built on a completely reconstructed interface, it delivers significant speed improvements: drawing opening speed is up by 40%, and common operations like MOVE, UNDO, and REDO are 20% faster. For complex workflows, features like Hatch (pick-point) are up to 30x faster than previous versions.

Key 2026 Features

  • Parametric Constraints (Phase 2): Introduces dimensional constraints and the Parameters Manager for formula-driven geometric control.
  • DWG Compare: Visual diffing between drawing versions with optimized Xref support.
  • Drawing Merge: Consolidate multiple DWGs into a single master file while preserving structure.
  • Engineering Projection: Precise bottom-view accuracy for complex mechanical and structural layouts.
  • Enhanced BIM Interop: Improved IFC import/export and ARCHLine.XP plugin integration.
