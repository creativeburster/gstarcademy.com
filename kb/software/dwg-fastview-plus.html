Product Overview

DWG FastView Plus is the premium edition of Gstarsoft's DWG viewer, adding editing capabilities beyond the free viewer's read-only functionality. It allows users to make simple modifications to DWG files — editing text, adjusting dimensions, adding annotations, and modifying basic geometry — without needing a full CAD application.

DWG FastView Plus targets professionals who occasionally need to make minor drawing corrections or additions but don't justify a full CAD license. It maintains compatibility with all DWG versions and supports the same multi-platform deployment as the free edition.

Key Features

  • Light editing: Edit text, modify dimensions, adjust properties, and add simple geometry to existing DWG files.
  • Batch operations: Batch print, batch format conversion (DWG to PDF), and batch property editing across multiple files.
  • Drawing comparison: Visual diff comparison between drawing versions, highlighting added, removed, and modified elements.

Frequently asked questions (3)

What are the advantages of FastView Plus over standard FastView?

FastView Plus is a high-performance Windows desktop application designed to handle extremely large DWG assemblies and run batch plotting and audit diagnostics.

How do I configure batch printing with specific plot styles?

Open the Batch Plot utility, select multiple drawings, load your enterprise .ctb file, select target printer/PDF generator, and run.

Can I merge markups from different team members in FastView Plus?

Yes. FastView Plus can load multiple markup layers on top of a single base drawing, allowing you to merge annotations into a master revision list.

As the technical reference notes, DWG FastView Plus (developed by Gstarsoft) operates as: 'Desktop viewer positioned as an alternative light client for plotting and reviewing DWGs on Windows.' Understanding its native feature limits and platform alignment is crucial for model health.

Competitive Positioning

DWG FastView Plus is the premium tier of DWG FastView, adding editing capabilities to compete with AutoCAD LT, DraftSight Standard, and ARES Commander in the lightweight CAD editing market.

vs. AutoCAD LT: DWG FastView Plus provides essential DWG editing (draw, modify, dimension, annotate) at a significantly lower price point. For users who need basic drafting without 3D or advanced customization, it covers 80% of daily tasks at a fraction of AutoCAD LT's subscription cost.

vs. DWG FastView (free): The Plus version adds drawing creation, entity modification, block insertion, and layer management—transforming the viewer into a production drafting tool suitable for markup corrections, redline implementation, and simple drawing creation.

Cross-platform editing: Available on Windows, macOS, iOS, and Android with cloud sync, enabling continuous editing workflows across office desktop and field tablet without file transfer management.

Use Cases & Industry Applications

  • Field markup implementation: Technicians implement redline corrections directly on-site, modifying dimensions, adding notes, and adjusting geometry without returning to the office CAD station.
  • Quick drawing edits: Project managers make minor drawing corrections (text edits, dimension updates, cloud markups) without launching full CAD applications or occupying primary CAD workstation licenses.
  • Mobile drafting: Surveyors and inspectors create simple field sketches and as-built markup drawings on tablets, capturing site conditions in DWG format for direct import into office workflows.
  • License overflow: When primary CAD licenses are fully allocated, DWG FastView Plus provides basic editing capability for urgent tasks without waiting for license availability.
  • Remote team collaboration: Distributed team members edit shared drawings via cloud storage, with each user working from their preferred device (phone, tablet, laptop) using the same DWG file.
