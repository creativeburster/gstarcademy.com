Frequently asked questions (15)

How do I convert an existing DWG to a BricsCAD BIM model?

Open the DWG in BricsCAD, run the BIM2DWG command, map existing layers to BIM categories, and use the BIM Import wizard to generate walls, floors, and structural elements automatically.

Can I use AutoLISP scripts written for AutoCAD in BricsCAD?

Yes. BricsCAD ships a compatible LISP interpreter; most standard AutoLISP functions work out‑of‑the‑box. Minor API differences (e.g., custom object handling) may require small adjustments.

What is the best workflow for creating sheet‑metal parts?

Start with a 3D solid, apply the SheetMetal command to define thickness, bend radius, and K‑factor, then use Flatten to generate the 2D flat pattern for fabrication.

How do I manage version control for large DWG assemblies?

Enable Bricsys 24/7 cloud storage, check files in/out using the built‑in version manager, and tag releases with meaningful comments. For offline work, integrate with Git‑LFS for binary handling and keep a changelog.

Is there a way to automate dimensioning for repetitive features?

Create a Dynamic Block with parameters for length/angle, then use the Block Attribute Manager to set dimension styles that update automatically when the block is edited.

How can I link external spreadsheets to BIM object attributes?

Use the BIM Data Link tool, select the spreadsheet, map columns to BIM fields (e.g., room number, fire rating), and enable live sync so updates propagate to the drawing instantly.

What are the recommended hardware specs for smooth 3D modeling?

A quad‑core CPU (Intel i7 or AMD Ryzen 7), 16 GB RAM minimum, a GPU with OpenGL 4.5 support (NVIDIA GTX 1660 or higher), and SSD storage for project files.

Can I export BricsCAD models to IFC for BIM collaboration?

Yes. Use the Export IFC command, choose the appropriate IFC schema (IFC2x3 or IFC4), and configure mapping options for walls, doors, and structural elements before exporting.

How do I create a material library for rendering?

Open the Material Editor, click New, define base color, roughness, metallic values, and optionally assign texture maps. Save the library file and reference it in the rendering settings panel.

What is the process for cleaning up a drawing before sending to a client?

Run Purge to remove unused layers and blocks, Audith to fix geometry errors, and Export to a clean DWG version with the +audit flag to ensure compliance with industry standards.

How can I set up custom keyboard shortcuts for frequent commands?

Open Options → User Preferences → Keyboard, click Customize, assign your desired key combos to commands, and export the shortcut file for team sharing.

Is there a built‑in clash detection tool?

BricsCAD includes a lightweight clash detection module under the BIM tab. Select two BIM layers, run Clash Detect, and review the generated report highlighting intersecting objects.

How do I generate a BOM from an assembly?

Select the assembly, run BOM Generate, configure attribute fields (part number, quantity, material), and export to CSV or Excel for downstream manufacturing processes.

Can I use Python for automation?

Yes. BricsCAD provides a Python interpreter (bricscadpy). Install the bricscadpy package, write scripts using the pybricscad API, and run them from the command line or script manager.

What licensing options are available for corporate teams?

BricsCAD offers network licenses, floating seats, and subscription plans with volume discounts. Contact sales for a customized quote based on user count and feature set.
