BricsCAD

A high-performance DWG-native alternative offering powerful 2D drafting, 3D modeling, and BIM in one package.

By Gstarcademy Editorial Team Reviewed by Mechanical Review Desk Last reviewed 2026-05-28 Editorial process

What it is

BricsCAD is a DWG-native 2D/3D CAD platform developed by Bricsys (acquired by Hexagon). It is famous for offering AutoCAD command compatibility while operating on a unified codebase that scales from basic 2D drafting to complete BIM authoring and mechanical assembly modeling.

Where it is used

Widely used across Europe and Asia by AEC offices, surveyors, industrial designers, and enterprise teams seeking an alternative to subscription-only CAD systems without losing LISP routine compatibility.

Learning curve and getting started

Extremely gentle for AutoCAD veterans as command names, aliases, and visual workflows match closely. The unified 3D/BIM workflow has a moderate learning curve but is highly intuitive compared to separate platform environments.

Licensing reality

Offers perpetual licenses (maintenance contracts optional) alongside subscription packages, making it popular for enterprises seeking capex-based asset ownership.

Ecosystem and extensions

Highly compatible with existing AutoCAD customization. The LISP engine is highly optimized, supporting VL, VLA, and VLX routines directly. Pro edition includes direct modeling and assembly constraints.

Common pitfalls and misconceptions

Mixing BIM and plain 2D objects without defining correct classifications. Forgetting to verify custom LISP compatibility on non-Windows platforms. Overlooking template setups when importing complex styles.

When to use vs. alternatives

Use when you want absolute DWG compatibility, optimized LISP performance, and perpetual license choices without subscription locked-in trees.

Recommended learning path

  1. Week 1 — Drafting. Familiarize with layout, commands, command aliases, and sheet sets.
  2. Week 2 — 3D Core. Explore direct modeling, quad cursor, and geometric constraints.
  3. Week 3 — BIM / MCAD. Test BIM conceptual modeling, mechanical sheet metal work, and parametric parts.
  4. Week 4 — Customization. Configure LISP routines, CUI settings, and custom tool palettes.

Frequently asked questions (15)

Is BricsCAD fully compatible with AutoCAD DWG files?

Yes, BricsCAD is fully DWG-native. It reads and writes standard DWG files directly, preserving all layout sheets, layers, blocks, and dimensions without conversion or data loss.

What is the difference between BricsCAD Lite and Pro?

BricsCAD Lite is strictly for 2D drafting and running LISP routines. BricsCAD Pro adds 3D modeling, assembly design, civil engineering tools, third-party apps support, and is the prerequisite for BIM and Mechanical vertical add-ons.

Can I run my AutoCAD LISP routines in BricsCAD?

Yes, BricsCAD has a highly optimized, extremely compatible LISP engine. Most standard LISP routines (.lsp, .fas, .vlx) run directly in BricsCAD without any modifications.

Does BricsCAD offer perpetual licenses?

Yes, BricsCAD stands out by continuing to offer perpetual (buy-once, own-forever) licenses alongside annual subscription packages for all its editions.

What is BricsCAD Ultimate?

BricsCAD Ultimate is a comprehensive package that bundle all BricsCAD features (Lite, Pro, BIM, Mechanical) into a single master installation, perfect for multi-disciplinary design teams.

Does BricsCAD run on Mac and Linux?

Yes, BricsCAD is built on a cross-platform codebase, offering identical core CAD features across Windows, macOS, and supported Linux distributions (Ubuntu, Red Hat).

What is the Quad cursor in BricsCAD?

The Quad is BricsCAD's context-sensitive heads-up menu that appears at the cursor location. It analyzes your current task and hover target to recommend the most relevant editing commands instantly.

How does BricsCAD BIM compare to Revit?

Unlike Revit's proprietary data structure, BricsCAD BIM is entirely DWG-native. It utilizes standard DWG solids classified with open IFC tags, enabling flexible modeling before forcing BIM classification structures.

What is the Blockify command?

Blockify is BricsCAD's AI tool that automatically scans a drawing for repeating groups of identical geometry and instantly replaces them with a single consolidated block reference, shrinking file sizes.

Can BricsCAD open SketchUp models?

Yes, BricsCAD Pro and above can import SketchUp (.skp) files directly, converting them into native CAD solids that can be edited, scaled, and classified with BIM data.

What is the Quad command hover delay?

You can customize the Quad's hover latency and size in the Settings dialog to ensure it only appears when you pause your cursor, avoiding unwanted visual clutter during fast drafting.

How do I license BricsCAD in an enterprise network?

BricsCAD offers Network License packages managed by a local network licensing server, allowing multiple designers to share a floating pool of seats across the organization.

What is the command to convert AutoCAD dynamic blocks?

Use the CONVERTDYNAMICBLOCKS command to automatically translate legacy AutoCAD dynamic blocks into BricsCAD's native, open parametric block format.

Can BricsCAD export to STEP and IGES?

Yes, BricsCAD Pro and above support exporting 3D solid geometries directly to standard neutral formats like STEP, IGES, and Parasolid for manufacturing.

What is BricsCAD's performance on Apple Silicon Macs?

BricsCAD is compiled natively for Apple Silicon, offering high-performance navigation, rapid drawing loads, and optimized memory usage on modern Mac workstations.
