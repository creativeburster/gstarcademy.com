AutoCAD

The Universal Standard for 2D Drafting & 3D Detailing

Autodesk · status: enriched

AutoCAD is the world's most ubiquitous computer-aided design software. Launched in 1982, it democratized digital drafting and established the .DWG format as the de facto industry standard for geometric data exchange. While often associated with 2D floor plans and mechanical layouts, AutoCAD features a robust 3D surface and solid modeling engine, and serves as the foundation for numerous discipline-specific "vertical" toolsets.

Core Drafting Paradigms

  • Command-Line Interface (CLI): AutoCAD's enduring power lies in its command prompt. Power users navigate entirely via keyboard aliases (e.g., L for Line, TR for Trim, O for Offset), bypassing ribbons for extreme efficiency.
  • Model Space vs. Paper Space: Geometry is drafted at a 1:1 true scale in an infinite Model Space. Layouts for plotting (with title blocks and scaled viewports) are arranged in Paper Space, ensuring drawing integrity regardless of final print size.
  • Coordinate Systems: Relies on the World Coordinate System (WCS) for global truth, while users actively manipulate the User Coordinate System (UCS) to draft on angled planes or 3D faces.
  • Annotative Scaling: A modern system where text, dimensions, and hatches automatically resize their display scale based on the viewport scale, eliminating the need for multiple dimension layers.

Specialized Toolsets (Verticals)

Modern "One AutoCAD" subscriptions include specialized toolsets built on the core AutoCAD engine, featuring intelligent objects and automated BOMs:

  • AutoCAD Architecture: Provides AEC-specific intelligent objects (walls, doors, windows) that automatically clean up intersections and generate elevations.
  • AutoCAD Mechanical: Includes libraries of 700,000+ standard manufacturing parts (fasteners, bearings), automated layer management, and advanced BOM generation.
  • AutoCAD Electrical: Built for control system designers to create panel layouts, schematic design, and automatic wire numbering.
  • AutoCAD Map 3D / Plant 3D: Extends AutoCAD into GIS topologies and P&ID process piping routing.

Extensibility & Automation

AutoCAD's massive ecosystem is driven by its open architecture, allowing firms to automate repetitive tasks:

  • AutoLISP: A dialect of LISP built directly into AutoCAD. Still the most popular way for end-users to write custom macros and parametric scripts.
  • ObjectARX (C++): The lowest-level, highest-performance API. Used by major developers (like Autodesk themselves) to create custom entity types and deep integrations.
  • .NET API & Python: Modern managed APIs (C#/VB.NET) for interacting with external databases (SQL/ERP) and building complex WPF dialogs.
