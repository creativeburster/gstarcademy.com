## 🎯 What is CAD Learn Hub?

**[CAD Learn Hub (gstarcademy.com)](https://gstarcademy.com)** is an open, structured literacy platform and learning directory designed for draftspersons, mechanical design engineers, BIM managers, and civil infrastructure specialists. 

Unlike scattered forums or paywalled video courses, CAD Learn Hub provides a unified, structured learning journey:
**Understand Fundamentals (Knowledge Base) $\to$ Master Tools (Curated Tutorials) $\to$ Stay Informed (Industry News & Benchmarks).**

## 🛠️ The 6 Core Career Tracks

1. **Architectural BIM**: Parametric families, LOD 300-400 modeling, and IFC open-standard collaboration.
2. **Mechanical CAD (MCAD)**: Constraint-based sketches, feature solids, tolerance analysis, and ASME Y14.5 GD&T.
3. **Civil & Infrastructure**: Digital terrain modeling, corridor grading, and volumetric calculations.
4. **General 2D Drafting**: Precision geometry, layers, block management, and ANSI/ISO drawing standards.
5. **Engineering Simulation (CAE/FEA)**: Finite element meshing, boundary conditions, and stress analysis.
6. **Visualization & Rendering**: PBR material workflows, lighting, and real-time architectural walk-throughs.
