GRX (C++ Runtime Extension)

High Performance

GstarCAD Runtime eXtension (GRX) is a C++ class library functionally and syntactically equivalent to AutoCAD ObjectARX®. Enables direct access to GstarCAD's core geometry database, graphics subsystem, and command engine.

  • • Syntax Parity: Almost 1:1 header and method names (e.g. AcDbEntity → GcDbEntity)
  • • Custom Entities: Implement custom graphical objects with DWG persistence
  • • Minimal Porting Cost: Usually requires only header replacement and recompilation

.NET API (C# / VB.NET)

Modern & Rapid

Full managed .NET wrapper providing modern object-oriented access. Develop rich WPF/WinForms dockable palettes, Ribbon controls, and automated transaction-based drawing processors with Visual Studio.

  • • Managed Assemblies: gcadmgd.dll & gcadmdg.dll
  • • Namespace Parity: Autodesk.AutoCAD.* → GstarCAD.*
  • • LINQ & Database Transactions: Safe and robust document transaction locks

AutoLISP & Visual LISP

Script Automation

Native interpreter for .lsp, .fas, and .vlx routines. Includes full support for ActiveX COM interop (vlax-*, vla-*) and Dialog Control Language (DCL) for user interfaces.

  • • No Compilation Required: Direct drag-and-drop loading via APPLOAD
  • • Compatibility: 99%+ of legacy AutoCAD LISP scripts execute identically
  • • Built-in VLISP IDE: Interactive debugger and code editor

VBA (Visual Basic) & COM

Office Integration

Complete VBA 7.1 (64-bit) runtime environment. Seamlessly exchange data between GstarCAD drawings and Microsoft Excel, Access, ERP, or SQL databases for automated BOM export and schedule updates.

  • • Type Library: Standard COM automation object model
  • • Legacy Support: Run existing .dvb project files
  • • Excel Interop: Real-time bi-directional drawing table updates

Porting C++ ObjectARX® Applications to GRX

Most ObjectARX projects can be compiled to GRX in hours using automated string replacement
// 1. Header Inclusion Prefix Transformation
- #include "dbmain.h" // AutoCAD
+ #include "gcad/gcad.h" // GstarCAD GRX

// 2. Class Prefix Transformation: Ac* → Gc*
- AcDbBlockTableRecord* pBlockRecord;
+ GcDbBlockTableRecord* pBlockRecord;

// 3. Command Definition Macro
- AcedRegCmds->addCommand(...);
+ GcedRegCmds->addCommand(...);
