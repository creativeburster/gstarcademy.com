GRX (C++ Runtime Extension)

High Performance

GstarCAD Runtime eXtension (GRX) is a C++ class library functionally and syntactically equivalent to AutoCAD ObjectARX®. Enables direct access to GstarCAD's core geometry database, graphics subsystem, and command engine.

  • • Syntax Parity: Almost 1:1 header and method names (e.g. AcDbEntity → GcDbEntity)
  • • Custom Entities: Implement custom graphical objects with DWG persistence
  • • Minimal Porting Cost: Usually requires only header replacement and recompilation

ObjectARX® to GRX Complete Symbol & Header Mapping Reference

Binary-level API architecture parity compiled by the Suzhou Gstarsoft SDK Engineering Team

The GstarCAD Runtime eXtension (GRX) SDK is engineered from the ground up to mirror the class hierarchy, virtual method table (vtable) semantics, smart pointer templates (GcDbObjectPointer), and transaction lifecycle of Autodesk ObjectARX®. By maintaining a conditional compilation header (StdArx.h) with typedef aliases, ISVs can compile a single C++ codebase into both .arx and .grx binaries:

Geometry Library (Ge) AcGePoint3d, AcGeVector3d, AcGeMatrix3d GcGePoint3d, GcGeVector3d, GcGeMatrix3d Identical linear algebra and tolerance methods
Graphics Interface (Gi) AcGiWorldDraw, AcGiViewportDraw GcGiWorldDraw, GcGiViewportDraw Full custom entity procedural rendering support

Production Code Blueprints: C# .NET Transactions & Side-Database Processing

Verified on GstarCAD 2027 Professional with .NET Framework 4.8 / .NET 8

Below is a complete, thread-safe C# .NET command implementation demonstrating how to iterate through Model Space entities, filter block references with extended entity data (XData), and perform off-screen batch processing using Database.ReadDwgFile() without opening drawings in the editor UI: 

#if GSTARCAD
using Gssoft.Gscad.Runtime;
using Gssoft.Gscad.ApplicationServices;
using Gssoft.Gscad.DatabaseServices;
using Gssoft.Gscad.EditorInput;
using Gssoft.Gscad.Geometry;
#else
using Autodesk.AutoCAD.Runtime;
using Autodesk.AutoCAD.ApplicationServices;
using Autodesk.AutoCAD.DatabaseServices;
using Autodesk.AutoCAD.EditorInput;
using Autodesk.AutoCAD.Geometry;
#endif

namespace EnterpriseCadAutomation
{
    public class BatchBomProcessor
    {
        [CommandMethod("GCAD_AUDIT_BLOCKS", CommandFlags.Modal)]
        public void AuditModelSpaceBlocks()
        {
            Document doc = Application.DocumentManager.MdiActiveDocument;
            Database db = doc.Database;
            Editor ed = doc.Editor;

            using (Transaction tr = db.TransactionManager.StartTransaction())
            {
                BlockTable bt = (BlockTable)tr.GetObject(db.BlockTableId, OpenMode.ForRead);
                BlockTableRecord ms = (BlockTableRecord)tr.GetObject(bt[BlockTableRecord.ModelSpace], OpenMode.ForRead);

                int count = 0;
                foreach (ObjectId objId in ms)
                {
                    if (objId.ObjectClass.DxfName == "INSERT")
                    {
                        BlockReference br = (BlockReference)tr.GetObject(objId, OpenMode.ForRead);
                        foreach (ObjectId attId in br.AttributeCollection)
                        {
                            AttributeReference att = (AttributeReference)tr.GetObject(attId, OpenMode.ForRead);
                            if (att.Tag.Equals("PART_NUMBER", System.StringComparison.OrdinalIgnoreCase))
                            {
                                count++;
                            }
                        }
                    }
                }
                ed.WriteMessage($"\n[GstarCAD Audit] Verified {count} intelligent part references in Model Space.");
                tr.Commit();
            }
        }
    }
}
