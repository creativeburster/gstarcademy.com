Layer 4 — Concept drill-down (matrix rows)

Buffett-letter style: one tight note per row, grounded in which PDFs carry the topic—then open the file for depth. Back to matrix ↑

Coordinates & precision

This is the “alphabet” of 2D: object snaps, grid discipline, and reliable numeric entry separate hobby drawings from reviewable engineering graphics. Shih/Jumper’s 2024 intro and the beginner tour stress cert-style accuracy; G206 and the SourceCAD drill pack assume you can already hold tolerance visually while drawing.

Go next: Shih 2D PDF · Beginner tour PDF · Curriculum stages 1–2

Layers / properties

Layers bundle visibility, plot behavior, and often lineweight logic—poor layer hygiene becomes expensive when teams exchange DWGs. The beginner tour and G206 treat layers as a production convention; Kurland’s 3D title still leans on organized properties when models get dense; SourceCAD exercises reward consistent layering across many parts.

Go next: Beginner tour PDF · G206 PDF · Glossary (layers / xref)

Layouts & plotting

Model space holds true geometry; layout tabs are where scale, viewports, and sheet frames turn a model into a deliverable. The intro tour walks plotting end-to-end; G206 reinforces model-vs-layout checklists; SourceCAD’s drawing sets assume you can publish predictable sheets.

Go next: Beginner tour PDF · G206 PDF · Practice PDF

Solids / 3D interface

Kurland is the anchor: workspace choice (3D Basics vs full 3D Modeling), solid and mesh tool ribbons, and the mental shift from “flat drafting” to volumetric editing. The beginner intro touches 3D lightly; SourceCAD’s later chapters keep 3D exercises practical rather than theoretical.

Go next: Kurland 3D PDF · Terms hub · Curriculum stage 3

BOM & tolerances

G206 is the spine here: moving from geometry to parts lists, explicit tolerances, and language that manufacturing and inspection can execute. Other PDFs touch annotation; this row is where “CAD pretty” meets contractual drawing practice—worth pairing with glossary entries on dimensioning.

Go next: G206 PDF · Term cards

Projection / practice sets

SourceCAD’s ebook is built around dimensioned exercises and third-angle projection literacy—closer to shop-floor reading skill than button tutorials. G206 adds discipline-neutral examples; use this row when learners need reps, not another feature tour.

Go next: Practice PDF · Self-study hub · G206 PDF
