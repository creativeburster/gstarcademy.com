Source · GstarCAD 2026 Complete Features Guide

GstarCAD 2026 delivers a significant leap in overall performance. Drawing opening speed is improved by over 40% on average (multi-reference drawings open in under 1 minute). Common operations are improved by over 20%. Specifically, EXTEND/TRIM is up to 11x faster, block creation is 5x faster, and Hatching (pick-point on complex drawings) is up to 30x faster.

Source · GstarCAD 2026 Complete Features Guide

GstarCAD supports native DWG and DXF file formats, fully compatible with ACAD from version 2.5 to 2018. For developers, it offers robust APIs including LISP (LSP, FAS, VLX), VBA, GRX (C++), .NET, COM, and Python. Note that .PY file loading is natively supported.

Source · GstarCAD Licensing Policy

GstarCAD offers a flexible licensing policy. You can choose a Perpetual License (buy once, use forever), pair it with a subscription plan for updates, or opt for a Yearly Subscription. Licenses are available as Stand-alone (tied to one host) or Network (pool of licenses on a server), using either a Soft key (serial number) or Dongle (USB-key).

Source · GstarCAD Point Cloud 2026 User Guide

Integrated with the Undet plugin, it supports a wide range of formats including: *.E57, *.FLS, *.RCP/RCS, *.PTX, *.ZFS, *.LAS, *.LAZ, *.PTS, *.PLY, *.DP, *.FPR, *.LSPROJ, *.FWS, *.CL3, *.CLR, *.RSP, ASCII / NEZ (X,Y,Z/i/RGB) and custom ASCII / TXT file format import.

Source · GstarCAD Point Cloud Density Settings

For loading full density, the threshold is typically 12-48 million points (can be increased to 72+ million on powerful PCs). For the maximum visible preview point count, a minimum of 16 million points is recommended, with an optimal range of 16-36+ million points.

Source · GstarCAD 2026 Innovation Features

GstarCAD 2026 introduces Phase 2 of Parametric Constraints, including Dimensional Constraints and a Parameters Manager. This allows you to link dimensions to mathematical formulas and variables, enabling automated design updates when parameters change.

Source · GstarCAD 2026 Innovation Features

Drawing Merge is an innovative feature that streamlines workflows by allowing you to easily consolidate multiple separate drawings or project branches into a single master file.
