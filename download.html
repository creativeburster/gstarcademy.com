Enterprise IT Silent Deployment & Network License Provisioning

Zero-touch mass installation across 50 to 5,000+ engineering workstations via Microsoft SCCM, Intune, or Active Directory GPO

For enterprise CAD managers evaluating GstarCAD across multi-disciplinary departments, our installers support standard Windows Installer (MSI) and silent executable parameters. IT administrators can pre-bind the FlexNet / Gstarsoft License Manager (GLM) server IP address, inject corporate .dwt drawing templates, map network .ctb plot style folders, and register trusted AutoLISP paths during unattended installation:

# 1. Silent Unattended Installation of GstarCAD 2027 Professional (64-bit)
GstarCAD2027_Pro_en-US_x64.exe /S /v"/qn INSTALLDIR="C:\Program Files\Gstarsoft\GstarCAD2027" ALLUSERS=1"

# 2. Pre-configure Floating Network License Server via Windows Registry (Port 27000)
reg add "HKLM\SOFTWARE\Gstarsoft\GstarCAD\R27\en-US\License" /v "LicenseServer" /t REG_SZ /d "27000@cad-lic-01.corp.internal" /f

# 3. Map Corporate Shared Plot Styles (.CTB), SHX Fonts, and Trusted LISP Directories
reg add "HKCU\Software\Gstarsoft\GstarCAD\R27\en-US\Profiles\Default\General" /v "PrinterStyleSheetDir" /t REG_SZ /d "\\fileserver\cad_standards\PlotStyles" /f
reg add "HKCU\Software\Gstarsoft\GstarCAD\R27\en-US\Profiles\Default\Variables" /v "TRUSTEDPATHS" /t REG_SZ /d "\\fileserver\cad_standards\LISP;C:\CADTools\..." /f

Evaluation, Compatibility & Commercial Licensing FAQ

Answers to common technical and procurement questions before installing your 30-day trial
1. Does the 30-day free trial add watermarks to plotted PDFs or modify my DWG files?

No. The 30-day evaluation version of GstarCAD Professional, Mechanical, and Architecture is 100% unlocked for commercial testing. Drawings saved or plotted during the trial contain zero educational stamps or watermarks, and can be opened seamlessly in AutoCAD® without any "foreign DWG" warning dialogs.

2. Can GstarCAD and AutoCAD be installed side-by-side on the same workstation?

Yes. GstarCAD installs into an isolated directory tree (C:\Program Files\Gstarsoft\) and uses independent registry hives and COM Class IDs (CLSIDs). You can run GstarCAD 2027 and AutoCAD 2024/2026 simultaneously on the same monitor to benchmark opening speeds, memory footprint, and LISP execution side-by-side.

3. How do I convert my 30-day trial into a permanent commercial license without reinstalling?

When you purchase a perpetual or subscription license from Gstarsoft or an authorized local distributor, simply open the GstarCAD License Manager from the Help menu, enter your 24-character Serial Key or point to your network license server IP. All your custom workspaces, tool palettes, and recent files remain intact—no reinstallation required.

4. What happens to my drawings if I purchase a Perpetual License and never pay again?

With a GstarCAD Perpetual License, you own the right to run that software version indefinitely with zero recurring annual fees. Unlike subscription-only CAD vendors that lock you out of editing mode when a subscription lapses, your GstarCAD perpetual seats never expire.
