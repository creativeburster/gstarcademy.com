Architecture of the Interactive CAD/BIM/CAE Knowledge Graph

The GstarCAD Academy Knowledge Graph models industrial engineering workflows as a directed acyclic prerequisite network combined with bidirectional semantic neighborhood links. Powered by a force-directed physics simulation (D3.js Force-Link & Many-Body spatial clustering), each node represents a verified engineering concept, geometric modeling kernel primitive, international drafting standard (ISO 128, ASME Y14.5, ISO 19650, buildingSMART IFC 4.3), or software-specific workflow.

1. Topological Cluster Taxonomy

Nodes are grouped into six primary engineering clusters: 2D Drafting & DWG Kernel Architecture (Layers, Xrefs, Dynamic Blocks, Annotative Scaling, AutoLISP), Parametric Mechanical CAD (MCAD) (B-Rep Topology, Sketch Constraints, GD&T Datum Reference Frames, Sheet Metal K-Factor), AEC & OpenBIM Coordination (IFC Schema, CDE Container Status, BCF Clash Tracking), Civil Infrastructure (TIN Delaunay Surfaces, Clothoid Alignments, Corridor Modeling), CAE Simulation (FEA Mesh Convergence, Shear Locking, CFD $y^+$ Boundary Layers), and PBR Visualization (ACEScg Color Pipelines, BSDF Energy Conservation).

2. Upstream Prerequisites vs. Downstream Mastery

When you select any node in the graph canvas, the Inspector Panel computes its Upstream Prerequisites (foundational concepts you must understand first, such as mastering Coordinate Systems and Object Snaps before configuring Shared Geodetic Coordinates) and its Downstream Applications (advanced production workflows unlocked by that concept, such as automated Sheet Set publishing or C++ GRX custom entity development).

3. Integration with GstarCAD Skill Certification

Every concept node in this graph maps directly via its canonical slug to our 654-question GstarCAD Skill Certification Engine (Take the Diagnostic Assessment). Passing track micro-lessons or the 12-question Placement Test automatically illuminates mastered nodes in your local browser profile, transforming this graph into a live visual transcript of your CAD engineering competency.
